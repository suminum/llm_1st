# 검증도구

자료가 **진짜로 그렇게 동작하는지** 기계로 확인하는 도구들입니다.

사람 눈으로는 안 잡힙니다. "다 됐다"고 말하기 전에 반드시 돌리세요.

```bash
npm run 검증          # 전체 (구조 감사 포함)
npm run 감사          # 짜임새만 빠르게
npm run 검증:브라우저  # 진짜 크롬으로 CORS 확인 (사람이 읽고 판단)
```

---

## 무엇을 확인하나

| 도구 | 확인하는 것 | 어떻게 |
| --- | --- | --- |
| `출력검증.js` | `// 출력:` 주석 ↔ 진짜 실행 결과 | `node` 로 실행해서 stdout 대조 |
| `서버검증.js` | `// 확인:` 선언 ↔ 진짜 서버 응답 | 서버를 띄우고 실제 요청 |
| `화면검증.js` | `// 화면:` 선언 ↔ 진짜 크롬으로 눌러 본 결과 | 서버를 띄우고 크롬으로 버튼을 눌러 봄 |
| `정합성검사.js` | 자료가 스스로 정한 규칙 | 파일을 읽어서 정적 검사 |
| `브라우저검증.js` | CORS 가 정말 막히는지 | 진짜 크롬을 띄워서 |
| `구조감사.js` | 단원마다 짜임새가 같은지 | 파일을 읽어서 세어 봄 |
| `전체검증.js` | 브라우저검증을 뺀 나머지를 한 번에 | — |

**브라우저검증만 따로**인 이유: 결과를 사람이 읽고 판단해야 합니다.
개념02는 전부 '실패'가 정답이고, 개념03·04는 전부 '성공'이 정답입니다.

**구조감사가 따로 있는 이유**: 앞의 것들은 전부 '이 코드가 도는가' 를 봅니다.
그런데 자료는 **관례가 조용히 끊기는 방식**으로도 무너집니다.
실제로 `── 정리 ──` 가 03단원 개념03에서 끊겨 38개 파일에 정리가 없었는데,
코드는 멀쩡히 돌기 때문에 나머지 검증기는 전부 초록불이었습니다.

## 출력검증

```js
console.log(1 + 2);
// 출력: 3
```

- `// 출력:` 은 **다음 줄에 단독으로** 씁니다. 코드 줄에 붙이면 수집이 안 됩니다(경고를 냅니다).
- 앞에 공백이 있어도 됩니다. `catch` 블록 안 등.
- 정답 블록 안의 `//    // 출력:` 은 `//` 로 시작하므로 자동으로 제외됩니다.
- 여러 줄이 나오면 `// 출력:` 도 그 줄 수만큼 씁니다.
- `.listen(` 이 있는 파일은 건너뜁니다. 서버검증이 봅니다.

```bash
node _검증도구/출력검증.js                    # 전체
node _검증도구/출력검증.js 02_파일_다루기      # 한 단원
```

## 서버검증

```js
app.get("/health", (req, res) => {
  res.json({ status: "ok" });
});

// 확인: GET /health
// 응답: 200 {"status":"ok"}
```

서버를 자식 프로세스로 띄우고(포트는 `PORT` 환경변수로 넘김), 실제로 요청을 보내
상태코드·본문·응답 헤더를 대조한 뒤 끕니다.

이 선언은 **학생에게도 그대로 안내**가 됩니다. 주석이 낭비되지 않습니다.

### 본문 쓰는 법

| 쓰는 법 | 보내는 것 |
| --- | --- |
| `{"a":1}` | JSON |
| `form:name=hong&age=20` | HTML 폼 형식 |
| `multipart:@file=사진.png` | 파일 업로드 (내용은 "가짜 파일 내용") |
| `multipart:@file=큰.png:500` | 500바이트짜리 파일 |
| `multipart:@file=a.png&desc=설명` | 파일 + 글자 필드 |

### 요청 헤더 붙이기

```js
// 확인: GET /me [Authorization: Bearer key-user-1]
// 응답: 200 {"이름":"김민준"}
```

여러 개는 `;` 로 나눕니다.

> **헤더 값에 한글을 쓰면 요청 자체가 안 나갑니다.** 증표·키는 영어로 만드세요.

### 응답 헤더 대조

```js
// 확인: GET /x [Origin: http://localhost:5500]
// 응답: 200 {"ok":true}
// 헤더: access-control-allow-origin=http://localhost:5500 | vary=Origin
```

여러 개는 `|` 로 나눕니다. 헤더 값 자체에 `;` 가 자주 들어가서 이렇게 정했습니다.
값이 `(없음)` 이면 **그 헤더가 없어야 한다**는 뜻입니다.

### 주의

- 선언은 **파일에 적힌 순서대로** 실행됩니다. 데이터가 바뀌는 서버라면 순서가 곧 시나리오입니다.
- 서버는 `PORT` 환경변수를 읽어야 합니다.
  ```js
  const PORT = Number(process.env.PORT) || 3000;
  ```
  `Number` 를 빼먹으면 `"3000"+100` 같은 사고가 납니다.
- 준비(초기화)가 끝난 뒤에 `listen` 하세요.
  ```js
  async function 시작하기() {
    await 저장소.초기화(처음데이터);
    app.listen(PORT, () => { ... });
  }
  ```

## 정합성검사

돌려 봐도 안 잡히는 것들을 파일을 **읽어서** 확인합니다.

| 규칙 | 안 지키면 |
| --- | --- |
| 한글 라우트 주소 | 에러 없이 조용히 404 |
| 한글 응답 헤더 값 | `ERR_INVALID_CHAR` 로 500 |
| 한글 업로드 필드 이름 | `MulterError: Unexpected field` |
| Express 4 라우트 문법 (`:id?`, 이름 없는 `*`) | 서버가 아예 안 켜짐 |
| 에러 처리기 인자 개수 | 에러 처리기로 인식이 안 됨 |
| `PORT` 를 글자인 채로 계산 | 포트가 `"3000100"` 이 됨 |
| `// 출력:` 이 코드 줄에 붙음 | 검증기가 수집을 못 함 |
| `// 확인:` 인데 `// 응답:` 이 없음 | 그 선언이 조용히 무시됨 |
| `// 확인:` 인데 `.listen` 이 없음 | 서버검증이 그 파일을 건너뜀 |

주석 줄은 검사하지 않습니다. 자료에는 '틀린 예'를 주석으로 보여 주는 곳이 아주 많습니다.

**진짜 코드에서 일부러 틀리게 쓴 곳**(살아 있는 데모)에는 그 줄에 표시를 답니다.

```js
app.get("/한글주소", (req, res) => {  // 검증무시: 일부러 안 되는 예를 살려 둔 것
```

지금 표시가 달린 곳은 셋뿐입니다.

| 파일 | 무엇 |
| --- | --- |
| `04/개념01` | 한글 라우트가 404 나는 것을 보여 주는 라우트 |
| `05/개념02` | 한글 헤더가 터지는 것을 `try/catch` 로 잡아 보여 주는 곳 |
| `09/개념02` | 한글 필드 이름이 `Unexpected field` 를 내는 라우트 |

## 브라우저검증

CORS 는 **브라우저만** 막습니다. Node 의 `fetch`·Postman·curl 은 CORS 를 아예 안 따집니다.
그래서 서버검증으로는 "정말 막히는지"를 확인할 수 없습니다.

진짜 크롬을 띄워서 `08_정적파일과_CORS/front/다른출처.html` 을 5500 포트로 열고,
버튼 다섯 개를 눌러 결과를 봅니다.

```bash
npm install --save-dev puppeteer-core     # 한 번만
node _검증도구/브라우저검증.js
```

크롬을 새로 받지 않습니다. 이미 깔린 크롬을 씁니다.
다른 곳에 깔았다면 `CHROME_PATH` 환경변수로 알려 주세요.

### 결과 읽는 법

| 대상 | 정답 |
| --- | --- |
| `개념02` | **전부 실패**. CORS 를 일부러 안 열었습니다 |
| `개념03` · `개념04` | 전부 성공. `⑤ 헤더읽기` 에서 `X-Total-Count` 가 보여야 합니다 |
| `연습문제_서버_정답` | 전부 성공 |
| `개념05` | **대상이 아닙니다**. 프록시 방식이라 같은 출처로 불러야 합니다 |

`개념05` 는 `http://localhost:3000` 을 직접 열어서 확인하세요.

## 새 단원을 추가할 때

폴더 이름을 `10_이름` 처럼 **두 자리 숫자로 시작**하면 자동으로 검사 대상이 됩니다.
따로 등록할 것이 없습니다.

`node_modules` 와 `uploads` 폴더는 건너뜁니다.
