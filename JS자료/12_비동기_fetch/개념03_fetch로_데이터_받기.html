개념 03 — fetch 로 데이터 받기

인터넷 연결이 필요합니다. 브라우저로 열고 버튼을 눌러 보세요. F12 → Console 과 Network 탭을 함께 보면 실제로 데이터를 받아오는 게 보입니다.

인터넷이 막혀 있어 안 된다면 이 파일 아래쪽 <script> 바로 위에 있는 오프라인_대체.js 줄에서 주석 기호를 지우세요. 인터넷 없이도 똑같이 동작합니다.

HTML 과 CSS 는 몰라도 됩니다. 이 파일 위쪽의 <style> 과 <body> 는 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script> 안부터 읽으세요.
