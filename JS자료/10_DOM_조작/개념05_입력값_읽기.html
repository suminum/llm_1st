개념 05 — 입력값 읽기

브라우저로 열고 F12 → Console 을 함께 보세요. 아래 칸에는 미리 값이 채워져 있습니다. 코드가 그 값을 읽어 아래 결과 상자에 정리해 뒀습니다.
값을 고쳐도 결과는 바뀌지 않습니다. 코드가 페이지를 열 때 한 번만 읽었기 때문입니다. 입력에 반응하는 방법은 11단원(이벤트)에서 배웁니다.

HTML 과 CSS 는 몰라도 됩니다. 이 파일 위쪽의 <style> 과 <body> 는 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script> 안부터 읽으세요.

여기에 결과가 나옵니다
