# 실습프로젝트

React 자료의 예제가 전부 들어 있는 폴더입니다. **여기서 `npm` 명령을 칩니다.**

---

## 시작하기

```
npm install        ← 맨 처음 한 번만 (인터넷 필요, 30초쯤)
npm run dev        ← 그 뒤로는 이것만
```

터미널에 뜬 주소(`http://localhost:5173/`)를 브라우저에서 열면 왼쪽에 예제 목록이 나옵니다.

**끄는 것은 `Ctrl` + `C`** 입니다. 터미널을 먼저 클릭하고 누르세요.

처음이라 막힌다면 `src/00_개발환경_만들기/개념01_설치하고_켜기.md` 를 보세요.
터미널을 한 번도 안 써 본 사람 기준으로 썼습니다.

---

## 예제는 어디에 있나

전부 `src` 안입니다. 단원 폴더에 `.jsx` 를 만들면 **왼쪽 목록에 저절로 나타납니다.**

```
src/
├─ _ui/                    자료가 쓰는 부품 (읽지 않아도 됩니다)
├─ 00_개발환경_만들기/       첫 시간에 읽는 문서 (.md)
├─ 01_React_시작하기/
├─ ...
└─ 15_부록_타입스크립트/
```

`App.jsx` 와 `main.jsx` 는 자료가 미리 만들어 둔 틀입니다. 고치지 않아도 됩니다.

---

## 이렇게 진행합니다

```
[터미널]   npm run dev 를 켜 둔 채로 그대로 둡니다   ← 건드리지 않습니다
[VS Code]  src 안의 예제 파일을 열어 읽고 고칩니다
[브라우저] 왼쪽에서 예제를 고르고, 저장하면 저절로 바뀌는 화면을 봅니다
```

- **새로고침(F5)은 누르지 마세요.** 왼쪽에서 고른 예제가 풀립니다. 저장이면 충분합니다.
- **화면이 안 바뀌면 터미널부터 보세요.** 문법이 틀리면 브라우저까지 가지도 못합니다.
- **F12 → Console 을 띄워 두세요.** 이 자료는 콘솔을 안 보면 절반이 안 보입니다.

## 14단원은 터미널을 두 개 씁니다

서버와 붙는 단원이라 연습용 서버를 따로 켭니다. **설치할 것은 없습니다.**

```
터미널 ①   실습프로젝트 에서          npm run dev
터미널 ②   실습프로젝트/14단원_서버 에서  node 서버.js
```

서버는 4000번 포트를 씁니다. 서버 코드는 읽지 않아도 됩니다.

---

## 명령 목록

| 명령 | 하는 일 |
|---|---|
| `npm install` | 도구 내려받기 (맨 처음 한 번) |
| `npm run dev` | 개발 서버 켜기 — 수업 중에는 이것만 씁니다 |
| `npm run build` | 배포용으로 묶기 (수업에서는 안 씁니다) |
| `npm run lint` | 코드 검사 (수업에서는 안 씁니다) |
| `npm run typecheck` | 타입 검사 — 15단원 부록에서 씁니다 |

---

## 필요한 것

- **Node.js 22 이상** — `node -v` 로 확인하세요. `v18`·`v20` 은 안 됩니다.
- **인터넷** — `npm install` 할 때만 필요합니다. 그 뒤로는 없어도 됩니다.

`node_modules` 폴더는 `npm install` 이 만듭니다. 지워도 됩니다 — 다시 치면 돌아옵니다.
