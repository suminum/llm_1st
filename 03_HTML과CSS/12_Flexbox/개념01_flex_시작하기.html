섹션 6 — 자주 하는 실수

다시 강조합니다. CSS 는 틀려도 에러가 나지 않습니다. 화면이 안 바뀌는 것이 유일한 신호입니다.

실수 1 — 나란히 놓고 싶은 상자 자신에게 display: flex 를 씀
.side-box { display: flex; } /* 상자 자신에게 */

상자들은 여전히 세로로 쌓입니다. display: flex 는 자기 자식을 늘어놓는 명령이라서, 상자 자신에게 쓰면 그 상자 안쪽만 손댈 뿐 옆 상자와는 아무 상관이 없습니다. 나란히 놓고 싶은 상자들의 부모에 써야 합니다.

엉뚱한 변화가 하나 생기기는 합니다. 상자 안 글자가 가운데에서 왼쪽으로 옮겨 갑니다. 상자가 컨테이너가 되면서 text-align: center 가 글자에 더 이상 통하지 않기 때문입니다. 바라던 것과 전혀 다른 곳이 바뀌니 더 헷갈립니다.

이렇게 쓰세요
.side-wrap { display: flex; } /* 상자들을 감싼 부모에게 */
실수 2 — 아이템에 justify-content 를 씀
.miss-item { justify-content: center; }

섹션 5 아래쪽 데모가 바로 이것입니다. 상자는 꿈쩍도 하지 않습니다. justify-content 는 컨테이너가 아이템들을 어디에 모을지 정하는 속성이라, 아이템이 자기한테 써 봐야 지시할 상대가 없습니다.

실수 3 — display: flexbox 라고 씀
.typo-wrap { display: flexbox; }

기술의 별명이 "플렉스박스" 라서 값 이름도 그럴 거라고 생각하기 쉽습니다. 그런 값은 없습니다. 값 하나가 틀리면 그 한 줄만 통째로 버려집니다. 아래 상자가 세로로 쌓여 있는 것이 그 결과입니다. 값은 flex 입니다.

실수 5 — 주축을 그냥 "가로" 라고 외움
주축 = 가로, 교차축 = 세로 /* 기본값일 때만 맞습니다 */

지금은 맞는 말이지만 개념02 에서 flex-direction: column 을 쓰는 순간 주축이 세로가 됩니다. 그때 justify-content 가 갑자기 위아래를 움직여서 "고장 났나?" 싶어집니다. 주축은 아이템이 줄 서는 방향이라고 외우세요.

── 정리 ──

1. display: flex 는 부모(컨테이너) 에 씁니다. 자식이 아닙니다.

2. 컨테이너의 바로 아래 자식이 자동으로 아이템이 됩니다. 손자는 아닙니다.

3. 주축은 아이템이 줄 서는 방향, 교차축은 그와 직각인 방향입니다.

4. 속성은 컨테이너용과 아이템용으로 나뉩니다. 자리를 틀리면 조용히 무시됩니다.

5. flex 를 쓰면 inline-block 의 정체 모를 6px 틈이 생기지 않습니다.

6. 세로 가운데 정렬은 계산 없이 컨테이너 두 줄로 끝납니다.
