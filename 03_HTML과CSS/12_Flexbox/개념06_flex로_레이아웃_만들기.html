섹션 6 — 자주 하는 실수

레이아웃을 조립할 때는 "어느 컨테이너에 쓸 것인가" 를 틀리는 실수가 가장 많습니다.

실수 1 — 메뉴를 오른쪽에 붙이려고 nav 에 justify-content 를 씀
.menu { justify-content: flex-end; } /* nav 안쪽만 움직입니다 */

메뉴 덩어리는 꿈쩍도 하지 않습니다. .menu 는 링크 세 개의 컨테이너이지, 자기 자신을 옮기는 주체가 아닙니다. nav 안에는 남는 공간이 없으니 링크들도 그대로입니다. 움직여야 할 것은 nav 의 부모인 header 입니다.

.bad-bar { justify-content: space-between; } /* 부모에 */
실수 2 — 카드 목록에 flex-wrap 을 안 씀
.bad-cards { display: flex; gap: 20px; } /* flex-wrap 이 없습니다 */

카드가 아랫줄로 내려가지 않고 한 줄에 전부 욱여넣어집니다. 여섯 개가 들어가느라 카드 폭이 121px 까지 줄고 글자가 잘게 접힙니다. 카드가 이상하게 좁아졌다면 flex-wrap: wrap 을 빠뜨린 것입니다.

실수 3 — 카드 높이를 맞추려고 height 를 직접 씀
.card { height: 120px; } /* 글이 길면 넘칩니다 */

지금은 맞아 보여도 글이 한 줄만 길어지면 글자가 카드 밖으로 삐져나옵니다. 키를 맞추는 일은 이미 flex 가 하고 있습니다. align-items 의 기본값 stretch 가 한 줄 안의 카드를 자동으로 가장 큰 카드에 맞춥니다. height 는 지우세요.

실수 4 — 사이드바 폭이 안 지켜짐
.side-col { flex: 0 1 220px; } /* shrink 가 1 입니다 */

220px 이라고 썼는데 화면에서는 164px 입니다. 가운데 숫자가 flex-shrink 이고, 1 이면 모자랄 때 줄어듭니다. 아래에서는 본문이 flex: 1 1 900px 으로 넓은 자리를 요구해 전체가 824px 을 넘겼고, 그래서 사이드바까지 폭을 양보했습니다. 폭을 꼭 지켜야 하면 가운데를 0 으로 두세요. flex: 0 0 220px 입니다.

본문

본문이 넓은 자리를 요구하면 전체가 컨테이너를 넘칩니다. 그러면 shrink 가 1 인 아이템부터 폭을 양보하기 시작합니다.

사이드바

220px 이라고 썼습니다

실수 5 — 카드 사이를 margin 으로 띄움
.card { margin-right: 20px; } /* 줄 끝에도 붙습니다 */

줄의 마지막 카드 오른쪽에도 20px 이 붙어서 오른쪽 끝이 다른 요소와 안 맞습니다. 게다가 아랫줄과의 세로 간격은 따로 margin-bottom 으로 또 줘야 하고, 맨 아랫줄에는 그것도 지워야 합니다. gap 한 줄이면 가로세로가 한 번에 해결되고 예외도 없습니다.

── 정리 ──

1. 내비게이션 바 = display: flex + justify-content: space-between + align-items: center.

2. 한 덩어리만 반대편으로 밀어내려면 그 아이템에 margin-left: auto.

3. 카드 목록 = flex-wrap: wrap + gap + 아이템에 flex: 1 1 기본폭.

4. 카드 높이 맞추기는 stretch 가 이미 해 줍니다. height 를 쓰지 마세요.

5. 카드 안에서 아래쪽에 붙이려면 세로 컨테이너로 만들고 margin-top: auto.

6. 정중앙 = justify-content: center + align-items: center.

7. 2단 = 고정 칸에 flex: 0 0 폭, 남는 칸에 flex: 1.

8. 페이지는 컨테이너를 겹겹이 포개서 만듭니다. 각 컨테이너는 자기 자식만 봅니다.
