개념 04 — 교차축 정렬 (align-items 와 align-content)

12단원 · Flexbox

이 파일의 무대는 안쪽 폭 600px · 안쪽 높이 160px 입니다. 상자 키는 글자 한 줄 기준으로 47px 이니, 세로로 113px 이 남습니다. 이 113px 이 어디로 가는지를 보면 align-items 가 한눈에 이해됩니다.

이 파일에 나오는 "왼쪽 좌표" 는 브라우저 창을 1280px 로 놓고 잰 값입니다. 본문이 가운데 정렬이라 창 폭이 다르면 숫자가 통째로 좌우로 밀립니다. 숫자 자체를 외우지 말고, 상자들 사이의 차이(간격·나뉜 몫)를 보세요. 그 차이는 창 폭과 상관없이 늘 같습니다.

섹션 7 — 자주 하는 실수

다섯 가지 모두 화면이 안 바뀌는 것이 유일한 신호입니다.

실수 1 — column 인데 좌우 정렬을 justify-content 로 함
.box { flex-direction: column; justify-content: center; }

좌우 가운데로 갈 줄 알았는데 위아래 가운데로 갑니다. column 에서 주축은 세로입니다. 좌우로 옮기려면 align-items: center 를 써야 합니다. 섹션 4 의 네 무대를 다시 보세요. 이 단원에서 가장 많이 나는 실수입니다.

실수 2 — 높이가 없는 컨테이너에서 align-items: center 를 씀
.noheight-stage { display: flex; align-items: center; }

아무 변화가 없습니다. 높이를 정하지 않으면 컨테이너 키는 가장 큰 아이템에 딱 맞춰집니다. 남는 세로 공간이 0 이니 가운데로 보낼 자리 자체가 없습니다. align-items 가 안 먹는다면 먼저 컨테이너 높이를 확인하세요.

2
실수 3 — align-self 를 컨테이너에 씀
.selfmiss-stage { align-self: flex-end; } /* 컨테이너에 썼습니다 */

아이템들은 그대로 있습니다. align-self 는 아이템이 자기 자리를 스스로 정하는 속성이라 컨테이너가 쓰면 아무 뜻이 없습니다. 전부 옮기려면 align-items, 하나만 옮기려면 align-self 입니다.

1
2
실수 4 — flex-wrap 없이 align-content 를 씀
.oneline-stage { align-content: center; } /* wrap 이 없습니다 */

아무 일도 일어나지 않습니다. align-content 는 여러 줄을 다루는 속성이라 flex-wrap: wrap 이 없으면 통째로 무시됩니다. 아래 무대에는 wrap 이 없어서 상자가 여전히 160px 로 늘어나 있습니다. 한 줄 안에서 위아래로 옮기고 싶었다면 필요한 것은 align-items 입니다.

1
2
실수 5 — 카드 높이를 맞추려는데 아이템에 height 가 있음
.card { height: 60px; } /* stretch 가 이 값을 못 이깁니다 */

"카드 키를 자동으로 맞추고 싶은데 안 된다" 는 대부분 이 경우입니다. stretch 는 높이를 정하지 않은 아이템만 늘립니다. 아이템에 적어 둔 height 를 지우면 그때부터 저절로 맞춰집니다. 섹션 1 의 두 번째 무대가 그 예입니다.

── 정리 ──

1. align-items 는 교차축 정렬이고 기본값은 stretch 입니다.

2. stretch 는 높이를 정하지 않은 아이템만 늘립니다.

3. 값은 stretch · flex-start · center · flex-end · baseline 입니다.

4. 하나만 다르게 하려면 그 아이템에 align-self 를 씁니다.

5. column 이면 justify-content 와 align-items 의 역할이 통째로 맞바뀝니다.

6. 정중앙은 justify-content: center + align-items: center 입니다.

7. 줄이 두 개 이상일 때 줄 뭉치를 움직이는 것은 align-content 입니다.
