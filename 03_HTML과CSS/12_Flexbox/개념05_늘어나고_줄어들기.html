개념 05 — 늘어나고 줄어들기

12단원 · Flexbox

이 파일의 속성은 전부 아이템에 씁니다. 컨테이너가 아닙니다. 무대 안쪽 폭은 600px 이고, 기본 상자 폭은 100px 입니다. 상자 셋이면 300px 을 쓰고 300px 이 남는다는 것만 기억하고 읽으세요.

이 파일에 나오는 "왼쪽 좌표" 는 브라우저 창을 1280px 로 놓고 잰 값입니다. 본문이 가운데 정렬이라 창 폭이 다르면 숫자가 통째로 좌우로 밀립니다. 숫자 자체를 외우지 말고, 상자들 사이의 차이(간격·나뉜 몫)를 보세요. 그 차이는 창 폭과 상관없이 늘 같습니다.

섹션 1 — flex-grow, 남는 공간을 비율로 나눠 갖기

flex-grow 는 남는 공간을 몇 몫 가져갈지 적는 숫자입니다. 기본값은 0 이고, 0 은 "한 몫도 안 받겠다" 는 뜻입니다.

✏️ 직접 해보기 1 — .grow2 의 값을 flex-grow: 4 로 바꿔 보세요. 몫의 합이 6 이 되어 한 몫은 50 이 되고, 첫 상자는 300px, 나머지는 150px 이 됩니다.

섹션 2 — flex-shrink, 모자랄 때 얼마나 양보할까

flex-shrink 는 grow 의 반대입니다. 기본값이 1 이라, 아무것도 안 써도 아이템은 이미 줄어들 준비가 되어 있습니다.

✏️ 직접 해보기 2 — .overflow-stage 에 flex-wrap: wrap 을 한 줄 더해 보세요. 세 번째 상자가 아랫줄로 내려가면서 삐져나온 부분이 사라집니다.

섹션 3 — flex-basis, 나눠 갖기 전의 기본 크기

flex-basis 는 계산을 시작할 때의 크기입니다. 기본값은 auto 이고, auto 는 "width 를 보라" 는 뜻입니다.

flex-grow: 1 + flex-basis: auto → 폭이 제각각

아주 아주 많이 긴 글자입니다

flex-grow: 1 + flex-basis: 0 → 셋 다 200px

짧다

아주 아주 많이 긴 글자입니다

flex-basis 는 주축 방향의 크기를 정합니다. flex-direction: column 이면 폭이 아니라 높이가 됩니다. 여기서도 "가로"가 아니라 "주축"이라는 말이 그대로 쓰입니다.

✏️ 직접 해보기 3 — .basis-zero-stage .word 의 flex-basis: 0 을 flex-basis: auto 로 바꿔 보세요. 아래 무대가 위 무대와 똑같아집니다.

order 는 HTML 을 고치지 않고 화면에 보이는 순서만 바꿉니다. 기본값은 0 이고, 숫자가 작을수록 앞에 옵니다.

order 는 보이는 순서만 바꿉니다. 개념02 의 -reverse 와 같은 주의사항이 그대로 적용됩니다. 코드 순서대로 읽어 주는 프로그램에는 여전히 1번, 2번, 3번으로 읽힙니다. 순서 자체가 중요하다면 HTML 을 고치세요.

섹션 6 — 자주 하는 실수

이 섹션의 속성들은 붙이는 자리를 특히 많이 틀립니다. 전부 아이템에 쓰는 속성이라는 것을 기억하세요.

실수 1 — flex-grow 를 컨테이너에 씀
.grow-on-container { display: flex; flex-grow: 1; }

아이템은 하나도 안 넓어집니다. flex-grow 는 아이템이 자기 몫을 주장하는 속성입니다. 컨테이너에 쓰면 "이 컨테이너가 자기 부모 안에서 늘어나겠다" 는 뜻이 되는데, 부모가 flex 컨테이너가 아니면 그마저도 무시됩니다.

100px
100px
이렇게 쓰세요
.grow-on-container .tile { flex-grow: 1; } /* 아이템에 */
실수 2 — flex: 1 을 써 놓고 width 가 안 먹는다고 함
.width-lost-stage .tile { width: 300px; flex: 1; }

width: 300px 이 분명히 있는데 화면에서는 200px 씩입니다. flex: 1 안에 flex-basis: 0% 가 숨어 있어서 width 를 덮어쓰기 때문입니다. 폭을 지키고 싶다면 flex: none 이나 flex: 0 0 300px 을 쓰세요.

width 300
width 300
width 300
실수 3 — flex-grow 값을 퍼센트라고 생각함
.percent-stage .tile { flex-grow: 50; } /* 50% 라는 뜻이 아닙니다 */

50 이든 1 이든 셋 다 같은 값이면 결과는 똑같습니다. flex-grow 는 절대적인 크기가 아니라 다른 아이템과 비교한 몫의 수이기 때문입니다. 아래 무대는 값이 50 인데도 결과가 flex-grow: 1 일 때와 같습니다.

grow 50
grow 50
grow 50
실수 4 — width 를 줬는데 상자가 작아진다고 함
.card { width: 300px; } /* flex-shrink 기본값 1 이 줄입니다 */

아이템의 width 는 공간이 넉넉할 때만 지켜집니다. 모자라면 flex-shrink 의 기본값 1 때문에 알아서 줄어듭니다. 섹션 2 의 첫 무대가 그 예입니다. 폭을 꼭 지켜야 하면 flex-shrink: 0 을 주거나 flex-wrap: wrap 으로 아랫줄에 내려보내세요.

실수 5 — order 로 내용 순서를 바꿈
.important { order: -1; } /* 중요한 글을 맨 앞으로 */

화면에서는 맨 앞으로 오지만 HTML 순서는 그대로입니다. 코드 순서대로 읽는 프로그램에는 여전히 원래 자리에서 읽히고, 키보드 탭 이동 순서도 화면과 어긋납니다. order 는 화면 폭에 따라 잠깐 자리를 바꾸는 용도이지 내용의 순서를 정하는 도구가 아닙니다.

── 정리 ──

1. 이 파일의 속성은 전부 아이템에 씁니다.

2. flex-grow 기본값 0 — 남는 공간을 몫 단위로 나눠 갖습니다.

3. flex-shrink 기본값 1 — 모자라면 알아서 줄어듭니다. 그래서 width 가 안 지켜집니다.

4. flex-basis 기본값 auto — 나눠 갖기를 시작하는 크기이고, 주축 방향입니다.

5. flex: 1 은 1 1 0% 입니다. basis 가 0 이라 내용 길이와 상관없이 폭이 같아집니다.

6. flex: none 은 0 0 auto, 늘지도 줄지도 않습니다.

7. order 는 보이는 순서만 바꿉니다. 내용 순서는 HTML 로 정하세요.
