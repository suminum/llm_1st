개념 04 — span 과 인라인

02단원 · 텍스트 태그

이 파일은 span 태그 하나와, 블록 요소와 인라인 요소라는 큰 구분을 다룹니다. 뒤에 나오는 CSS 단원 전체가 이 구분 위에 세워집니다. 데모 상자에서 무엇이 줄을 차지하고 무엇이 끼어드는지를 눈으로 익히세요.

span 은 감싸기만 하고 아무 일도 하지 않습니다. 화면도 전혀 바뀌지 않습니다.

섹션 3 — 인라인 요소는 글자 흐름 안에 낍니다

섹션 6 — 자주 하는 실수

블록과 인라인을 헷갈리면 화면이 미묘하게 어긋납니다. 에러는 나지 않으니 눈으로 알아채야 합니다.

실수 1 — span 을 나누면 줄이 바뀔 줄 알았음
<span>첫 줄</span> <span>둘째 줄</span>

소스에서 줄을 나눠 썼으니 화면에서도 나뉠 것 같습니다. 안 나뉩니다. "첫 줄 둘째 줄" 이 한 줄로 붙어 나옵니다. span 이 인라인이라 줄을 끊지 않고, 소스의 엔터는 개념02 에서 배운 대로 공백 한 칸으로 접히기 때문입니다.

span 을 줄 나눠 쓴 실제 결과

실수 2 — 문단 두 개를 옆에 나란히 놓으려 함
<p>왼쪽</p><p>오른쪽</p>

소스에서 아무리 붙여 써도 두 줄로 나옵니다. p 가 블록이라 각자 한 줄씩 통째로 차지하기 때문입니다. 옆에 나란히 놓는 방법은 11단원과 12단원에서 CSS 로 배웁니다. HTML 만으로는 방법이 없습니다.

실수 3 — 뜻이 있는데도 span 으로 감쌈
<p>마감은 <span class="important">오늘</span>입니다</p>

중요하다는 뜻이 있으니 <strong> 이 맞습니다. span 으로 감싸고 CSS 로 굵게 만들면 화면은 똑같이 나옵니다. 하지만 화면 낭독기에게는 아무 강조도 전달되지 않습니다. 개념03 섹션 3 에서 본 것과 똑같은 문제입니다.

실수 4 — 모든 글자를 span 으로 감쌈
<span>안</span><span>녕</span>

화면은 안녕 그대로입니다. 아무 문제 없어 보입니다. 하지만 손잡이가 필요 없는 곳에 손잡이를 단 것이라 소스만 길어지고 읽기 어려워집니다. span 은 꾸밀 계획이 있는 곳에만 붙이세요.

실수 5 — 인라인 요소에 가로폭을 주려 함
span { width: 300px; }

10단원에서 width 를 배우고 나면 꼭 한 번 해 보게 되는 일입니다. 아무 일도 일어나지 않습니다. 에러도 안 납니다. 인라인 요소는 글자만큼만 차지하기로 되어 있어서 폭 지시를 무시합니다. 해결법은 11단원의 display 에서 배웁니다. (위 코드는 CSS 입니다. 07단원부터 배우니 지금은 눈으로만 보세요)

── 정리 ──

1. span 은 아무 뜻도 없는 인라인 요소입니다. 나중에 CSS 로 꾸미려고 붙잡아 두는 손잡이입니다.

2. 블록 요소는 한 줄을 통째로 차지합니다. 글자가 짧아도 그렇습니다. h1~h6, p, hr, blockquote 가 블록입니다.

3. 인라인 요소는 글자만큼만 차지하고 흐름 안에 낍니다. span, strong, em, mark 등입니다.

4. 같은 글자라도 p 로 감싸면 824px, span 으로 감싸면 70px 을 차지합니다. 화면에는 안 보이는 차이입니다.

5. 인라인 안에 블록을 넣지 마세요. 줄이 쪼개집니다.

6. 블록과 인라인을 바꾸는 display 는 11단원에서 배웁니다. 지금은 바꾸지 않고 성질만 익힙니다.
