개념 02 — 순서 있는 목록

03단원 · 목록과 표

이 파일에서는 번호가 앞에 붙는 목록을 만듭니다. 태그는 ol 하나만 새로 배우고, 번호 모양을 바꾸는 속성 type, start, reversed, value 를 봅니다. 그리고 언제 ul 이고 언제 ol 인지 고르는 기준을 익힙니다.

섹션 1 — ol 로 순서 있는 목록 만들기

ul 을 ol 로 바꾸기만 하면 됩니다. 안쪽은 그대로 li 입니다.

실제 결과

  1. 물 550mL 를 끓입니다
  2. 면과 스프를 넣습니다
  3. 4분 30초 더 끓입니다

ol 은 ordered list 의 줄임말입니다. ul 의 u 는 unordered(순서 없는), ol 의 o 는 ordered(순서 있는) 입니다. 글자 하나 차이라 헷갈리기 쉬우니 o 는 순서(order) 로 외워 두세요.

✏️ 직접 해보기 1 — 위 목록의 맨 앞에 <li>냄비를 꺼냅니다</li> 를 끼워 넣어 보세요. 아래 항목들의 번호가 어떻게 되는지 확인하는 것이 목적입니다.

섹션 2 — 언제 ul 이고 언제 ol 인가

판단 기준은 하나입니다. 순서를 바꿔도 뜻이 그대로면 ul, 뜻이 망가지면 ol 입니다.

같은 세 줄을 ul 로 쓴 것 (준비물)

  • 연필
  • 지우개
  • 공책

순서가 뜻인 세 줄을 ol 로 쓴 것 (가입 절차)

  1. 약관에 동의합니다
  2. 아이디와 비밀번호를 정합니다
  3. 가입 완료 화면을 확인합니다

✏️ 직접 해보기 2 — "우리 반 달리기 1등 · 2등 · 3등" 목록을 만든다면 ul 과 ol 중 무엇을 써야 할까요? 직접 목록을 만들어 위 상자 아래에 넣어 보세요.

섹션 3 — type 으로 번호 모양 바꾸기

ol 에 type 속성을 주면 번호가 알파벳이나 로마자로 바뀝니다.

type="A" — 대문자 알파벳

  1. 첫 번째 항목
  2. 두 번째 항목

type="a" — 소문자 알파벳

  1. 첫 번째 항목
  2. 두 번째 항목

type="I" — 대문자 로마 숫자

  1. 첫 번째 항목
  2. 두 번째 항목
  3. 세 번째 항목
  4. 네 번째 항목

type="i" — 소문자 로마 숫자

  1. 첫 번째 항목
  2. 두 번째 항목
  3. 세 번째 항목
  4. 네 번째 항목

✏️ 직접 해보기 3 — 위 type="A" 목록의 값을 type="i" 로 바꿔 보세요. 그다음 type="Z" 처럼 없는 값도 한 번 넣어 보고 어떻게 되는지 확인하세요.

섹션 4 — start 로 시작 번호 바꾸기, reversed 로 거꾸로 세기

번호는 기본이 1 부터 오름차순입니다. 두 속성으로 시작점과 방향을 바꿀 수 있습니다.

start="5" — 5번부터 시작

  1. 다섯 번째 순서입니다
  2. 여섯 번째 순서입니다

reversed — 거꾸로 세기

  1. 동메달
  2. 은메달
  3. 금메달

reversed 는 번호만 거꾸로 붙입니다. 줄의 순서를 뒤집어 주지는 않습니다. 위 상자에서 "동메달" 이 여전히 첫 줄인 것을 보세요.

✏️ 직접 해보기 4 — 위 start="5" 목록에 type="A" 를 같이 넣어 보세요. (<ol type="A" start="5">) 어떤 글자부터 시작하는지 확인하세요.

섹션 5 — value 로 번호 하나만 바꾸기

value 는 li 에 붙이는 속성입니다. 그 항목의 번호를 직접 정합니다.

가운데 항목에만 value="10" 을 준 결과

  1. 하나
  2. 열
  3. 열하나

✏️ 직접 해보기 5 — 위 목록의 value="10" 을 value="100" 으로 바꿔 보세요. 마지막 줄 번호가 몇으로 바뀌는지 확인하세요.

섹션 6 — 자주 하는 실수

아래 실수들도 에러가 나지 않습니다. 번호가 이상하게 보이거나, 아무 일도 안 일어나거나 둘 중 하나입니다.

실수 1 — 번호를 손으로 씀
<ol> <li>1. 물을 끓입니다</li> <li>2. 면을 넣습니다</li> </ol>
  1. 1. 물을 끓입니다
  2. 2. 면을 넣습니다

번호가 두 번 나옵니다. 브라우저가 붙인 번호와 손으로 쓴 번호가 겹치기 때문입니다. 게다가 중간에 항목을 끼워 넣으면 손으로 쓴 번호는 자동으로 안 고쳐져서 앞뒤가 어긋납니다. 번호는 쓰지 마세요.

실수 2 — reversed 를 "false" 로 끄려고 함
<ol reversed="false">
  1. 첫 줄
  2. 둘째 줄
  3. 셋째 줄

false 라고 썼는데도 그대로 거꾸로 나옵니다. 불리언 속성은 값을 보지 않고 이름이 있는지만 보기 때문입니다. 끄려면 reversed 를 통째로 지우세요.

실수 3 — 없는 type 값을 씀
<ol type="가">
  1. 첫 줄
  2. 둘째 줄

아무 일도 일어나지 않고 그냥 숫자로 나옵니다. 경고도 없습니다. 브라우저는 모르는 값을 만나면 조용히 무시하고 기본값을 씁니다. "가. 나. 다." 같은 한글 번호는 type 으로는 만들 수 없습니다.

실수 4 — value 를 ol 에 붙임
<ol value="5"> <li>첫 줄</li> </ol>
  1. 첫 줄
  2. 둘째 줄

아무 일도 일어나지 않습니다. 1 부터 그대로 셉니다. value 는 li 에 붙는 속성입니다. ol 에서 시작 번호를 정하는 것은 start 입니다. 붙이는 자리를 바꿔 쓰면 조용히 무시되니 화면을 꼭 확인하세요.

실수 5 — 번호가 예뻐서 ol 을 고름
<ol> <li>아메리카노</li> <li>카페라떼</li> </ol>

메뉴판에는 순서가 없습니다. 화면은 멀쩡히 나오지만 뜻이 틀립니다. 화면 낭독기는 "1번 항목, 2번 항목" 이라고 읽어 줍니다. 듣는 사람은 순위나 순서가 있는 줄 알게 됩니다. 모양이 마음에 든다면 ul 로 두고 07단원부터 CSS 로 꾸미세요.

실수 6 — 안쪽 목록 번호가 이어질 거라 생각함
  1. 준비하기
    1. 냄비 꺼내기
    2. 물 받기
  2. 끓이기

안쪽 목록은 1 부터 다시 셉니다. 바깥의 1 을 이어받아 2, 3 이 되지 않습니다. "1.1", "1.2" 같은 번호를 원한다면 그것은 CSS 로 만드는 것이라 지금은 할 수 없습니다. 바깥 목록의 다음 항목은 안쪽 목록과 상관없이 2 로 이어집니다.

── 정리 ──

1. 순서가 뜻을 갖는 목록은 <ol> 로 감쌉니다. 항목은 그대로 <li> 입니다.

2. 번호는 손으로 쓰지 않습니다. 브라우저가 li 를 세어 붙여 줍니다.

3. 고르는 기준은 "순서를 바꿔도 뜻이 같은가" 입니다. 같으면 ul, 아니면 ol.

4. type 은 번호 모양(1 A a I i), start 는 시작 번호입니다.

5. reversed 는 값 없이 이름만 씁니다. "false" 라고 써도 켜집니다.

6. value 만 li 에 붙고, 그 항목부터 번호를 다시 셉니다.
