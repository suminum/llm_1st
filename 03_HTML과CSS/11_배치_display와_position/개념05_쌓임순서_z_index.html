개념 05 — 쌓임 순서와 z-index

11단원 · 배치 (display와 position)

이 파일의 데모는 전부 상자가 서로 겹쳐 있습니다. 어느 상자가 위에 보이는지, 그리고 그 이유가 무엇인지만 보면 됩니다. 마지막 섹션에서는 float 를 짧게 만나고 12단원으로 넘어갑니다.

섹션 1 — 나중에 쓴 것이 위에 그려집니다

아래 세 상자에는 z-index 가 하나도 없습니다. 그런데도 앞뒤 순서가 정해져 있습니다.

z-index 없이 겹친 상자 세 개

A · 먼저 씀
B · 가운데
C · 나중에 씀

✏️ 직접 해보기 1 — 위 HTML 에서 boxA 줄을 잘라 boxC 줄 아래로 옮겨 보세요. 분홍 상자가 맨 위로 올라옵니다. 확인했으면 되돌려 놓으세요.

섹션 2 — position 이 걸린 쪽이 위입니다

순서보다 더 센 규칙이 하나 있습니다. position 이 걸린 요소는 안 걸린 요소보다 무조건 위입니다.

먼저 쓴 상자에만 position: relative 를 걸었습니다

먼저 쓴 것 · position: relative
나중에 쓴 것 · position 없음

그래서 "왜 이 상자가 자꾸 위로 올라오지?" 싶을 때는 그 상자에 position 이 걸려 있는지부터 보세요. z-index 를 만지기 전에 확인할 일입니다.

✏️ 직접 해보기 2 — .ord-pos 에서 position: relative; 를 지워 보세요. 이제 순서 규칙만 남아서 하늘색 상자가 위로 올라옵니다. 확인했으면 되돌려 놓으세요.

섹션 3 — z-index 로 순서 정하기

z-index 는 숫자가 큰 쪽이 위입니다. 단, position 이 static 이면 안 먹습니다.

섹션 1 과 같은 상자에 z-index 만 준 결과

A · z-index 3
B · z-index 2
C · z-index 1

위 상자는 z-index: 999 인데 position 이 없습니다

z-index: 999 · position 없음
z-index 없음 · position: relative

✏️ 직접 해보기 3 — .zs-static 에 position: relative; 를 한 줄 넣어 보세요. 그 순간 분홍 상자가 위로 올라옵니다. 999 가 그제야 일을 합니다. 확인했으면 그 줄을 지우세요.

섹션 4 — 숫자는 형제끼리만 비교됩니다

z-index: 999 가 z-index: 2 에게 지는 일이 있습니다. 비교는 같은 부모 밑에서만 일어나기 때문입니다.

999 짜리 자식이 2 짜리 부모에게 집니다

부모 A · z-index 1
자식 · z-index 999
부모 B · z-index 2

✏️ 직접 해보기 4 — .ctx-a 의 z-index: 1; 을 z-index: 3; 으로 바꿔 보세요. 이번엔 부모 A 쪽 세계가 통째로 앞으로 나와서 분홍 자식이 부모 B 를 덮습니다. 확인했으면 되돌려 놓으세요.

섹션 5 — float 는 짧게만

float 는 요소를 한쪽으로 붙이고 나머지 글자가 그 옆으로 흐르게 하는 속성입니다.

글 옆에 그림을 흘리는 용도

사진 자리

크림 파스타는 우유와 생크림을 함께 써야 맛이 부드럽습니다. 버섯은 미리 센 불에 볶아 물기를 날려 두면 소스가 묽어지지 않습니다. 면은 봉지에 적힌 시간보다 1분 짧게 삶고, 소스에 넣어 마저 익힙니다. 마지막에 치즈를 갈아 올리면 완성입니다. 소금은 면을 삶는 물에 넉넉히 넣고, 소스에는 거의 넣지 않는 편이 간을 맞추기 쉽습니다. 접시를 미리 데워 두면 식탁에 올렸을 때 소스가 굳지 않습니다. 여기까지 읽는 동안 글줄이 왼쪽 네모를 피해 흐르다가, 네모가 끝나는 곳부터 왼쪽 끝까지 넓어졌습니다. 그것이 float 가 하는 일입니다.

✏️ 직접 해보기 5 — .ft-thumb 의 float 를 right 로 바꿔 보세요. 네모가 오른쪽으로 가고 글이 왼쪽으로 흐릅니다. 확인했으면 left 로 되돌려 놓으세요.

섹션 6 — 자주 하는 실수

겹침 문제는 화면만 봐서는 원인을 못 찾습니다. 아래 다섯 가지가 원인의 거의 전부입니다.

실수 1 — position 없이 z-index 만 줌
.top-layer { z-index: 9999; }

아무 일도 안 일어납니다. z-index 는 position 이 static 이 아닌 요소에만 먹습니다. 숫자를 더 키우는 것은 소용이 없습니다. position: relative; 한 줄을 같이 넣으세요.

이렇게 하세요
.top-layer { position: relative; z-index: 9999; }
실수 2 — 안 올라와서 숫자만 계속 키움
.popup { position: absolute; z-index: 99999999; }

부모가 이미 낮은 z-index 로 자기 세계를 만들어 놨다면 안에서 숫자를 아무리 키워도 소용이 없습니다. 고칠 곳은 그 요소가 아니라 부모입니다. 부모의 z-index 를 올리거나, 그 요소를 부모 밖으로 꺼내세요.

실수 3 — z-index 에 단위를 붙임
.card { position: relative; z-index: 10px; }

그 줄이 통째로 무시됩니다. z-index 는 길이가 아니라 순서를 나타내는 그냥 정수입니다. 10 이라고만 쓰세요. px 를 붙이는 습관 때문에 자주 나는 실수입니다.

실수 4 — float 로 화면을 좌우로 나눔
.left { float: left; width: 300px; } .right { float: left; width: 500px; }

모양은 나옵니다. 그런데 부모의 높이가 0 이 되어 다음 내용이 위로 겹쳐 올라옵니다. 옛날에는 이걸 고치는 요령이 여러 개 있었지만, 지금은 그냥 12단원 flex 를 쓰면 됩니다.

실수 5 — 배경색을 안 줘서 아래 글자가 비쳐 보임
.overlay { position: absolute; top: 0; left: 0; }

요소의 기본 배경은 투명입니다. 위에 제대로 올라가 있는데도 아래 글자가 그대로 비쳐서 글자끼리 겹쳐 읽을 수 없게 됩니다. "z-index 가 안 먹네" 가 아니라 배경색이 없는 것입니다. background 를 주면 해결됩니다(07단원).

── 정리 ──

1. 겹쳤을 때 기본 규칙은 나중에 쓴 것이 위입니다.

2. 그보다 센 규칙이 있습니다. position 이 걸린 것이 위입니다.

3. z-index 는 숫자가 큰 쪽이 위입니다. 단위 없는 정수로 씁니다.

4. position 이 static 이면 z-index 가 안 먹습니다.

5. 숫자는 같은 부모 밑 형제끼리만 비교됩니다. 안 올라오면 부모를 보세요.

6. float 는 글 옆에 그림을 흘릴 때만 씁니다. 배치는 12·13단원의 flex·grid 로 합니다.
