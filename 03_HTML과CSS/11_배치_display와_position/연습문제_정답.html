이 글은 왼쪽 네모를 피해 흐르게 될 문장입니다. 문장이 충분히 길어야 네모 옆을 지나 아래까지 이어지는 모습을 볼 수 있습니다. 신문 기사에서 사진 옆에 글이 붙어 있는 모양을 떠올리면 됩니다. 이 방식은 지금도 글 옆에 그림을 놓을 때 쓰입니다. 화면을 좌우로 나누는 일에는 쓰지 않습니다. 그림과 글이 서로 다른 상자에 들어 있는데도 한 덩어리처럼 보이는 것이 이 방식의 좋은 점입니다. 이쯤 오면 글줄이 네모 아래로 내려와 상자 왼쪽 끝에서 시작하는 것이 보입니다.

── 이 단원에서 꼭 남길 것 ──

1. 인라인에는 width·height·위아래 margin 이 안 먹습니다.

2. top·left·z-index 는 position 이 static 이면 안 먹습니다.

3. relative 는 자리를 남기고, absolute 는 자리를 없앱니다.

4. absolute 를 쓸 때는 부모에 relative 를 한 줄 겁니다.

5. 안 되는 CSS 는 에러가 아니라 침묵입니다. 화면을 눈으로 확인하세요.
