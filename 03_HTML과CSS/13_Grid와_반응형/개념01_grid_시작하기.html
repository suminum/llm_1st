개념 01 — grid 시작하기

13단원 · Grid 와 반응형

이 파일에서는 격자를 만드는 법을 배웁니다. display: grid 로 격자를 켜고, grid-template-columns 로 칸을 나누고, fr 로 비율을 정하고, gap 으로 사이를 띄웁니다. 마지막 섹션에서 flex 와 grid 중 무엇을 쓸지 판단하는 기준을 정리합니다.

섹션 7 — 자주 하는 실수

다시 강조합니다. CSS 는 틀려도 에러가 나지 않습니다. 틀린 줄은 그냥 없는 셈 치고 넘어갑니다. 그래서 "아무 일도 안 일어나는" 것이 가장 흔한 증상입니다.

실수 1 — display: grid 를 자식에 씀
.cell { display: grid; grid-template-columns: 1fr 1fr 1fr; }

무슨 일이 일어나나요: 칸들이 여전히 위아래로 쌓입니다. 자식 하나하나가 각자 "속이 3칸인 격자" 가 됐을 뿐, 자식들끼리는 아무 관계가 없습니다. 격자로 만들 대상은 자식들을 담고 있는 부모입니다.

이렇게 쓰세요
.step2-grid { display: grid; grid-template-columns: 1fr 1fr 1fr; }
실수 2 — 칸 개수만 씀
grid-template-columns: 3;

무슨 일이 일어나나요: 아무 일도 안 일어납니다. 칸이 나뉘지 않고 한 줄에 하나씩 그대로 쌓입니다. 이 속성은 칸의 개수가 아니라 각 칸의 크기를 하나씩 적는 자리입니다. 3칸으로 나누고 싶으면 1fr 1fr 1fr 처럼 값을 세 개 씁니다.

실수 3 — 값을 쉼표로 구분함
grid-template-columns: 1fr, 1fr, 1fr;

무슨 일이 일어나나요: 역시 아무 일도 안 일어납니다. 칸이 하나도 안 나뉩니다. CSS 에서 여러 값을 나열할 때는 띄어쓰기로 구분합니다. 쉼표를 쓰는 속성은 font-family 처럼 따로 정해져 있습니다.

실수 4 — fr 을 width 에 씀
.cell { width: 1fr; }

무슨 일이 일어나나요: 그 줄이 통째로 무시되고 폭이 안 바뀝니다. fr 은 grid-template-columns 와 grid-template-rows 안에서만 쓰는 단위입니다. 일반 폭을 비율로 주고 싶으면 % 를 씁니다(개념04).

실수 5 — 칸이 열 개수보다 많으면 잘린다고 생각함
grid-template-columns: 200px 200px 200px; (자식은 7개)

무슨 일이 일어나나요: 잘리지 않습니다. 아랫줄이 저절로 생겨서 7개가 3 + 3 + 1 로 놓입니다. "왜 갑자기 두 줄이 됐지?" 하고 당황하는 경우가 많은데, 격자가 정상 동작한 것입니다. 한 줄에 다 넣고 싶으면 열 개수를 자식 수에 맞춰 늘려야 합니다.

실수 6 — 간격을 자식의 margin 으로 냄
.cell { margin: 5px; }

무슨 일이 일어나나요: 칸 사이는 벌어지지만 격자 바깥쪽에도 5px 씩 여백이 생깁니다. 옆 요소와 줄이 안 맞아서 "왜 여기만 살짝 밀렸지?" 하게 됩니다. 게다가 칸 안쪽 폭이 margin 만큼 줄어들어 fr 계산도 어긋납니다. 격자 안쪽 간격은 gap 으로 내세요.

── 정리 ──

1. display: grid 는 부모에 씁니다. 자식은 저절로 칸이 됩니다.

2. grid-template-columns 에 적은 값의 개수 = 열의 개수, 값 하나가 칸 하나의 크기입니다. 구분은 띄어쓰기입니다.

3. fr 은 남는 공간을 나눠 가지는 비율입니다. 200px 1fr 처럼 고정과 섞어 쓸 수 있습니다.

4. gap 은 칸 사이에만 여백을 넣습니다. 바깥쪽에는 안 넣습니다.

5. grid-template-rows 로 줄 높이를 정합니다. 안 정하면 내용에 맞춰집니다.

6. 자식이 열 개수보다 많으면 아랫줄이 저절로 생깁니다. 잘리지 않습니다.

7. 한 줄이면 flex, 격자면 grid. 섞어 쓰는 것이 보통입니다.
