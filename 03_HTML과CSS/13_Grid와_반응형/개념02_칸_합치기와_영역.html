개념 02 — 칸 합치기와 영역

13단원 · Grid 와 반응형

이 파일에서는 한 상자가 여러 칸을 차지하게 만드는 법을 배웁니다. 먼저 격자 선 번호를 세는 법(여기에 함정이 있습니다), 다음에 span, 그다음에 이름으로 배치하는 grid-template-areas 입니다. 마지막으로 repeat() · minmax() · auto-fit 을 배웁니다.

섹션 1 — 격자에는 선 번호가 있습니다

grid 는 칸이 아니라 선에 번호를 붙입니다. 번호는 1부터 시작하고, 칸이 3개면 선은 4개입니다. 이 한 문장이 이 파일에서 가장 중요합니다.

1 2 3 4 ← 선 번호 +-----------+-----------+-----------+ | A | B | C | +-----------+-----------+-----------+ 칸 A = 1번 선 ~ 2번 선 칸 B = 2번 선 ~ 3번 선 칸 C = 3번 선 ~ 4번 선

실제 결과 — 칸 3개짜리 격자 (선은 4개)

A
B
C

칸이 3개면 선은 4개, 칸이 4개면 선은 5개입니다. 선의 개수는 항상 칸 개수보다 하나 많습니다.

✏️ 직접 해보기 1 — .line-grid 의 grid-template-columns 를 1fr 1fr 1fr 1fr 로 바꾸면 선은 몇 개가 될까요? 먼저 종이에 답을 적고 나서 값을 바꿔 확인하세요. (칸은 4개로 늘어나지만 상자는 3개뿐이라 마지막 칸은 비어 있습니다)

섹션 2 — grid-column 과 grid-row 로 칸을 합칩니다

시작 선 / 끝 선 을 빗금으로 이어서 씁니다. 이 두 속성은 격자 부모가 아니라 칸이 되는 자식에 씁니다.

섹션 3 — span 으로 "몇 칸" 이라고 쓰기

선 번호가 헷갈릴 때는 span 을 씁니다. 몇 칸을 차지할지 개수로 쓰는 방법입니다.

실제 결과 1 — grid-column: span 2 (두 칸)

실제 결과 2 — grid-column: 2 (한 칸, 자리만 이동)

숫자 하나 = 시작 선 번호. 두 칸을 원하면 span 2. 이 문장을 소리 내어 한 번 읽어 두세요. 나중에 반드시 한 번은 걸립니다.

✏️ 직접 해보기 3 — .trap-grid .just2 를 grid-column: span 2; 로 고쳐 보세요. 칸의 폭과 자리가 어떻게 달라지는지 두 상자를 번갈아 보며 확인하세요.

섹션 5 — grid-template-areas 로 이름 붙여 배치하기

칸마다 이름을 붙이고, 그 이름을 글자 그림처럼 늘어놓아 배치합니다. 선 번호를 한 번도 세지 않아도 됩니다.

실제 결과 — 이름으로 만든 페이지 뼈대

머리말 (head)
옆 메뉴 (side)
본문 (main)
바닥글 (foot)

여기서 쓴 header, aside, main, footer 는 06단원에서 배운 뜻이 있는 태그입니다. 격자와는 상관없지만, 이름이 맞으면 코드를 읽기가 훨씬 쉬워집니다.

✏️ 직접 해보기 5 — .area-page 의 grid-template-areas 를 아래처럼 바꿔서 옆 메뉴를 오른쪽으로 옮겨 보세요. "head head" "main side" "foot foot" (따옴표 세 덩어리를 각각 다른 줄에 쓰면 읽기 좋습니다)

✏️ 직접 해보기 6 — 브라우저 창의 오른쪽 끝을 마우스로 잡고 천천히 좁혀 보세요. 위 "카드 6개" 상자의 줄 수가 4칸 → 3칸 → 2칸 → 1칸으로 바뀝니다. 그다음 .auto-cards 의 180px 을 300px 로 바꾸고 같은 실험을 해 보세요. 칸 수가 더 빨리 줄어듭니다.

섹션 7 — 자주 하는 실수

아래 실수들은 전부 에러가 나지 않습니다. 그 줄이 조용히 무시되거나, 엉뚱한 자리에 칸이 놓일 뿐입니다.

실수 1 — 선 번호를 칸 번호로 셈
/* 칸 1 과 칸 2 를 합치고 싶어서 */ grid-column: 1 / 2;

무슨 일이 일어나나요: 칸이 안 넓어집니다. 그대로 한 칸입니다. 1번 선에서 2번 선까지는 칸 하나이기 때문입니다. 두 칸을 원하면 1 / 3 입니다. 선을 센다는 것을 잊으면 항상 하나씩 모자랍니다.

이렇게 쓰세요
grid-column: 1 / 3; /* 또는 */ grid-column: span 2;
실수 2 — grid-column: 2 를 "두 칸" 으로 씀
grid-column: 2;

무슨 일이 일어나나요: 폭은 그대로인데 칸이 오른쪽으로 한 칸 밀립니다. 그리고 왼쪽 첫 칸이 텅 비어서 "왜 여기가 비었지?" 하게 됩니다. 숫자 하나는 시작 선 번호입니다. 개수가 아닙니다. 섹션 3 의 두 상자를 다시 비교해 보세요.

실수 3 — grid-template-areas 의 줄마다 이름 개수가 다름
grid-template-areas: "head head" "side main main" "foot foot";

무슨 일이 일어나나요: 가운데 줄만 이름이 세 개라 격자가 네모가 아니게 되고, grid-template-areas 줄이 통째로 버려집니다. 그런데 자식들은 여전히 grid-area 로 이름을 부르고 있어서 갈 곳을 못 찾습니다. 그래서 네 덩어리가 전부 격자 오른쪽 아래 구석의 좁은 자리에 겹쳐 쌓입니다. 화면이 크게 무너지니 알아채기는 쉽습니다. 줄마다 개수를 세로로 줄 맞춰 쓰면 눈으로 바로 보입니다.

실수 4 — 이름을 서로 다르게 씀
grid-template-areas: "head head" "side main" "foot foot"; .area-side { grid-area: aside; } /* side 라고 써야 합니다 */

무슨 일이 일어나나요: 그 상자만 정해진 자리를 못 찾아 격자 오른쪽 아래에 새 줄과 새 칸이 생기고 거기에 혼자 놓입니다. 게다가 새 칸이 생긴 만큼 나머지 칸들의 폭도 같이 줄어듭니다. 이름이 하나만 어긋나도 화면 전체가 흔들립니다. 자리가 이상하면 먼저 이름 철자부터 맞춰 보세요.

실수 5 — repeat() 안에 쉼표를 안 씀
grid-template-columns: repeat(3 1fr);

무슨 일이 일어나나요: 아무 일도 안 일어납니다. 칸이 하나도 안 나뉘고 한 줄에 하나씩 쌓입니다. repeat() 괄호 안에서만 쉼표를 씁니다. 괄호 밖에서는 띄어쓰기라는 점이 헷갈리는 원인입니다.

실수 6 — minmax() 의 순서를 반대로 씀
grid-template-columns: repeat(auto-fit, minmax(1fr, 180px));

무슨 일이 일어나나요: 역시 아무 일도 안 일어납니다. 칸이 안 나뉩니다. minmax 는 최솟값이 먼저이고, 최솟값 자리에는 fr 을 쓸 수 없습니다. "최소 180px, 최대 1fr" 이므로 minmax(180px, 1fr) 입니다.

── 정리 ──

1. grid 는 선에 번호를 붙입니다. 1부터 시작하고, 칸 개수보다 하나 많습니다.

2. grid-column: 1 / 3 은 1번 선부터 3번 선까지, 즉 두 칸입니다.

3. grid-column: span 2 도 두 칸입니다. grid-column: 2 는 두 칸이 아니라 2번 선에서 시작하는 한 칸입니다.

4. grid-column 과 grid-row 는 자식에 씁니다.

5. repeat(개수, 값) 은 같은 값을 반복합니다. 괄호 안만 쉼표입니다.

6. grid-template-areas 로 이름을 붙여 배치하면 CSS 만 봐도 모양이 보입니다. 줄마다 이름 개수가 같아야 합니다.

7. repeat(auto-fit, minmax(180px, 1fr)) 은 미디어쿼리 없이도 칸 수가 저절로 바뀌는 격자를 만듭니다.
