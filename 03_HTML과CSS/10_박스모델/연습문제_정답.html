── 정리 ──

1. 값이 두 개면 위아래 / 좌우. padding 도 margin 도 같습니다.

2. 테두리가 안 보이면 style, 여백이 안 생기면 단위를 보세요.

3. 상자를 가운데 보내려면 width + margin: 0 auto 가 한 쌍입니다.

4. 크기를 정확히 맞추려면 box-sizing: border-box 를 켜세요.

5. 넘친 내용은 overflow: auto 가 대체로 정답입니다.
