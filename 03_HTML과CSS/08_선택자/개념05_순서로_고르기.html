개념 05 — 순서로 고르기

08단원 · 선택자

이 파일은 몇 번째인지로 고르는 법을 다룹니다. 상자마다 색칠된 줄이 몇 번째인지 세면서 읽으세요. 섹션 2 는 이 단원에서 가장 유명한 함정이니 천천히 보세요.

섹션 1 — :first-child 와 :last-child

부모의 첫 자식과 마지막 자식을 고릅니다.

실제 결과

  • 1등 — 아메리카노
  • 2등 — 카페라떼
  • 3등 — 딸기라떼
  • 4등 — 자몽차

항목이 하나뿐이면 그 하나가 첫 자식이자 마지막 자식입니다. 두 규칙이 다 걸립니다. 그때는 나중에 쓴 규칙의 색이 보입니다(개념06).

p:first-child 는 "p 중에서 첫 번째" 가 아닙니다. "첫 자식인데 그게 p 인 경우" 입니다.

섹션 3 — :nth-child (몇 번째인지 직접 세기)

괄호 안에 숫자·키워드·수식을 넣어 원하는 순서를 고릅니다.

숫자 하나 — li:nth-child(2)

  • 첫 번째 줄
  • 두 번째 줄
  • 세 번째 줄

키워드 — li:nth-child(odd)

  • 1번 줄
  • 2번 줄
  • 3번 줄
  • 4번 줄
  • 5번 줄

수식 — li:nth-child(3n+1)

  • 1번 줄
  • 2번 줄
  • 3번 줄
  • 4번 줄
  • 5번 줄
  • 6번 줄
  • 7번 줄

:nth-last-child(1) 처럼 뒤에서부터 세는 것도 있습니다. :last-child 와 같은 뜻입니다. 뒤에서 두 번째가 필요할 때 씁니다.

✏️ 직접 해보기 3 — 세 번째 상자의 3n+1 을 3n 으로 바꿔 보세요. 초록 줄이 어느 줄로 옮겨 가는지 세어 본 뒤 되돌려 놓으세요.

섹션 4 — :nth-child 와 :nth-of-type 의 차이

세는 대상이 다릅니다. 하나는 형제 전부를 세고, 하나는 같은 태그끼리만 셉니다.

p:nth-child(2) — 형제 전부를 셉니다

헷갈리면 이렇게 외우지 말고 세어 보세요. child 는 형제를 전부 세고, of-type 은 같은 태그만 셉니다. 자식이 전부 같은 태그라면 둘은 같은 결과입니다.

섹션 5 — :not() (빼고 고르기)

괄호 안에 쓴 것만 빼고 고릅니다.

실제 결과

  • 아메리카노
  • 카페라떼 (품절)
  • 딸기라떼
  • 자몽차 (품절)

:not() 은 괄호 안의 선택자 세기를 그대로 가져옵니다. li:not(.sold) 는 li.sold 와 세기가 같습니다. 이 이야기는 개념06 에서 다시 다룹니다.

섹션 6 — 자주 하는 실수

순서 선택자의 실수는 "한 개도 안 걸리거나 너무 많이 걸리는" 모양으로 나타납니다.

실수 1 — :first-child 를 "p 중 첫째" 로 읽음
.m1 p:first-child { color: crimson; }

섹션 2 의 그 함정입니다. 아래 상자의 첫 자식은 h3 입니다. 그래서 한 개도 안 걸립니다. "p 중 첫째" 를 원했다면 p:first-of-type 이라고 써야 합니다.

제목입니다

첫 문단인데 빨개지지 않습니다.

이렇게 쓰세요
.m1 p:first-of-type { color: crimson; }
실수 2 — 순서를 0 부터 센다고 생각함
.m2 li:nth-child(0) { background-color: #fff3a0; }

CSS 의 순서는 1 부터 셉니다. 0 번째 자식은 세상에 없으므로 아무 일도 안 일어납니다. 첫 줄을 고르려면 nth-child(1) 입니다.

  • 첫 줄인데 노래지지 않습니다.
  • 둘째 줄
실수 3 — n 앞뒤의 숫자를 바꿔 씀
.m3 li:nth-child(n+2) { background-color: #fff3a0; }

"두 칸마다 하나씩" 을 원하고 썼는데 두 번째부터 끝까지 전부 칠해집니다. 숫자를 n 앞에 쓰면 간격이고, n 뒤에 쓰면 시작점입니다. 두 칸마다는 2n 입니다.

  • 1번 줄
  • 2번 줄
  • 3번 줄
  • 4번 줄
실수 4 — 첫째가 하나뿐일 거라고 생각함
.m4 li:first-child { background-color: #fff3a0; }

:first-child 는 부모마다 셉니다. 목록이 두 개면 첫 줄도 두 개입니다. "한 개만 칠하고 싶다" 면 부모를 먼저 좁혀야 합니다.

  • 첫 번째 목록의 첫 줄
  • 첫 번째 목록의 둘째 줄
  • 두 번째 목록의 첫 줄
  • 두 번째 목록의 둘째 줄
실수 5 — 콜론 앞에 공백을 넣음
.m5 li :first-child { background-color: #fff3a0; }

공백이 자손 결합자라서 "li 안에 있는 첫 자식" 을 찾습니다. 아래 li 안에는 글자만 있고 요소가 없으니 한 개도 못 찾습니다. 개념04 에서 본 것과 똑같은 사고입니다. 콜론은 항상 붙여 씁니다.

  • 첫 줄인데 노래지지 않습니다.
  • 둘째 줄
이렇게 쓰세요
.m5 li:first-child { background-color: #fff3a0; }

── 정리 ──

1. :first-child 는 "첫 자식인데 그게 그 태그인 경우" 입니다. "그 태그 중 첫째" 가 아닙니다.

2. 제목 한 줄이 앞에 끼면 p:first-child 는 한 개도 안 걸립니다. 그때는 :first-of-type 을 쓰세요.

3. :nth-child() 는 1 부터 셉니다. odd even 2n 3n+1 을 넣을 수 있습니다.

4. n 앞의 숫자는 간격, n 뒤의 숫자는 시작점입니다. n+2 는 "두 번째부터 전부" 입니다.

5. :nth-child 는 형제 전부를, :nth-of-type 은 같은 태그끼리만 셉니다.

6. :not(...) 은 괄호 안에 해당하지 않는 것을 고릅니다.

7. 순서는 부모마다 다시 셉니다. 목록이 둘이면 첫째도 둘입니다.
