섹션 7 — 자주 하는 실수

아래 다섯 가지 모두 에러가 나지 않습니다. 화면도 멀쩡합니다. 그래서 알아채기가 어렵습니다.

실수 1 — main 을 여러 개 씀
<main> <h2>공지</h2> </main> <main> <h2>자료실</h2> </main>

화면은 아무 문제 없이 잘 나옵니다. 빨간 글씨도 안 뜹니다. 그런데 "본문" 이 둘이 되어 버립니다. 낭독기가 "본문으로 건너뛰기" 를 할 때 어디로 가야 할지 정할 수 없고, 검사 도구를 돌리면 "문서에 main 이 둘 이상" 이라는 경고가 나옵니다. 두 덩어리를 나누고 싶으면 main 안에서 <section> 두 개로 나누세요.

실수 2 — header 는 페이지에 하나뿐이라고 생각함
<article> <div> <h3>새 열람실이 열렸습니다</h3> <p>2026년 8월 11일</p> </div> </article>

"header 는 이미 위에 썼으니까 여기는 div 로" 라고 생각한 코드입니다. 이 글의 제목과 날짜가 그냥 글자로 취급됩니다. header 는 페이지의 맨 위가 아니라 그 구역의 머리말입니다. article 안에도, section 안에도 각각 하나씩 있어도 됩니다.

이렇게 쓰세요
<article> <header> <h3>새 열람실이 열렸습니다</h3> <p>2026년 8월 11일</p> </header> </article>
실수 3 — 링크만 보이면 nav 로 감쌈
<p>자세한 내용은 <nav><a href="안내.html">안내문</a></nav> 을 보세요.</p>

문장 속 링크 하나는 길 안내가 아니라 그냥 링크입니다. 이렇게 쓰면 낭독기의 구역 목록에 "내비게이션" 이 잔뜩 쌓여서 정작 진짜 메뉴를 못 찾게 됩니다. 이정표가 스무 개면 없는 것과 같습니다. 게다가 nav 는 블록이라 문장이 세 줄로 쪼개집니다.

실수 4 — footer 를 쓰면 화면 맨 아래로 갈 거라 기대함
<footer>연락처</footer> <p>아직 할 말이 남았습니다.</p>

footer 는 코드에 적힌 자리에 그대로 놓입니다. 아래로 내려가지도, 착 달라붙지도 않습니다. 섹션 5 의 상자에서 이미 확인했습니다. 화면 맨 아래에 붙이는 일은 11단원과 12단원에서 CSS 로 합니다.

실수 5 — 모든 페이지에 있는 것을 main 안에 넣음
<main> <nav>공지 · 자료실 · 오시는 길</nav> <h2>새 열람실</h2> </main>

메뉴는 모든 페이지에 똑같이 있습니다. 그러면 이 페이지만의 알맹이가 아닙니다. main 안에 넣으면 "이 페이지의 본문은 메뉴부터입니다" 라고 말한 셈이 되어, 건너뛰기를 해도 또 메뉴부터 듣게 됩니다. 공통으로 들어가는 것은 main 밖에 두세요.

── 정리 ──

1. 페이지 뼈대는 header · nav · main · footer 네 덩어리입니다.

2. 네 태그 모두 블록이고 화면을 바꾸지 않습니다. 위아래로 쌓일 뿐입니다.

3. <main> 은 페이지에 하나입니다. 옆 페이지에도 있는 것은 main 밖에 둡니다.

4. <main> 은 header · footer · nav · article · aside 안에 넣지 않습니다.

5. <header> 와 <footer> 는 여러 번 나와도 됩니다. 글 하나에도 붙습니다.

6. <nav> 는 주요 길 안내에만 씁니다. 문장 속 링크에는 쓰지 않습니다.

7. <footer> 는 화면 맨 아래로 내려가지 않습니다. 적힌 자리에 그대로 놓입니다.
