닫는 태그에는 절대 속성을 쓰지 않습니다. 써도 에러는 안 나지만, 브라우저가 통째로 버립니다.

섹션 6 — 자주 하는 실수

속성 관련 실수는 화면에 흔적이 거의 안 남습니다. 그래서 이 섹션이 특히 중요합니다.

실수 1 — 따옴표를 한쪽만 닫음
<p title="가게 안내>오늘도 문을 엽니다.</p> <p>그다음 문단입니다.</p>

닫는 따옴표가 없으니 브라우저는 다음 큰따옴표가 나올 때까지 전부 값으로 삼킵니다. 뒤에 큰따옴표가 아예 없으면 파일 끝까지 삼킵니다. 그러면 화면이 통째로 하얗게 빕니다. 에러 메시지는 없습니다. 화면이 갑자기 비면 따옴표부터 세어 보세요.

이렇게 쓰세요
<p title="가게 안내">오늘도 문을 엽니다.</p> <p>그다음 문단입니다.</p>
실수 2 — 등호를 빠뜨림
<p title "가게 안내">오늘도 문을 엽니다.</p>

이름과 값이 등호로 이어져 있지 않으니 하나의 속성으로 안 묶입니다. title 은 값이 없는 속성이 되고, 남은 글자는 공백에서 또 잘려 "가게 와 안내" 라는 이름이 이상한 속성 두 개가 됩니다. 글자는 멀쩡히 보이고 설명만 안 뜹니다.

실수 3 — 속성 이름에 오타
<p titel="가게 안내">오타가 난 속성입니다.</p>

title 이 titel 이 되었습니다. 그런 이름의 속성은 없으니 브라우저는 알아듣지 못하고 그냥 무시합니다. 아래 상자가 실제로 그렇게 쓴 결과입니다. 마우스를 올려도 아무것도 안 뜹니다.

오타 난 속성을 쓴 결과

오타가 난 속성입니다.

실수 4 — 닫는 태그에 속성을 씀
<p>오늘도 문을 엽니다.</p title="가게 안내">

섹션 2 에서 본 그대로입니다. 브라우저가 읽지도 않고 버립니다. 글자는 멀쩡하고 속성만 없던 일이 됩니다. 속성은 언제나 여는 태그 안에 씁니다.

실수 5 — 둥근 따옴표가 섞여 들어감
<p title=“가게 안내”>오늘도 문을 엽니다.</p>

워드나 한글 프로그램에서 쓴 글을 복사해 붙이면 곧은 따옴표가 둥근 따옴표로 자동으로 바뀌어 따라옵니다. 이건 코드에서 쓰는 따옴표가 아닙니다. 브라우저는 이것을 그냥 글자로 보고, 값을 감싸는 끈이 없으니 섹션 4 에서 본 것처럼 공백에서 값을 잘라 버립니다. 그래서 title 의 값은 “가게 까지만 들어갑니다. 모양이 비슷해서 눈으로 찾기가 아주 어렵습니다. 코드는 반드시 VS Code 같은 코드 편집기에서 치세요.

── 정리 ──

1. 속성은 태그에 정보를 덧붙이는 것이고, 모양은 언제나 이름="값" 입니다.

2. 속성은 여는 태그 안에만 씁니다. 닫는 태그에 쓰면 조용히 버려집니다.

3. 여러 개를 쓸 때는 공백으로 띄웁니다. 쉼표를 찍지 않습니다.

4. 값은 큰따옴표로 감쌉니다. 안 감싸면 공백에서 값이 잘립니다.

5. lang title id class 네 개를 이름만 익혀 둡니다.

6. 속성은 대부분 화면을 안 바꿉니다. 안 바뀐다고 틀린 것이 아닙니다.
