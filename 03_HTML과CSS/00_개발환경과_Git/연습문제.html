문제 3 — 저장소 만들고 첫 커밋 (개념02 섹션3)

기대 결과 (git log --oneline 을 쳤을 때) ae4c0c2 첫 페이지를 만들었습니다

문제 4 — 기호 읽기 (개념02 섹션4)

index.html 에 한 줄을 더 넣고 저장하세요. 그 다음 세 번 git status --short 를 칩니다.

① 고치기만 한 직후 ② git add . 를 한 뒤 ③ git commit 을 한 뒤 기대 결과 ① M index.html ② M index.html ③ (아무것도 안 나옵니다)

★ ①과 ②는 공백의 자리가 다릅니다. 잘 보세요.

문제 5 — 무엇이 바뀌었나 (개념02 섹션5)

기대 결과 .gitignore:1:.env .env

문제 9 — 가지 만들고 합치기 (개념05 섹션1·3)

인사말 이라는 가지를 만들고, 거기서 파일을 고쳐 커밋한 뒤, main 으로 돌아와 합치세요.

기대 결과 (합칠 때) Updating 6d15fca..73859b6 Fast-forward index.html | 1 + 1 file changed, 1 insertion(+)

문제 10 — 충돌 내고 풀기 ★ (개념05 섹션4·5)

일부러 충돌을 내고 손으로 푸세요.

① 가지 '가' 를 만들고 <h1> 의 글자를 '가나다' 로 고쳐 커밋 ② main 으로 돌아와 같은 줄을 '라마바' 로 고쳐 커밋 ③ main 에서 가지 '가' 를 합치기 ④ 충돌을 풀고 커밋 기대 결과 (③에서) Auto-merging index.html CONFLICT (content): Merge conflict in index.html Automatic merge failed; fix conflicts and then commit the result.

★ 다 하고 나면 git merge --abort 로 빠져나오는 것도 한 번 해 보세요.

문제 11 — [손으로] 못 찾는다고 합니다 (개념01)

같이 실습하는 사람이 이렇게 말합니다.

"Git 을 분명히 깔았는데 git --version 이 안 돼요. 다시 깔아 봤는데도 똑같아요."

(1) 무엇부터 시켜 보겠습니까?
(2) 왜 그것이 답이 됩니까?
(3) 그래도 안 되면 다음으로 무엇을 보겠습니까?

문제 12 — [손으로] 커밋했는데 안 들어갔습니다 (개념02)

파일을 고치고 git commit -m "고침" 을 쳤는데 이렇게 나옵니다.

nothing added to commit but untracked files present

(1) 무슨 뜻입니까?
(2) 무엇을 빠뜨렸습니까?
(3) git status --short 를 치면 무엇이 보이겠습니까?

문제 13 — [손으로] .env 를 올려 버렸습니다 ★ (개념03·04)

(1) .gitignore 에 .env 를 적었는데도 git status 에 계속 보입니다. 왜입니까?
(2) 어떻게 추적에서 뺍니까?
(3) ★ 그렇게 하면 문제가 다 끝납니까?
(4) 지금 제일 먼저 해야 할 일은 무엇입니까?

문제 14 — [손으로] push 가 거부됐습니다 (개념04)

git push 를 했더니 이렇게 나옵니다.

! [rejected] main -> main (fetch first) error: failed to push some refs to '…' hint: Updates were rejected because the remote contains work that you do not hint: have locally.

(1) 무슨 일이 있었던 것입니까?
(2) 무엇을 해야 합니까?

(4) ★ 이런 일이 덜 생기게 하려면 어떤 습관을 들여야 합니까?
