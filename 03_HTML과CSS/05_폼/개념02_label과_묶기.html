개념 02 — label 로 이름 붙이기, fieldset 으로 묶기

05단원 · 폼

이 파일은 읽기만 해서는 절반도 이해가 안 됩니다. 아래 상자마다 글자를 마우스로 눌러 보세요. 어떤 글자는 눌러도 아무 일이 없고, 어떤 글자는 누르는 순간 칸이 켜집니다. 그 차이를 만드는 것이 오늘 배우는 label 입니다.

섹션 1 — 글자와 칸을 연결한다는 것

먼저 연결이 없는 쪽을 보고, 무엇이 아쉬운지 느껴 봅시다.

연결이 없는 경우 — "이름" 글자를 눌러 보세요

이름

✏️ 직접 해보기 1 — 위 상자의 "이름" 글자를 다섯 번쯤 눌러 보세요. 칸에 커서가 안 들어가는 것을 확인하고, 이번에는 칸을 직접 눌러 보세요. 두 동작의 차이를 기억해 두면 다음 섹션이 훨씬 잘 보입니다.

섹션 2 — 연결 방법 1: for 와 id 를 같은 값으로

칸에 id 를 붙이고, label 의 for 에 똑같은 값을 적으면 둘이 연결됩니다.

연결한 경우 — "이름" 글자를 눌러 보세요

for 값과 id 값은 대소문자까지 똑같아야 합니다. for="userName" 과 id="username" 은 다른 값이라 연결되지 않습니다. 그런데 에러는 나지 않습니다. 그냥 조용히 안 눌립니다.

✏️ 직접 해보기 2 — 위 상자의 for="userName" 을 for="userNamee" 로 (끝에 e 하나 더) 바꿔 보세요. 새로고침하고 글자를 누르면 다시 아무 일도 안 일어납니다. 확인했으면 되돌려 놓으세요.

섹션 3 — 연결 방법 2: label 로 통째로 감싸기

label 안에 칸을 넣어 버리면 for 도 id 도 없이 연결됩니다.

감싼 경우 — "사는 곳" 글자를 눌러 보세요

label 은 글자처럼 옆으로 흐르는 인라인 요소입니다. 그래서 감싸도 줄이 새로 바뀌지 않습니다. 인라인은 02단원 개념04 에서 배운 그 성질입니다. 한 줄 안에서 옆으로 붙고 줄을 끊지 않습니다. 이 성질을 CSS 로 바꾸는 방법은 11단원에서 배웁니다.

✏️ 직접 해보기 3 — 위 상자 아래에 감싸기 방식으로 "이메일" 칸을 하나 더 만들어 보세요. <label>이메일 <input type="text" name="userMail" /></label> 를 <p> 로 감싸서 넣으면 새 줄에 나옵니다.

섹션 4 — 체크박스에서 차이가 가장 크게 느껴집니다

체크박스는 누를 곳이 13픽셀짜리 작은 네모뿐입니다. 연결해 두면 옆의 긴 글자 전체가 누를 곳이 됩니다.

연결 안 된 체크박스 — 글자를 눌러도 안 켜집니다

광고 메일을 받겠습니다

연결한 체크박스 — 글자 아무 데나 눌러 보세요

✏️ 직접 해보기 4 — 두 상자를 번갈아 눌러 보세요. 위 상자는 글자를 눌러도 안 켜지고, 아래 상자는 켜집니다. 그다음 위 상자의 코드를 <label> 로 감싸서 글자를 눌러도 켜지게 고쳐 보세요.

섹션 5 — fieldset 과 legend 로 여러 칸을 묶기

fieldset 은 관련 있는 칸들을 한 덩어리로 묶는 테두리이고, legend 는 그 덩어리의 제목입니다.

섹션 7 — 자주 하는 실수

label 관련 실수는 전부 "눌러 봐야 아는" 실수입니다. 화면만 봐서는 정상과 구별되지 않습니다.

실수 1 — for 값과 id 값이 다름
<label for="userAge">나이</label> <input id="userage" type="text" />

userAge 와 userage 는 다른 값입니다. A 하나 차이입니다. 글자를 눌러도 칸이 안 켜집니다. 에러도 경고도 없습니다. 아래에서 "나이" 를 눌러 보세요. 아무 일도 안 일어납니다.

이렇게 쓰세요
<label for="userAge">나이</label> <input id="userAge" type="text" />

바로 위 살아 있는 예에서는 이름을 userAge2 로 붙였습니다. 위 잘못된 예가 이미 userAge 를 쓰고 있어서 한 페이지 안에서 id 가 겹치면 안 되기 때문입니다(04단원 개념03). 이름만 다르고 원리는 위 코드와 똑같습니다.

실수 2 — 같은 id 를 두 칸에 붙임
<input id="pick" type="checkbox" /> <input id="pick" type="checkbox" />

id 는 페이지 안에서 하나뿐이어야 합니다. 두 개면 label 이 위쪽 하나만 찾아냅니다. 아래 칸은 이름표가 있는 줄 알았는데 사실 없는 상태가 됩니다. 칸을 복사해서 붙여 넣을 때 id 를 안 고쳐서 자주 생깁니다.

실수 3 — label 없이 글자만 옆에 씀
<p>전화번호 <input type="text" /></p>

제일 흔합니다. 화면은 완벽해 보입니다. 그런데 글자를 눌러도 반응이 없고, 화면 낭독기는 "편집창" 이라고만 읽습니다. 이름표가 될 글자는 <label> 로 감싸는 습관을 들이세요.

실수 4 — legend 를 fieldset 밖에 씀
<legend>기본 정보</legend> <fieldset> <p>이름 ...</p> </fieldset>

제목을 먼저 쓰고 상자를 여는 순서로 쓰면 이렇게 됩니다. legend 가 fieldset 안에 없으니 테두리와 아무 관계 없는 그냥 글자가 되어 상자 위에 덩그러니 놓입니다. 상자의 테두리는 끊긴 곳 없이 사각형으로 이어집니다.

이름

실수 5 — 감싸 놓고 for 에 엉뚱한 값을 씀
<label for="abc">약관 동의 <input id="agree" type="checkbox" /> </label>

감싸기만 했으면 잘 됐을 텐데, for="abc" 를 덧붙이는 바람에 label 이 abc 라는 없는 칸을 찾으러 갑니다. 그래서 안 눌립니다. 감쌌으면 for 를 쓰지 말고, for 를 쓸 거면 감싸지 마세요.

── 정리 ──

1. <label> 은 글자와 입력칸이 한 쌍이라는 것을 코드에 적는 태그입니다.

2. 연결하면 글자를 눌러도 칸이 켜집니다. 이것이 눈에 보이는 증거입니다.

3. 연결 방법은 for 와 id 를 같은 값으로 맞추거나, 감싸는 것입니다.

4. id 는 페이지 안에서 하나뿐이어야 하고, name 과는 하는 일이 다릅니다.

5. <fieldset> 으로 묶고 <legend> 로 제목을 답니다.

6. 이름표는 label 로, 예시는 placeholder 로. 역할을 섞지 마세요.
