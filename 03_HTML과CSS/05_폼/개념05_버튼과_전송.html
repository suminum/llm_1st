개념 05 — 버튼, 그리고 값이 어디로 가는가

05단원 · 폼

이 파일에는 눌러도 되는 버튼과 지금은 누르지 말아야 하는 버튼이 섞여 있습니다. 상자마다 어느 쪽인지 적어 두었으니 읽고 누르세요. 누르지 말라는 버튼을 눌러도 큰일이 나지는 않습니다. 페이지가 새로고침될 뿐입니다.

섹션 1 — button 태그의 생김새

<button> 은 태그 사이에 넣은 글자가 버튼에 그대로 적히는 태그입니다.

실제 결과 — 눌러도 안전합니다

버튼의 크기는 안에 적힌 글자 길이에 맞춰 저절로 정해집니다. 그래서 글자가 긴 버튼이 더 넓습니다. 크기와 색을 직접 정하는 것은 09~10단원입니다.

✏️ 직접 해보기 1 — 위 상자에 버튼을 하나 더 만들어 여러분이 원하는 글자를 넣어 보세요. type="button" 을 꼭 같이 쓰세요. 이유는 바로 다음 섹션에서 나옵니다.

섹션 2 — type 을 안 쓰면 기본이 submit 입니다

type 을 빠뜨린 버튼은 누르는 순간 폼을 제출합니다. 폼이 제출되면 페이지가 넘어가고 쳐 넣은 값이 전부 사라집니다.

실제 결과 — 이 버튼은 지금 누르지 마세요

위 버튼을 눌러도 컴퓨터가 망가지지는 않습니다. 주소창 끝에 ?userName= 이 붙으면서 페이지가 새로고침될 뿐입니다. 원래대로 돌아오려면 주소창의 물음표 뒷부분을 지우고 엔터를 치거나, 파일을 다시 열면 됩니다.

✏️ 직접 해보기 2 — 위 버튼에 type="button" 을 붙여 보세요. 새로고침한 뒤 칸에 글자를 쳐 넣고 버튼을 눌러 보면 이번에는 아무 일도 안 일어나고 쳐 넣은 값도 그대로 남아 있습니다.

섹션 3 — type="button": 아무 일도 안 하는 버튼

type="button" 은 누르면 정말 아무 일도 안 일어나는 버튼입니다.

실제 결과 — 마음껏 눌러 보세요

✏️ 직접 해보기 3 — 위 칸에 글자를 쳐 넣고 버튼을 다섯 번쯤 눌러 보세요. 글자가 그대로 남아 있는 것을 확인하세요. 섹션 2 의 버튼과 정반대입니다.

섹션 4 — type="reset": 처음 상태로 되돌리기

type="reset" 은 빈 칸으로 만드는 것이 아니라 페이지를 처음 열었을 때의 값으로 되돌립니다.

실제 결과 — 값을 바꾼 뒤 되돌리기를 눌러 보세요

✏️ 직접 해보기 4 — 이름 칸의 value="김민준" 을 지우고 새로고침한 뒤 다시 해 보세요. 이번에는 되돌리기를 누르면 칸이 빈 칸이 됩니다. "처음 상태" 가 무엇이냐에 따라 결과가 달라진다는 뜻입니다.

섹션 5 — input type="submit" 과 button 의 차이

버튼을 만드는 방법이 하나 더 있습니다. <input type="submit" /> 입니다. 글자를 넣는 자리가 다릅니다.

실제 결과 — 폼 밖에 있어서 눌러도 안전합니다

버튼이 form 밖에 있으면 제출 기능이 동작하지 않습니다. 위 네 개가 그렇습니다. 보내야 하는 버튼은 반드시 <form> 안에 넣으세요.

✏️ 직접 해보기 5 — 위 상자의 id="defaultSubmit" 버튼에 value="신청하기" 를 넣어 보세요. 새로고침하면 "제출" 이라고 적혀 있던 버튼의 글자가 "신청하기" 로 바뀌고 버튼도 그만큼 넓어집니다.

섹션 6 — form 의 action 과 method (개념만)

action 은 어디로 보낼지, method 는 어떻게 보낼지입니다. 뜻만 알아 두세요.

실제 결과 — 이 버튼도 지금은 누르지 마세요

✏️ 직접 해보기 6 — 위 폼의 method="get" 을 지우고 새로고침해 보세요. 화면이 하나도 안 바뀝니다. method 를 안 쓰면 원래 get 이기 때문입니다. 확인했으면 되돌려 놓으세요.

섹션 7 — 자주 하는 실수

버튼의 실수는 누르는 순간에만 드러납니다. 화면을 아무리 들여다봐도 안 보입니다.

실수 1 — 버튼에 type 을 안 씀
<form> <button>한 줄 더 추가</button> </form>

제출과 아무 상관 없는 버튼인데 누르는 순간 폼이 제출됩니다. 화면이 새로고침되고 사용자가 채운 값이 전부 날아갑니다. 이 단원에서 가장 자주 나는 사고입니다. type 을 안 쓰면 기본이 submit 이라는 것을 잊지 마세요.

이렇게 쓰세요
<form> <button type="button">한 줄 더 추가</button> </form>
실수 2 — button 의 글자를 value 에 씀
<button type="button" value="보내기"></button>

input 버릇대로 쓴 것입니다. button 의 글자는 태그 사이에 넣어야 합니다. value 에 쓴 글자는 화면에 안 나옵니다. 글자가 하나도 없는 납작한 버튼이 나옵니다. 아래에서 직접 보세요. 처음에는 버튼이 있는지도 잘 안 보입니다.

이렇게 쓰세요
<button type="button">보내기</button>

실수 3 — input type="submit" 안에 글자를 넣음
<input type="submit">보내기</input>

input 은 빈 태그라 안에 글자를 못 넣습니다. 그래서 이렇게 됩니다. 버튼에는 브라우저 기본 글자인 "제출" 이 나오고, 우리가 쓴 "보내기" 는 버튼 밖에 그냥 글자로 남습니다. 글자는 value 에 넣어야 합니다.

보내기

실수 4 — reset 이 칸을 비워 준다고 생각함
<input type="text" name="city" value="부산" /> <button type="reset">지우기</button>

버튼에 "지우기" 라고 적어 놓으니 사용자는 빈 칸이 될 것이라고 기대합니다. 그런데 누르면 "부산" 이 다시 나타납니다. reset 은 비우는 것이 아니라 처음 값으로 되돌리는 것이기 때문입니다. 버튼 글자를 "되돌리기" 나 "처음 상태로" 라고 적어야 오해가 없습니다.

실수 5 — 제출 버튼을 form 밖에 둠
<form> <input type="text" name="userName" /> </form> <button type="submit">보내기</button>

닫는 태그 위치를 잘못 잡아서 버튼이 폼 밖으로 밀려난 경우입니다. 버튼은 멀쩡히 보이는데 눌러도 아무 일이 안 일어납니다. 제출할 폼을 못 찾기 때문입니다. 들여쓰기를 맞춰 두면 이런 실수가 눈에 띕니다.

── 정리 ──

1. <button> 은 태그 사이에 넣은 글자가 버튼에 적힙니다. 태그도 넣을 수 있습니다.

2. type 을 안 쓰면 기본이 submit 입니다. 누르면 제출됩니다.

3. type="button" 은 아무 일도 안 합니다. 제출과 무관한 버튼에 씁니다.

4. type="reset" 은 비우는 것이 아니라 처음 값으로 되돌립니다.

5. <input type="submit" value="보내기" /> 는 글자를 value 에 넣습니다.

6. action 은 보낼 주소, method 는 보내는 방식(get/post)입니다.

7. 제출 버튼은 반드시 <form> 안에 있어야 동작합니다.
