개념 03 — type 을 바꾸면 칸이 달라집니다

05단원 · 폼

이 파일에는 그중 열세 가지가 살아 있는 채로 들어 있습니다. (text 는 개념01 에서 이미 써 봤으니 여기서는 뺐습니다) 하나하나 직접 눌러 보고 값을 넣어 보세요. 칸이 작고 밋밋한 것은 정상입니다. 꾸미는 것은 09~10단원입니다. 섹션 4 의 라디오 버튼은 특히 천천히 보세요.

섹션 1 — 글자를 받는 칸들: password, email, search, tel, url

이 다섯은 겉모습이 text 와 거의 같습니다. 다른 것은 "가려 주느냐" 와 "이 값이 무슨 뜻이냐" 입니다.

실제 결과 — 다섯 칸에 모두 글자를 쳐 보세요

type="password" 는 어깨 너머로 훔쳐보는 것만 막습니다. 네트워크로 오갈 때 안전하게 만드는 것은 완전히 다른 이야기이고, HTML 이 하는 일이 아닙니다. 이 자료의 범위 밖이니 지금은 그런 게 있다는 것만 아세요.

✏️ 직접 해보기 1 — 비밀번호 칸의 type="password" 를 type="text" 로 바꿔 보세요. 새로고침한 뒤 글자를 치면 점 대신 글자가 그대로 보입니다. 확인했으면 되돌려 놓으세요.

섹션 2 — 자판 말고 다른 방법으로 넣는 칸: number, date, range, color

여기서부터는 생김새가 확실히 달라집니다. 화살표, 달력, 미끄럼 막대, 색 상자가 나옵니다.

실제 결과 — 화살표를 누르고, 막대를 끌어 보세요

type="number" 는 숫자처럼 생긴 것을 받는 칸입니다. 전화번호나 우편번호에 쓰면 안 됩니다. 앞자리 0 이 사라지고, 화살표로 전화번호를 1씩 올리는 이상한 일이 생깁니다. 그런 값은 type="tel" 이나 type="text" 를 쓰세요.

✏️ 직접 해보기 2 — 좋아하는 색 칸에 value="#ff0000" 을 넣어 보세요. 새로고침하면 까맣던 네모가 빨갛게 바뀝니다. 그다음 우물 정 자만 빼서 value="ff0000" 으로 바꿔 보면 다시 까맣게 돌아갑니다.

섹션 3 — checkbox: 여러 개를 골라도 되는 칸

네모를 눌러 켜고 끕니다. 몇 개를 켜든 상관없습니다. 각각이 따로 노는 스위치입니다.

실제 결과 — 원하는 만큼 켜 보세요

추가 재료 (여러 개 고를 수 있습니다)

위에서 세 칸의 name 이 모두 topping 으로 같습니다. 체크박스는 이름이 같아도 서로 간섭하지 않습니다. 켜진 것들의 값이 각각 따로 보내질 뿐입니다. (라디오 버튼은 정반대입니다. 바로 다음 섹션입니다)

✏️ 직접 해보기 3 — 베이컨 칸에 checked 를 붙여 보세요. 새로고침하면 치즈와 베이컨 두 개가 켜진 채로 화면이 열립니다. 두 개가 동시에 켜지는 것이 체크박스의 성질입니다.

섹션 4 — radio: 하나만 고르는 칸 (가장 중요한 섹션)

라디오 버튼은 name 이 같은 것끼리 한 무리가 됩니다. 한 무리 안에서는 하나만 켜집니다.

잘못된 예 — name 을 하나씩 다르게 지음
<input type="radio" name="size1" value="s" /> 작은 것 <input type="radio" name="size2" value="m" /> 중간 것 <input type="radio" name="size3" value="l" /> 큰 것

이름이 셋 다 다르니 서로 남남입니다. 세 개를 차례로 눌러 보세요. 셋 다 켜지고 한 번 켜지면 꺼지지도 않습니다. "하나만 고르게 하려고 라디오를 썼는데 다 골라진다" 가 바로 이 상황입니다.

크기를 골라 주세요

올바른 예 — name 을 전부 같게
<input type="radio" name="size" value="s" /> 작은 것 <input type="radio" name="size" value="m" /> 중간 것 <input type="radio" name="size" value="l" /> 큰 것

이름이 size 로 같으니 한 무리입니다. 하나를 누르면 먼저 켜져 있던 것이 저절로 꺼집니다. 보내지는 값은 켜진 하나뿐입니다. 예를 들어 size=m 하나만 갑니다.

크기를 골라 주세요

name 이 같은 라디오는 화면에서 멀리 떨어져 있어도 한 무리입니다. 반대로 나란히 붙어 있어도 name 이 다르면 남남입니다. 판단 기준은 위치가 아니라 name 하나뿐이라는 것을 기억하세요.

✏️ 직접 해보기 4 — 잘못된 예의 name="size1", name="size2", name="size3" 을 전부 name="sizeFix" 로 고쳐 보세요. 새로고침한 뒤 눌러 보면 이제 하나만 켜집니다. 고치기 전과 후를 꼭 둘 다 눌러 보세요.

섹션 5 — file 과 hidden

file 은 컴퓨터의 파일을 고르는 칸이고, hidden 은 화면에 아예 안 보이는 칸입니다.

✏️ 직접 해보기 5 — id="hiddenField" 칸의 type="hidden" 을 type="text" 로 바꿔 보세요. 새로고침하면 숨어 있던 칸이 나타나고 안에 notice-12 가 들어 있습니다. 값은 원래부터 거기 있었다는 것을 확인하는 것이 목적입니다.

섹션 6 — 자주 하는 실수

여기 있는 다섯 가지는 전부 화면이 멀쩡하게 나옵니다. 눌러 보거나 값을 보내 봐야 알 수 있습니다.

실수 1 — 라디오 버튼의 name 을 하나씩 다르게 지음
<input type="radio" name="pay1" value="card" /> 카드 <input type="radio" name="pay2" value="cash" /> 현금

이 단원 최고의 함정입니다. 동그라미 두 개가 동시에 켜집니다. 한 번 켜지면 꺼지지도 않아서 사용자가 고칠 방법이 없습니다. 라디오를 쓸 때는 name 을 먼저 정하고 그 이름을 복사해 붙이세요.

이렇게 쓰세요
<input type="radio" name="pay" value="card" /> 카드 <input type="radio" name="pay" value="cash" /> 현금
실수 2 — 체크박스에 value 를 안 씀
<input type="checkbox" name="topping" /> 치즈 <input type="checkbox" name="topping" /> 베이컨

화면은 완벽합니다. 켜고 끄기도 잘 됩니다. 그런데 켜서 보내면 받는 쪽에 topping=on 만 두 번 도착합니다. 치즈인지 베이컨인지 알 수 없습니다. 옆의 글자는 값이 아닙니다.

실수 3 — checked="false" 로 끄려고 함
<input type="checkbox" name="agree" checked="false" /> 동의

켜집니다. checked 는 값이 무엇이든 상관없이 "적혀 있으면 켬" 이기 때문입니다. 끄고 싶으면 checked 를 통째로 지우세요. 아래에서 직접 확인하세요. 왼쪽 네모가 처음부터 켜져 있습니다.

실수 4 — 날짜 칸의 value 를 우리 식으로 씀
<input type="date" value="2026/03/15" />

빈 칸이 됩니다. 날짜 칸이 알아듣는 모양은 2026-03-15 하나뿐입니다. 빗금이나 한글이 섞이면 조용히 버려집니다. 아래 두 칸을 비교해 보세요. 왼쪽은 비어 있고 오른쪽에는 날짜가 들어 있습니다.

잘못된 값 올바른 값

실수 5 — type 이름에 오타를 냄
<input type="chekbox" name="agree" /> 동의

모르는 type 은 전부 text 로 그려집니다. 네모 체크박스가 나와야 할 자리에 글자 칸이 덩그러니 나옵니다. "왜 체크박스가 안 나오지?" 싶으면 type 철자부터 확인하세요.

동의

── 정리 ──

1. 태그는 input 하나이고 type 값만 바꾸면 칸의 종류가 바뀝니다.

2. password 는 가려 줄 뿐 안전하게 만들어 주지는 않습니다.

3. checkbox 는 여러 개, radio 는 하나만 고릅니다.

4. 라디오는 name 이 같아야 한 무리가 됩니다. 다르면 다 켜집니다.

5. checkbox 와 radio 의 value 는 켜졌을 때 보낼 값입니다.

6. checked 는 적혀 있기만 하면 켜집니다. 끄려면 통째로 지웁니다.

7. hidden 은 안 보이지만 값은 갑니다. 비밀 값을 넣으면 안 됩니다.
