개념 03 — 페이지 안 이동

04단원 · 링크와 이미지

이 파일의 링크는 다른 파일로 가지 않습니다. 같은 문서 안에서 화면만 움직입니다. 아래 목차를 눌러 보고, 주소창 끝에 # 이 붙는 것도 같이 확인하세요.

섹션 1 — id 로 이름표 붙이기

도착하고 싶은 자리에 먼저 id 라는 이름표를 붙입니다.

실제 결과 (id 를 붙여도 화면은 그대로입니다)

이 줄에는 id 가 없습니다. 두 줄이 똑같이 생겼습니다.

✏️ 직접 해보기 1 — 위 상자의 두 번째 문단에도 id="secondBox" 를 붙여 보세요. 저장하고 새로고침해도 화면이 하나도 안 바뀌는 것을 확인하세요.

섹션 2 — # 으로 그 자리로 점프

href="#이름" 처럼 우물 정(#) 뒤에 id 이름을 적으면 그 자리로 갑니다.

섹션 4 — mailto 로 메일 보내기

href="mailto:주소" 를 쓰면 누를 때 메일 쓰기 창이 열립니다.

제목과 내용을 미리 채워서 보내기

메일 주소를 이렇게 페이지에 그대로 적어 두면 광고 메일을 보내는 프로그램이 주소를 긁어 갑니다. 실제 사이트에서는 05단원에서 배울 문의 폼을 쓰는 경우가 더 많습니다. mailto 는 간단한 개인 페이지에서 주로 씁니다.

맨 위로 가기

✏️ 직접 해보기 5 — 위 전화번호를 031-987-6543 으로 바꾸세요. href 안의 번호와 화면에 보이는 글자를 둘 다 고쳐야 합니다.

섹션 6 — 자주 하는 실수

문서 안 이동은 안 되어도 아무 표시가 없습니다. 눌러도 그냥 가만히 있습니다.

실수 1 — href 에서 # 을 빠뜨림
<a href="recipeStep">만드는 방법으로</a>

# 이 없으면 브라우저는 이것을 파일 이름으로 읽습니다. 그래서 같은 폴더에서 recipeStep 이라는 파일을 찾다가 실패하고, 파일을 찾을 수 없다는 하얀 화면이 뜹니다.

만드는 방법으로 (눌러 보세요)

이렇게 쓰세요
<a href="#recipeStep">만드는 방법으로</a>
실수 2 — id 값에 # 을 붙임
<h3 id="#recipeStep">만드는 방법</h3>

# 은 부르는 쪽에만 붙입니다. 이름표 자체에 # 을 넣으면 이름이 #recipeStep 이 되어 버려서 href="#recipeStep" 이 찾는 recipeStep 과 다른 이름이 됩니다. 눌러도 아무 일이 일어나지 않습니다.

실수 3 — 대소문자가 다름
<h3 id="recipeStep"> 인데 <a href="#recipestep"> 이라고 씀

S 하나가 소문자로 바뀌었을 뿐인데 완전히 다른 이름입니다. 눌러도 화면이 그대로입니다. 에러도 없고 표시도 없어서 찾기 어렵습니다. 이름표를 만들 때 복사해서 붙여 넣는 습관을 들이면 이 실수가 사라집니다.

만드는 방법으로 (눌러도 안 움직입니다)

실수 4 — 같은 id 를 두 군데에 붙임
<p id="notice">첫 번째</p> <p id="notice">두 번째</p>

브라우저는 첫 번째 것만 찾아갑니다. 두 번째는 영원히 못 갑니다. 역시 에러는 나지 않습니다. id 는 한 문서에 하나뿐이어야 한다는 규칙을 지키세요. 여러 요소를 한꺼번에 묶고 싶을 때 쓰는 것은 08단원에서 배울 class 입니다.

실수 5 — mailto 뒤에 // 를 붙임
<a href="mailto://hong@example.com">메일 보내기</a>

https:// 가 눈에 익어서 습관처럼 // 를 붙이는 실수입니다. 메일 창이 열리기는 하는데 받는 사람 칸이 이상하게 채워집니다. mailto: 뒤에는 곧바로 메일 주소만 씁니다.

실수 6 — id 이름에 띄어쓰기를 넣음
<h3 id="recipe step">만드는 방법</h3>

이름 안에 띄어쓰기가 있으면 href="#recipe step" 으로 부를 수 없습니다. 주소에서 띄어쓰기는 값의 끝으로 취급되기 때문입니다. 눌러도 아무 일이 일어나지 않습니다. 낱말을 이어 붙일 때는 recipeStep 처럼 붙여 쓰세요.

── 정리 ──

1. 도착지에 id="이름" 을 붙이고, href="#이름" 으로 부릅니다.

2. # 은 부르는 쪽에만 붙입니다. id 값에는 붙이지 않습니다.

3. id 는 한 문서 안에서 단 하나여야 하고, 대소문자를 구분합니다.

4. href="#" 은 문서 맨 위로 갑니다.

5. mailto:주소 는 메일 쓰기 창, tel:번호 는 전화 걸기입니다.

6. mailto 와 tel 뒤에는 // 를 붙이지 않습니다.

7. 문서 안 이동이 안 될 때는 에러가 나지 않고 그냥 가만히 있습니다.
