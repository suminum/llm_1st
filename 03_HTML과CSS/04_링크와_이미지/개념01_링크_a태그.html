섹션 6 — 자주 하는 실수

다시 강조합니다. 아래 실수는 전부 에러가 나지 않습니다. 링크가 조용히 안 될 뿐입니다.

실수 1 — href 를 빠뜨림
<a>개념 02 로 가기</a>

파란색도 밑줄도 사라지고, 눌러도 아무 일이 없습니다. a 태그는 있지만 갈 곳이 없어서 브라우저가 링크로 취급하지 않습니다. "글자가 검은색 그대로면 href 를 확인하라" 로 기억하세요.

실수 2 — 파일 이름을 잘못 씀
<a href="개념2_경로.html">개념 02 로 가기</a>

진짜 파일 이름은 개념02_경로.html 인데 개념2 라고 썼습니다. 링크는 파랗게 잘 보입니다. 그런데 누르면 "파일을 찾을 수 없습니다" 라는 하얀 화면이 뜹니다. 글자가 한 자만 달라도 다른 파일입니다.

개념 02 로 가기 (눌러 보세요)

실수 3 — 값을 따옴표로 감싸지 않음
<a href=내 파일.html>눌러 보기</a>

브라우저는 띄어쓰기가 나오는 순간 값이 끝났다고 판단합니다. 그래서 목적지가 내 가 되어 버리고, 뒤의 파일.html 은 정체 불명의 속성으로 취급됩니다. 값은 항상 따옴표로 감싸세요.

눌러 보기

실수 4 — target="blank" 라고 씀
<a href="개념02_경로.html" target="blank">새 탭에서 열기</a>

앞의 밑줄(_) 이 빠졌습니다. 그래도 에러는 나지 않고 새 창이 열립니다. 그런데 이 값은 "blank 라는 이름의 창" 이라는 뜻이라, 다른 링크를 또 누르면 새 탭이 생기지 않고 아까 그 창의 내용만 바뀝니다. 반드시 _blank 로 쓰세요.

실수 5 — 링크 안에 링크를 넣음
<a href="첫째.html">바깥 <a href="둘째.html">안쪽</a></a>

브라우저가 안쪽 a 를 밖으로 끄집어내서 링크 두 개로 쪼개 버립니다. 겉보기에는 멀쩡해 보여서 알아채기 어렵습니다. 링크 안에는 링크를 넣지 마세요. (그림을 링크로 만드는 방법은 개념04 에서 배웁니다)

── 정리 ──

1. 링크는 <a href="목적지">링크 글자</a> 로 만듭니다.

2. href 는 화면에 보이지 않고, 사이에 낀 글자만 보입니다.

3. 링크 글자는 그것만 읽어도 어디로 가는지 알 수 있게 씁니다. "여기를 클릭" 금지.

4. target="_blank" 는 새 탭. 함께 rel="noopener" 를 붙입니다.

5. title 은 마우스를 올렸을 때 뜨는 덤 설명입니다. 중요한 말은 넣지 않습니다.

6. download 를 붙이면 열리는 대신 파일로 저장됩니다.

7. href 가 없으면 파란색도 밑줄도 없고 눌리지도 않습니다.
