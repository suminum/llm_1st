개념 04 — 이미지 img

04단원 · 링크와 이미지

이 파일에서는 그림을 페이지에 거는 방법을 배웁니다. 아래에 보이는 그림은 전부 이미지 폴더에 들어 있는 진짜 파일입니다. 인터넷 없이도 보입니다. 그림 하나는 일부러 안 보이게 만들어 두었습니다.

섹션 1 — img 태그와 src

그림은 <img src="경로" alt="설명" /> 한 줄로 겁니다. 닫는 태그가 없습니다.

실제 결과

<img>, <img/>, <img /> 는 셋 다 똑같이 동작합니다. 이 자료에서는 빈 태그라는 것이 눈에 잘 띄도록 <img ... /> 로 통일합니다. 01단원 개념02 의 <br /> 와 같은 약속입니다.

섹션 2 — alt 는 왜 반드시 써야 하나

alt 는 그림을 볼 수 없을 때 대신 읽는 글입니다. 빼먹으면 그림이 아예 없는 것과 같아집니다.

위는 잘 보이는 그림, 아래는 일부러 경로를 틀리게 쓴 그림

아래쪽에 글자가 보인다면 alt 가 제 일을 한 것입니다. 만약 alt 를 안 썼다면 그 자리에는 아주 작은 깨진 그림 표시 하나만 남습니다. 무엇이 있었는지 알 길이 없습니다.

섹션 3 — width 와 height 로 크기 정하기

width 와 height 에 숫자만 적으면 그 픽셀 크기로 보입니다.

왼쪽부터 원래 크기 / 가로만 100 / 억지로 120 × 60

원래보다 크게 늘리면 흐려집니다. 200 짜리 그림을 800 으로 늘리면 점이 커져서 뭉개져 보입니다. 큰 그림이 필요하면 처음부터 큰 파일을 준비하세요. (지금 쓰는 .svg 는 예외입니다. 이유는 섹션 5 에서 봅니다)

섹션 6 — 자주 하는 실수

그림이 안 나올 때 브라우저는 아무 말도 해 주지 않습니다. 빈자리만 남을 뿐입니다.

실수 1 — alt 를 안 씀
<img src="이미지/사과.svg" />

그림이 잘 보일 때는 아무 문제가 없어 보입니다. 그래서 계속 빠뜨립니다. 문제는 그림이 안 뜨는 날에 드러납니다. 그때 그 자리에는 가로세로 16 정도의 아주 작은 깨진 그림 표시 하나만 남습니다. 눈이 안 보이는 사람에게는 처음부터 아무것도 없는 것과 같습니다. alt 는 선택이 아니라 필수라고 생각하세요.

이렇게 쓰세요
<img src="이미지/사과.svg" alt="빨간 사과 그림" />
실수 2 — img 를 닫으려고 함
<img src="이미지/사과.svg" alt="빨간 사과 그림"></img>

img 는 빈 태그라서 닫는 태그가 없습니다. 그림은 정상으로 보입니다. 브라우저가 그런 것은 없다며 조용히 버리기 때문입니다. 동작은 하지만 규칙에 없는 표기라 쓰지 마세요. 01단원 개념02 의 <br /> 를 떠올리면 됩니다.

실수 3 — 크기 값에 단위를 붙임
<img src="이미지/사과.svg" alt="빨간 사과 그림" width="10em" />

HTML 속성으로 크기를 줄 때는 숫자만 씁니다. 브라우저는 앞쪽 숫자만 읽고 뒤에 붙은 글자를 버립니다. 그래서 width="100px" 는 100 으로 읽혀 우연히 잘 동작합니다. 여기에 속아 단위를 써도 되는 줄 알고 10em 이라고 적으면 10 만 남아 10 픽셀짜리 점처럼 작아집니다. 아래가 그 결과입니다. (CSS 에서는 반대로 단위를 꼭 붙여야 합니다. 10단원에서 배웁니다)

이렇게 쓰세요
<img src="이미지/사과.svg" alt="빨간 사과 그림" width="160" />

실수 4 — alt 에 파일 이름이나 "이미지" 라고 씀
<img src="이미지/풍경.svg" alt="풍경.svg" />

화면상으로는 아무 차이가 없습니다. 그래서 실수라는 것도 모릅니다. 하지만 소리로 들으면 "풍경 점 에스브이지" 라고 읽힙니다. alt 는 파일 이름을 옮겨 적는 칸이 아니라, 그림을 못 보는 사람에게 그림을 설명해 주는 칸입니다.

실수 5 — 그림 파일만 다른 폴더로 옮김
이미지/사과.svg 를 다른 폴더로 옮긴 뒤 HTML 은 그대로 둠

HTML 안에는 그림이 들어 있지 않고 주소만 적혀 있다는 것을 잊었을 때 납니다. 파일을 옮기면 주소가 달라지므로 src 도 같이 고쳐야 합니다. 어제까지 잘 보이던 그림이 오늘 갑자기 안 보인다면 이것부터 확인하세요.

── 정리 ──

1. 그림은 <img src="경로" alt="설명" /> 로 겁니다. 닫는 태그가 없습니다.

2. HTML 파일 안에 그림이 들어 있는 것이 아니라 주소만 적혀 있습니다.

3. alt 는 필수입니다. 그림을 못 볼 때 대신 읽는 글입니다.

4. 장식용 그림만 alt="" 로 비웁니다. 아예 안 쓰는 것과 다릅니다.

5. width 하나만 적으면 세로는 비율대로 따라옵니다. 둘 다 적으면 찌그러집니다.

6. 크기 값에 단위를 붙이지 않습니다. 숫자만 씁니다. 10em 은 10 픽셀이 됩니다.

7. a 로 img 를 감싸면 그림이 링크가 되고, 그때 alt 에는 갈 곳을 씁니다.
