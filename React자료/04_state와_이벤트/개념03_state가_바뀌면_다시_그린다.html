개념 03 — state가 바뀌면 다시 그린다

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

이 파일은 콘솔이 주인공입니다. 버튼을 누를 때마다 콘솔에 줄이 몇 개씩 늘어나는지 세어 보세요.

정리

  1. set 함수를 부르면 그 컴포넌트 함수가 처음부터 다시 실행됩니다. 이 일을 렌더링이라고 합니다.
  2. 다시 실행될 때 useState 는 시작값이 아니라 기억해 둔 값을 줍니다.
  3. 함수 안의 보통 변수는 매번 새로 만들어집니다. state 만 남습니다.
  4. 새 값이 지금 값과 같으면 React 는 다시 그리지 않습니다.
  5. 부모가 다시 그려지면 그 안의 자식들도 다시 실행됩니다.
  6. 다시 그린다고 화면을 새로 만들지 않습니다. 달라진 곳만 실제 화면에 반영합니다.
  7. set 함수는 이벤트 핸들러 안에서만 부릅니다. 렌더링 중에 부르면 무한 루프입니다.
