04단원 연습문제 정답 — state와 이벤트

먼저 스스로 풀어 본 다음에 보세요. 직접 눌러 보면서 F12 → Console 도 함께 확인하세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

정답과 모양이 조금 달라도 결과가 같으면 맞은 것입니다. 이름을 다르게 지었거나, 화살표 함수를 밖으로 빼서 썼거나 하는 차이는 상관없습니다.

정리

  1. onClick 에는 함수를 넘깁니다. 괄호를 붙이면 그릴 때 실행됩니다.
  2. 값을 넘겨야 하면 () => 함수(값) 로 감쌉니다.
  3. 화면이 바뀌어야 하는 값만 useState 로 만듭니다.
  4. set 함수를 부르면 컴포넌트가 처음부터 다시 실행됩니다.
  5. 한 이벤트에서 같은 state 를 두 번 바꿀 때는 함수형 갱신을 씁니다.
  6. 배열·객체 state 는 새로 만들어 넣습니다. push 나 직접 대입은 안 됩니다.
  7. 계산으로 얻을 수 있는 값은 state 로 두지 않습니다.
