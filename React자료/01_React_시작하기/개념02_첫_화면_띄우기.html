개념 02 — 첫 화면 띄우기

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script type="text/babel"> 안부터 읽으세요.

이 파일은 직접 고쳐 보는 파일입니다. 코드를 고쳤으면 저장(Ctrl+S) → 브라우저에서 F5 를 꼭 누르세요. 섹션 4에서 자세히 설명합니다.

① 섹션 2~3 — React 가 그림을 그릴 자리

여기는 아직 React 가 그리기 전입니다

② 섹션 5 — 화면 설명을 함수로 묶기

정리

  1. 위쪽 script 3줄은 각각 React(화면 설명 만들기), ReactDOM(브라우저에 붙이기), Babel(태그 문법 번역) 을 불러옵니다.
  2. 우리 코드가 들어가는 script 에는 type="text/babel" 이 붙습니다.
  3. id="root" 인 div 는 React 가 그림을 그릴 자리입니다. 그 안은 React 가 통째로 맡습니다.
  4. createRoot(자리) 는 자리를 맡는 줄이고, root.render(화면설명) 은 그려 달라는 줄입니다.
  5. 화면 설명이 길어지면 function App() 으로 묶고 render(<App />) 로 넣습니다. 이름은 대문자로 시작합니다.
  6. 고쳤으면 저장(Ctrl+S) → 브라우저에서 F5. 안 바뀐다면 이것부터 확인하세요.
