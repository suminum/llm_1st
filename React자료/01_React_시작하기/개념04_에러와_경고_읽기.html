개념 04 — 에러와 경고 읽기

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 을 반드시 함께 여세요. 이 파일은 콘솔을 보는 파일입니다.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script type="text/babel"> 안부터 읽으세요.

아래 ② 와 ④ 는 일부러 비워 둔 자리입니다. 고장이 아닙니다. 왜 비어 있는지 알아내는 것이 이 파일의 목표입니다.

① 제대로 나오는 화면

② 섹션 4 — 이름을 소문자로 만든 것 (일부러 틀린 것)

③ 섹션 4 — 같은 코드에서 이름만 대문자로 바꾼 것

④ 섹션 6 — createRoot 만 하고 render 를 안 부른 자리

정리

  1. 콘솔의 React DevTools 안내와 Babel 경고 두 줄은 이 자료에서 항상 나옵니다. 정상입니다.
  2. 빨간 에러는 맨 윗줄과 오른쪽 줄 번호만 읽으면 됩니다.
  3. SyntaxError 는 script 안이 통째로 안 돌아갑니다. 맨 위의 console.log 조차 안 찍히면 이 종류입니다.
  4. Target container is not a DOM element 는 그릴 자리를 못 찾았다는 뜻입니다. id 철자와 # 을 확인하세요.
  5. 컴포넌트 이름이 소문자면 React 가 HTML 태그로 봅니다. 에러 없이 화면만 빕니다.
  6. 아무 메시지도 없는데 화면이 비면 저장·F5 → 이름 대문자 → render 를 불렀는가 순서로 확인하세요.
