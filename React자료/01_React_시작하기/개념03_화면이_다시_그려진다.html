개념 03 — 화면이 다시 그려진다

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script type="text/babel"> 안부터 읽으세요.

이 파일에는 1초마다 스스로 움직이는 초시계가 두 개 있습니다. ② 와 ③ 의 입력칸에 글자를 쳐 놓고 기다려 보는 것이 이 파일의 핵심입니다.

① 섹션 1 — 버튼을 누르면 그 자리를 다시 그립니다

② 섹션 2~3 — React 가 1초마다 다시 그리는 초시계

③ 섹션 4 — 같은 초시계를 React 없이 직접 다시 그린 것

④ 섹션 5 — render 를 부르는 것은 내 몫입니다

⑤ 섹션 6 — 일부러 틀리게 쓴 것

정리

  1. 화면을 바꾸는 방법은 root.render(...) 를 다시 부르는 것 하나뿐입니다.
  2. createRoot 는 자리마다 한 번, render 는 여러 번입니다.
  3. 다시 불러도 화면이 통째로 새로 만들어지지 않습니다. React 가 달라진 곳만 고칩니다.
  4. 그래서 초시계가 갱신돼도 옆 입력칸의 글자와 커서가 그대로 남습니다. innerHTML 로 직접 다시 그리면 전부 사라집니다.
  5. 다만 "다시 그려라" 라고 말하는 일은 아직 내 몫입니다. 데이터만 바꾸고 render 를 빠뜨리면 화면이 조용히 어긋납니다.
  6. 이 부름을 대신해 주는 것이 04단원의 useState 입니다.
