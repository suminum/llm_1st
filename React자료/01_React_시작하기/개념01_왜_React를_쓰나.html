개념 01 — 왜 React를 쓰나

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. 이 자료에서는 가르치지 않습니다. <script type="text/babel"> 안부터 읽으세요.

이 파일은 "따라 치는" 파일이 아닙니다. 앞으로 배울 것이 무엇인지 한 번 보고 넘어가는 파일입니다. 코드가 이해되지 않아도 정상입니다.

① 지금까지 하던 방식 (JS자료 10~13단원)

0개

    ② React 방식 — 같은 화면입니다

    정리

    1. 지금까지는 화면을 어떻게 고칠지 직접 적었습니다(명령형).
    2. React 는 데이터가 이러면 화면은 이렇게 생겼다만 적습니다(선언형).
    3. 데이터를 바꾸면 React 가 바뀐 부분을 찾아 화면에 반영합니다.
    4. 화면을 고치는 코드가 흩어지지 않아서, 화면이 복잡해질수록 이득이 커집니다.
    5. React 는 자바스크립트를 대신하지 않습니다. map·filter·스프레드를 계속 씁니다.
    6. 01~07단원은 더블클릭으로, 08단원부터는 Vite 프로젝트로 진행합니다.
