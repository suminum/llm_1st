개념 05 — state를 어디에 둘까

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

데모 ① · ③ · ⑤ 는 일부러 고장 난 예제입니다. 화면의 값들이 서로 안 맞는 것이 정상입니다.

정리

  1. 계산할 수 있는 값은 state 로 두지 않습니다. 개수는 items.length, 총액은 reduce 로 그때그때 계산합니다.
  2. state 를 둘로 두면 반드시 어긋납니다. 사람이 매번 챙기는 방식은 언젠가 실패합니다.
  3. 고른 항목은 통째로 저장하지 말고 id 만 저장한 뒤 find 로 찾습니다.
  4. props 로 받은 값을 useState 초기값으로 복사하지 않습니다. 초기값은 처음 한 번만 쓰입니다.
  5. 판단 순서: 안 바뀌나 → props 인가 → 계산되나 → 그래도 아니면 state.
  6. state 로 정했다면 쓰는 곳이 하나면 그 안에, 둘 이상이면 공통 부모에 둡니다.
  7. state 가 적을수록 어긋날 자리가 적습니다.
