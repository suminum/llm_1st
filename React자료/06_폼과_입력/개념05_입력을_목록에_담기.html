개념 05 — 입력을 목록에 담기

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

입력칸에 글을 쓰고 추가를 눌러 보세요. Enter 도 됩니다. 여러 개 넣어 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

정리

  1. 입력칸 state 와 목록 state 를 따로 둡니다. 입력칸은 칠 때마다, 목록은 제출할 때만 바뀝니다.
  2. 목록에 더할 때는 setTodos([...todos, 값]) 으로 새 배열을 만듭니다. push 는 쓰지 않습니다 (이유는 07단원).
  3. 더한 뒤 setText("") 로 입력칸을 비우면 연속으로 쓰기 편합니다.
  4. trim() 으로 공백만 친 것을, includes() 로 이미 있는 것을 걸러냅니다. 검사한 값과 저장하는 값이 같아야 합니다.
  5. 항목마다 id 를 붙여 객체로 담으면 같은 글자를 여러 번 담을 수 있고 key 도 안전해집니다.
  6. set 함수를 부른 직후에도 state 는 아직 옛날 값입니다. 방금 넣은 것까지 세려면 + 1 을 해야 합니다.
