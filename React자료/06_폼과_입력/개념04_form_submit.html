개념 04 — form submit

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

입력칸에서 Enter 도 쳐 보고, 버튼도 눌러 보세요. 두 가지가 같은 일을 하는지 보는 것이 이 파일의 목표 중 하나입니다.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

정리

  1. 입력칸이 있는 화면은 form 으로 묶고 onSubmit 을 붙입니다. 버튼 클릭과 Enter 가 같은 곳으로 모입니다.
  2. e.preventDefault() 를 빠뜨리면 페이지가 새로고침되어 state 가 전부 처음 값으로 돌아갑니다.
  3. form 안 버튼은 type 을 안 적으면 제출 버튼입니다. 제출용이 아닌 버튼에는 type="button" 을 붙입니다.
  4. 검사는 위에서 하나씩 하고 안 맞으면 바로 return 합니다. 문구는 state 에 넣고 화면은 React 가 그립니다.
  5. value.trim() 으로 공백만 친 경우를 걸러냅니다.
  6. 입력칸을 비우는 것은 setText("") 한 줄입니다. 입력칸을 직접 붙잡을 필요가 없습니다.
