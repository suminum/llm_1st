개념 01 — JSX란 무엇인가

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

이 파일은 콘솔이 주인공입니다. 화면보다 콘솔에 찍히는 글자를 더 많이 봅니다.

① JSX 로 만든 화면

② React.createElement 로 만든 화면 — ① 과 같습니다

③ JSX 를 따옴표로 감쌌을 때 (섹션 6에서 설명)

정리

  1. JSX 는 자바스크립트 식입니다. 값 하나가 남으므로 변수에 담고 함수로 돌려주고 배열에 넣을 수 있습니다.
  2. Babel 이 JSX 를 React.createElement("태그", 속성, 안쪽) 함수 호출로 바꿔 줍니다. 브라우저는 JSX 를 모릅니다.
  3. 그 결과로 남는 것은 화면 설계도 객체입니다. type 과 props 를 가집니다. 아직 화면은 아닙니다.
  4. 설계도를 실제 화면으로 만드는 것은 render 입니다.
  5. createElement 를 직접 써도 결과는 같습니다. JSX 는 그것을 읽기 쉽게 적는 방법입니다.
  6. JSX 를 따옴표로 감싸면 그냥 문자열입니다. 화면에 태그가 글자로 보이면 이 실수입니다.
