개념 05 — 비었을 때와 falsy 함정

이 파일은 브라우저로 더블클릭해서 엽니다. F12 → Console 도 함께 보세요.

HTML 과 CSS 는 몰라도 됩니다. 위쪽 <style> 은 화면 모양을 만드는 코드입니다. <script type="text/babel"> 안부터 읽으세요.

이 파일의 데모에는 일부러 잘못 만든 화면이 여러 개 있습니다. 어디가 잘못됐는지 눈으로 찾아보세요.

정리

  1. 빈 배열에 map 을 써도 에러가 안 납니다. 화면에 아무것도 안 나올 뿐입니다.
  2. 그래서 비었을 때 안내 문구를 직접 보여 줘야 합니다. 삼항이나 일찍 return 을 씁니다.
  3. {items.length && ...} 는 목록이 비면 화면에 0 을 찍습니다. 에러도 경고도 안 납니다.
  4. 이유는 두 가지가 겹쳐서입니다. && 는 왼쪽이 거짓이면 왼쪽 값을 그대로 돌려주고, React 는 숫자 0 을 화면에 그립니다.
  5. 고치는 법은 하나입니다. && 왼쪽을 length > 0 처럼 참·거짓이 나오는 식으로 만드세요.
  6. NaN 도 화면에 그대로 나옵니다. 개수로 나누는 계산은 비었을 때를 먼저 확인하세요.
  7. 빈 배열은 참입니다. {items && ...} 가 아니라 {items.length > 0 && ...} 라고 쓰세요.
