## 파일 읽는 법

### 개념 파일 (`개념01_...`, `개념02_...`)

설명이 주석으로 들어 있는 코드입니다. **읽지만 말고 직접 쳐 보세요.**

파일은 항상 같은 순서로 되어 있습니다.

1. **맨 위 헤더** — 이 파일이 무엇을 다루는지
2. **`── 섹션 N: 제목 ──`** — 주제가 바뀌는 지점
3. **`✏️ 직접 해보기`** — 섹션마다 나오는 짧은 과제.
   **정답은 파일 맨 아래 `직접 해보기 정답` 블록**에 주석으로 있습니다. 먼저 스스로 해 보세요.
4. **`섹션 N: 자주 하는 실수`** — 실제로 자주 하는 실수 모음.
   `// [실수 1]` 처럼 번호가 붙어 있고 **주석 처리되어 있습니다.**
   주석을 풀고 실행해 결과를 눈으로 본 다음, **반드시 다시 주석 처리하세요.**

   > **단, `[SyntaxError]` 라고 적힌 것은 눈으로만 보세요.**
   > 다른 에러는 그 줄에서만 나고 앞의 출력은 그대로 나옵니다.
   > 그런데 `SyntaxError` 는 브라우저가 코드를 아예 못 읽는 상태라
   > **화면이 통째로 비고 콘솔도 한 줄도 안 나옵니다.**
   > 여러분이 망가뜨린 게 아니니 놀라지 마세요. 다시 `//` 를 붙이면 그대로 돌아옵니다.
5. **`정리`** — 그 파일의 핵심 5~7줄.
   **주석이 아니라 화면 아래쪽 파란 상자에 보입니다.** 복습할 때 여기만 봐도 됩니다.

### 결과를 적어 둔 주석 3가지

| 주석 | 뜻 |
|---|---|
| `// 콘솔:` | 개발자도구 Console 탭에 찍히는 결과 |
| `// 화면:` | 브라우저 화면이 어떻게 보이는지 |
| `// 화면(누르면):` | 버튼을 누르거나 글자를 친 **뒤**의 화면 |

전부 **"실행하면 이렇게 나온다"** 는 뜻입니다.
**적어 둔 값은 전부 실제로 실행해서 맞춘 것입니다.** 다르게 나오면 어딘가 잘못 친 것입니다.

구분하는 요령 — **우리 코드가 낸 메시지는 한글, 브라우저가 낸 것은 영어**입니다.

## 자주 나오는 에러

| 에러 메시지 | 뜻 | 해결 |
|---|---|---|
| 화면이 하얗고 콘솔도 비어 있다 | `SyntaxError` — 코드 모양이 깨졌다 | 괄호 `( )`, 중괄호 `{ }`, 따옴표 짝을 확인 |
| `Cannot read properties of null` | 없는 것을 읽으려 했다 | `querySelector` 의 id 오타, 또는 값이 아직 없는 상태 |
| `Objects are not valid as a React child` | 객체를 그대로 화면에 넣었다 | `{user}` 가 아니라 `{user.name}` |
| `Each child in a list should have a unique "key" prop` | 목록에 `key` 를 안 붙였다 | 05단원 개념03 |
| `Too many re-renders` | 그리는 중에 state 를 바꿨다 | `onClick={fn()}` 처럼 괄호를 붙이지 않았는지 확인 |
| `'npm' 은(는) 내부 또는 외부 명령...` | Node.js 가 없다 | 위 "준비물" 을 다시 하고 터미널을 새로 여세요 |

에러가 나면 **빨간 글씨의 맨 윗줄**과 **오른쪽 끝의 파일·줄 번호**를 먼저 보세요.
에러는 실패가 아니라 안내문입니다. 읽는 법은 `01단원 개념04` 에 따로 정리해 두었습니다.

## 인터넷이 막혀 09단원·13단원이 안 될 때

09단원과 13단원 종합03·04 는 `jsonplaceholder.typicode.com` 이라는 연습용 서버에서
데이터를 받아옵니다. 학교나 회사 네트워크가 막아 두면 그 예제들이 멈춥니다.

그럴 때는 **인터넷 없이 돌리는 대체본**을 켜면 됩니다.
`실습프로젝트/index.html` 을 열면 이런 줄이 있습니다.

```html
<!-- <script src="/오프라인_대체.js"></script> -->
```

앞의 `<!--` 와 뒤의 `-->` 만 지우고 저장하면 켜집니다.
켜지면 콘솔 맨 위에 `[오프라인 대체본이 켜져 있습니다]` 가 찍힙니다.

**진짜 서버가 주는 데이터를 그대로 담아 두었기 때문에, 자료에 적힌 결과가 똑같이 나옵니다.**
없는 번호를 요청했을 때 404 가 나오는 것까지 똑같습니다.

인터넷이 되는 곳으로 옮기면 `<!--` 와 `-->` 를 다시 붙여 꺼 두세요.
