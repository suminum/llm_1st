## 시작 전 준비 (처음 한 번만)

### 1. Node.js 설치

01~09단원은 **Node.js**라는 프로그램으로 실행합니다. 없으면 아무것도 안 돌아갑니다.

1. <https://nodejs.org> 접속
2. 왼쪽의 **LTS** 버튼을 눌러 내려받기 (오른쪽 Current 말고 왼쪽입니다)
3. 받은 파일을 실행 → 계속 "다음"만 누르면 됩니다
4. 설치가 끝나면 **컴퓨터를 껐다 켜거나, 열려 있던 터미널을 모두 닫고 다시 여세요**

설치가 됐는지 확인하는 방법 — 터미널에 이렇게 칩니다.

```
node -v
```

`v22.14.0` 처럼 **v로 시작하는 숫자**가 나오면 성공입니다.

> `'node'은(는) 내부 또는 외부 명령... 이 아닙니다` 가 나오면 아직 설치가 안 됐거나
> 터미널을 다시 열지 않은 것입니다. 터미널을 닫았다가 새로 열어 보세요.

### 2. VS Code 설치

코드를 쓰는 편집기입니다. <https://code.visualstudio.com> 에서 받아 설치하세요.

설치 후 VS Code 를 열고 **파일 → 폴더 열기**로 이 `JS자료` 폴더를 통째로 여세요.
파일 하나만 여는 것보다 폴더째 여는 편이 훨씬 편합니다.

### 3. 알아두면 좋은 것

- **HTML과 CSS는 몰라도 됩니다.** 10~12단원 파일 위쪽에 있는 `<style>`, `<body>` 같은 코드는
  화면 모양을 만드는 부분입니다. 이 자료에서는 가르치지 않습니다. `<script>` 안부터 읽으세요.
- **12단원은 인터넷 연결이 필요합니다.** 인터넷에서 데이터를 받아오는 내용이라 그렇습니다.
  학교나 회사 네트워크가 막아 두어 안 되는 경우가 있는데, 그때 쓰는 방법을 아래에 적어 두었습니다.

### 4. 인터넷이 막혀 12단원이 안 될 때

12단원과 13단원 종합04는 `jsonplaceholder.typicode.com` 이라는 연습용 서버에서 데이터를 받아옵니다.
이 주소가 막혀 있으면 **인터넷 없이 돌리는 대체본**을 켤 수 있습니다.

해당 파일(12단원 개념03·04·05·연습문제·연습문제_정답, 13단원 종합04 두 개) 위쪽에 이런 줄이 있습니다.

```html
<!-- <script src="오프라인_대체.js"></script> -->
```

여기서 앞의 `<!--` 와 뒤의 `-->` 만 지우면 켜집니다.

```html
<script src="오프라인_대체.js"></script>
```

켜지면 콘솔(F12) 맨 위에 `[오프라인 대체본이 켜져 있습니다]` 가 찍힙니다.
**진짜 서버가 주는 데이터를 그대로 담아 두었기 때문에, 자료에 적힌 결과가 똑같이 나옵니다.**
없는 번호를 요청했을 때 404가 나오는 것까지 똑같습니다.

인터넷이 되는 곳으로 옮기면 `<!--` 와 `-->` 를 다시 붙여 꺼 두세요.

## 파일 읽는 법

### 개념 파일 (`개념01_...`, `개념02_...`)

설명이 주석으로 들어있는 코드입니다. **읽지만 말고 직접 쳐 보세요.**

```js
// ── 섹션 1: 변수에 값 담기 ──

let drink = "아메리카노";
console.log(drink);
// 출력: 아메리카노
```

> 변수 이름은 영어로 씁니다. 한글로도 만들 수는 있지만, 나중에 배울
> React·서버 코드는 전부 영어 이름을 쓰기 때문에 지금부터 습관을 들입니다.
> 대신 **주석과 화면에 보이는 글자는 한글**입니다.

파일은 항상 같은 순서로 되어 있습니다.

1. **맨 위 헤더** — 이 파일이 무엇을 다루는지, 어떻게 실행하는지
2. **`── 섹션 N: 제목 ──`** — 주제가 바뀌는 지점
3. **`✏️ 직접 해보기`** — 섹션마다 나오는 짧은 과제.
   **정답은 파일 맨 아래 `직접 해보기 정답` 블록**에 주석으로 있습니다. 먼저 스스로 해 보세요.
4. **`섹션 N: 자주 하는 실수`** — 학생들이 실제로 자주 하는 실수 모음.
   `// [실수 1]` 처럼 번호가 붙어 있고 **주석 처리되어 있습니다.**
   주석을 풀고 실행해서 결과를 눈으로 본 다음, **반드시 다시 주석 처리하세요.**

   > **단, `SyntaxError` 라고 적힌 것은 눈으로만 보세요.**
   > 다른 에러는 주석을 풀어도 그 줄에서만 나고 앞의 출력은 그대로 나옵니다.
   > 그런데 `SyntaxError` 는 자바스크립트가 파일을 아예 못 읽는 상태라
   > **출력이 한 줄도 안 나옵니다.** 여러분이 망가뜨린 게 아니니 놀라지 마세요.
   > 실수로 풀었다면 다시 `//` 를 붙이면 그대로 돌아옵니다.
   > 각 파일의 실수 섹션 맨 위에도 같은 안내를 적어 두었습니다.
5. **`── 정리 ──`** — 그 파일의 핵심 5~6줄. 복습할 때 여기만 봐도 됩니다.

### 결과를 적어 둔 주석 3가지

| 주석 | 뜻 | 나오는 곳 |
|---|---|---|
| `// 출력:` | 터미널에 찍히는 결과 | 01~09단원, 13단원 `.js` |
| `// 콘솔:` | 개발자도구 Console 탭에 찍히는 결과 | 10~12단원 |
| `// 화면:` | 브라우저 화면이 어떻게 바뀌는지 | 10~12단원 |

전부 **"실행하면 이렇게 나온다"** 는 뜻입니다. 직접 실행해서 같은지 확인하세요.
다르게 나오면 어딘가 잘못 친 것입니다.

## 자주 나오는 에러 4가지

| 에러 메시지 | 뜻 | 해결 |
|---|---|---|
| `'node'은(는) 내부 또는 외부 명령...` | Node.js 가 없다 | 맨 위 "시작 전 준비" 를 다시 하세요. 설치 후 터미널을 새로 열어야 합니다 |
| `ReferenceError: x is not defined` | 없는 이름을 불렀다 | 변수 이름 오타 확인, 만들기 전에 쓰지 않았는지 확인 |
| `SyntaxError: Unexpected token` | 문법이 깨졌다 | 괄호 `( )`, 중괄호 `{ }`, 따옴표 짝이 맞는지 확인 |
| `TypeError: x is not a function` | 함수가 아닌 걸 함수처럼 불렀다 | 이름 오타 확인 (`lenght` → `length`) |

브라우저(10~12단원)에서는 에러가 화면이 아니라 **개발자도구 Console 탭**에 빨간 글씨로 나옵니다.
`F12` 를 눌러 확인하세요.

에러가 나면 **빨간 글씨의 맨 윗줄**과 **몇 번째 줄인지**를 먼저 보세요.
에러는 실패가 아니라 안내문입니다.
