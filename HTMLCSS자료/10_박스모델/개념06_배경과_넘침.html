개념 06 — 배경과 넘침

10단원 · 박스 모델

이 파일은 배경 꾸미기와 넘친 내용 다루기 두 가지를 다룹니다. 배경 그림은 같은 폴더의 무늬.svg 와 풍경.svg 를 씁니다. 인터넷 주소를 쓰지 않았으므로 인터넷이 끊겨 있어도 그대로 보입니다.

섹션 1 — 배경이 칠해지는 범위

배경은 콘텐츠 + padding + 테두리 아래까지 깔립니다. margin 자리에는 안 깔립니다.

굵은 점선 사이로 배경이 비칩니다

background-color 는 테두리 아래까지 깔립니다

✏️ 직접 해보기 1 — 파일 위쪽 <style> 에서 .bgc-box 에 margin: 20px; 한 줄을 추가해 보세요. 새로 생긴 20px 자리에는 연파랑이 안 칠해지는 것을 확인하고 되돌리세요.

섹션 2 — 배경에 그림 깔기

background-image: url("파일이름"); 으로 그림을 깝니다. 그림은 기본적으로 반복됩니다.

repeat (기본값) / no-repeat / repeat-x

배경 그림은 <img> 태그와 역할이 다릅니다. 내용으로서 의미가 있는 사진은 <img> 로 넣고(04단원), 장식용 무늬나 배경은 CSS 의 background-image 로 넣습니다.

✏️ 직접 해보기 2 — .bgi-repeatx 의 background-repeat: repeat-x; 를 repeat-y; 로 바꿔 보세요. 무늬가 어느 방향으로 늘어서는지 확인하고 되돌리세요.

섹션 3 — 그림을 어디에 둘지 정하기

background-position 은 가로 위치와 세로 위치를 차례로 씁니다.

right top / center / 120px 40px

✏️ 직접 해보기 3 — .bgp-righttop 의 background-position: right top; 을 left bottom; 으로 바꿔 보세요. 무늬가 대각선 반대편으로 옮겨 갑니다.

섹션 4 — 그림 크기 정하기 (cover 와 contain)

cover 는 빈틈없이 채우기, contain 은 다 보이게 넣기입니다.

원래 크기 / cover / contain / 직접 지정

✏️ 직접 해보기 4 — .bgs-cover 에 background-position: center bottom; 한 줄을 추가해 보세요. 잘리는 부분이 위쪽으로 바뀌어 땅이 보이기 시작합니다.

섹션 5 — background 한 줄로 줄여 쓰기

background 하나에 색 · 그림 · 반복 · 위치를 몰아서 쓸 수 있습니다.

background 한 줄로 네 가지를 한꺼번에

background: #fff8dc url("무늬.svg") no-repeat right center;

✏️ 직접 해보기 5 — .bg-short 의 값에서 no-repeat 를 빼고 새로고침해 보세요. 무늬가 상자를 가득 채우고, 위치 지정이 아무 의미가 없어집니다.

섹션 6 — 넘친 내용 다루기 (overflow)

상자보다 내용이 길 때 넘친 부분을 어떻게 할지 정합니다.

visible (기본값) — 글이 상자 밖으로 흘러나옵니다

이 상자의 세로 길이는 90px 입니다. 그런데 안에 든 글이 그보다 훨씬 깁니다. 남는 부분이 어떻게 되는지 보세요. overflow 속성이 그것을 정합니다. 지금은 아무것도 안 정했으므로 기본값 visible 이 쓰이고 있습니다.

hidden — 넘친 부분이 잘립니다

이 상자의 세로 길이는 90px 입니다. 그런데 안에 든 글이 그보다 훨씬 깁니다. 남는 부분이 어떻게 되는지 보세요. overflow 속성이 그것을 정합니다. 지금은 hidden 이라서 넘친 글이 잘려 나갑니다.

auto — 넘칠 때만 스크롤바가 생깁니다

이 상자의 세로 길이는 90px 입니다. 그런데 안에 든 글이 그보다 훨씬 깁니다. 남는 부분이 어떻게 되는지 보세요. overflow 속성이 그것을 정합니다. 지금은 auto 라서 오른쪽에 세로 스크롤바가 생겼습니다.

scroll — 스크롤바 자리를 항상 잡아 둡니다

이 상자의 세로 길이는 90px 입니다. 그런데 안에 든 글이 그보다 훨씬 깁니다. 남는 부분이 어떻게 되는지 보세요. overflow 속성이 그것을 정합니다. 지금은 scroll 이라서 가로 스크롤바 자리까지 잡혀 있습니다.

헷갈리면 auto 를 쓰세요. 필요할 때만 스크롤바를 붙여 주므로 대부분의 경우에 맞습니다. hidden 은 잘린 내용을 읽을 방법이 없어지므로, 정말 안 보여도 되는 내용에만 쓰세요.

✏️ 직접 해보기 6 — .ov-hidden 의 height: 90px 을 지우려면 어디를 고쳐야 할까요? 위쪽 <style> 에서 네 상자가 공유하는 규칙을 찾아 height 줄을 잠깐 지워 보고, 네 상자가 어떻게 변하는지 확인한 뒤 되돌리세요.

섹션 7 — 자주 하는 실수

배경 그림은 안 보여도 에러가 안 납니다. 그냥 빈 상자가 보일 뿐이라 원인을 찾기 어렵습니다.

실수 1 — 그림 경로가 틀림
background-image: url("없는그림.svg");

아무 그림도 안 보입니다. 화면에는 배경색만 남습니다. 깨진 그림 아이콘조차 안 나옵니다. <img> 태그와 다른 점입니다. 아래 상자가 그때의 모습입니다. 배경색만 있고 그림 자리는 그냥 비어 있습니다. 여러분 파일에서 진짜로 경로가 틀리면 F12 개발자도구의 Console 탭에 그 파일을 못 찾았다는 빨간 줄이 뜹니다. 배경이 안 보이면 Console 부터 확인하세요. (아래 상자는 모습만 흉내 낸 것이라 이 페이지의 Console 에는 아무것도 안 뜹니다)

실수 2 — 빈 상자에 배경만 주고 height 를 안 줌
<div class="hero"></div> .hero { background-image: url("풍경.svg"); }

아무것도 안 보입니다. 안에 내용이 없으면 상자의 세로 길이가 0 이 되고, 세로가 0 인 상자에는 배경을 칠할 자리가 없기 때문입니다. 빈 상자에 배경 그림을 깔 때는 height 를 꼭 같이 주세요.

실수 3 — 단축 background 를 나중에 씀
background-image: url("무늬.svg"); background: #fff8dc;

배경 그림이 조용히 사라집니다. 단축 background 는 자기가 안 적은 항목까지 전부 기본값으로 되돌리기 때문입니다. padding, border 와 똑같은 규칙입니다. 단축을 먼저, 개별을 나중에 쓰세요.

실수 4 — cover 와 contain 을 바꿔 씀

로고에 cover 를 쓰면 로고 가장자리가 잘려 나갑니다. 배경 사진에 contain 을 쓰면 옆에 빈 자리가 생겨 어색해집니다. 잘려도 되면 cover, 다 보여야 하면 contain 입니다.

실수 5 — 넘치는 원인을 안 고치고 hidden 으로 덮음
overflow-x: hidden; /* 가로 스크롤바만 안 보이게 */

가로 스크롤바는 사라지지만 내용은 여전히 밖에 있습니다. 잘려서 안 보일 뿐입니다. 화면이 좁아지면 글자가 통째로 안 읽히기도 합니다. 진짜 원인은 대개 개념05 의 width: 100% + padding 입니다. box-sizing: border-box 로 원인을 고치세요.

실수 6 — url 을 문자열처럼만 씀
background-image: "무늬.svg";

url( ) 을 빼먹었습니다. 이 줄이 통째로 버려집니다. 배경이 아예 안 나옵니다. 파일 이름만 적는 것이 아니라 url("무늬.svg") 형태로 감싸야 합니다. 따옴표는 없어도 되지만 파일 이름에 공백이나 한글이 있으면 붙이는 편이 안전합니다.

── 정리 ──

1. 배경은 콘텐츠 + padding + 테두리 아래까지 깔립니다.

2. background-image: url("무늬.svg"); 로 그림을 깝니다. 기본은 반복입니다.

3. background-repeat 는 repeat / no-repeat / repeat-x / repeat-y.

4. background-position 은 가로 위치 → 세로 위치 순으로 씁니다.

5. cover 는 빈틈없이 채우고(잘림), contain 은 다 보이게 넣습니다(빈 자리).

6. 단축 background 는 안 적은 항목을 기본값으로 되돌립니다. 먼저 쓰세요.

7. overflow 는 visible / hidden / auto / scroll. 헷갈리면 auto.
