개념 03 — 설명 목록

03단원 · 목록과 표

이 파일에서는 용어와 설명이 짝을 이루는 목록을 만듭니다. dl, dt, dd 세 태그를 씁니다. 점도 번호도 붙지 않아서 처음에는 "이게 목록인가?" 싶습니다. 대신 설명 쪽만 오른쪽으로 들어가는 모양으로 짝이 눈에 보입니다.

섹션 1 — dl, dt, dd 로 짝 만들기

dl 로 감싸고, 그 안에 dt(용어) 와 dd(설명) 를 번갈아 씁니다.

실제 결과

웹페이지의 뼈대를 만드는 언어입니다.
CSS
뼈대를 꾸미는 언어입니다.

dt 와 dd 는 짝의 개수가 같을 필요가 없습니다. 섹션 2 에서 dt 하나에 dd 를 여러 개 다는 경우를 봅니다.

섹션 5 — 자주 하는 실수

dl 은 점도 번호도 없어서 잘못 써도 티가 잘 안 납니다. 그만큼 코드를 눈으로 확인하는 습관이 필요합니다.

실수 1 — dt 가 굵게 나올 거라고 기대함
<dt>HTML</dt>
HTML
굵어지지 않았습니다.

용어가 보통 굵기 그대로 나옵니다. 재 보면 굵기 값이 400 으로 본문과 같습니다. dt 는 "여기가 용어다" 라는 뜻만 붙이고 겉모양은 건드리지 않습니다. 굵게 하려면 <strong> 으로 감싸거나 09단원에서 CSS 로 하세요.

실수 2 — dl 안에 p 를 바로 넣음
<dl> <p>아래는 용어 설명입니다</p> <dt>HTML</dt> </dl>

아래는 용어 설명입니다

HTML
웹페이지의 뼈대입니다.

ul 의 규칙과 같습니다. dl 의 자식 자리에는 dt 와 dd 만 옵니다. 화면에는 그냥 한 줄이 더 늘어날 뿐이라 알아채기 어렵습니다. 안내 문장이 필요하면 dl 바깥, 그 위에 p 로 쓰세요.

실수 3 — dt 없이 dd 만 씀
<dl> <dd>설명만 있습니다</dd> </dl>
설명만 있습니다

들여쓰기만 된 줄 하나가 보입니다. 에러는 없습니다. 그래서 "글자를 안으로 밀고 싶을 때" dd 를 쓰는 사람이 있는데, 이것은 뜻을 속이는 일입니다. 무엇에 대한 설명인지가 사라집니다. 들여쓰기는 10단원에서 CSS 로 하세요.

실수 4 — dt 를 dl 밖에서 씀
<dt>혼자 있는 용어</dt>
혼자 있는 용어

평범한 한 줄로 보일 뿐입니다. li 는 혼자 있어도 점이라도 붙어서 티가 났지만, dt 는 원래 아무 표시가 없어서 완전히 똑같아 보입니다. p 를 쓴 것과 화면상 구분이 안 됩니다. 반드시 dl 안에 두세요.

실수 5 — dd 를 먼저 쓰고 dt 를 나중에 씀
<dl> <dd>웹페이지의 뼈대입니다</dd> <dt>HTML</dt> </dl>

화면에는 설명이 위, 용어가 아래로 나옵니다. 보기에도 어색하지만 더 큰 문제는 어느 용어에 딸린 설명인지 알 수 없게 된다는 점입니다. 브라우저는 dd 를 바로 위의 dt 에 딸린 것으로 봅니다. 위에 dt 가 없으면 딸릴 곳이 없습니다. dt 를 먼저 쓰세요.

── 정리 ──

1. 용어와 설명이 짝인 목록은 <dl> 로 감쌉니다.

2. <dt> 가 용어, <dd> 가 설명입니다. dt 를 먼저 씁니다.

3. dd 만 왼쪽에서 안으로 들어갑니다. 점도 번호도 붙지 않습니다.

4. dt 는 굵어지지 않습니다. 굵기가 필요하면 strong 이나 CSS 를 씁니다.

5. dt 하나에 dd 여러 개, 그 반대도 됩니다. 개수를 맞출 필요가 없습니다.
