개념 04 — 표 만들기

03단원 · 목록과 표

이 파일에서는 표를 만듭니다. table, tr, th, td 로 뼈대를 세우고, caption 으로 제목을 달고, thead · tbody · tfoot 으로 세 부분을 나눕니다. 마지막 섹션의 경고 하나는 꼭 읽어 주세요. 표는 화면을 나누는 도구가 아닙니다.

섹션 1 — 표는 행(tr) 단위로 씁니다

table 안에 tr 을 쌓고, tr 안에 td 를 넣습니다. 세 겹 중첩입니다.

border="1" 을 붙인 표

김민준 90
이서연 85

border 를 뺀 같은 표

김민준 90
이서연 85

table 은 내용만큼만 넓어집니다. 위 표가 화면 왼쪽에 작게 붙어 있는 것은 그 때문입니다. 폭을 정하는 것도 10단원 CSS 일입니다.

✏️ 직접 해보기 1 — 위 첫 번째 표에 세 번째 행을 만들어 "박지훈" 과 "70" 을 넣어 보세요. <tr> 부터 통째로 한 벌 더 쓰면 됩니다.

섹션 2 — th 와 td 의 차이

칸에는 두 종류가 있습니다. 제목 칸은 th, 자료 칸은 td 입니다.

첫 줄만 th 로 쓴 표

th 가 굵고 가운데 정렬로 나오는 것은 브라우저가 정해 둔 기본 모양일 뿐입니다. 09단원에서 CSS 를 배우면 이 모양은 얼마든지 바꿉니다. 모양이 아니라 뜻을 보고 th 를 고르세요.

✏️ 직접 해보기 2 — 위 표에서 <td>김민준</td> 를 <th>김민준</th> 로 바꿔 보세요. 그 칸만 어떻게 달라지는지 보세요.

섹션 6 — 표를 화면 배치에 쓰지 마세요

이 섹션은 규칙이 아니라 경고입니다. 꼭 읽어 주세요.

표로 화면을 나눠 본 것 (따라 하지 마세요)

메뉴 본문이 여기에 들어갑니다. 표로 화면을 나누면 이렇게 됩니다.

판단이 헷갈릴 때 스스로에게 물어보세요. "이 내용을 종이에 옮겨 적을 때도 표로 그릴까?" 성적표는 표로 그립니다. 메뉴와 본문은 표로 그리지 않습니다.

✏️ 직접 해보기 6 — 위 배치용 표를 table 대신 02단원에서 배운 <p> 두 개로 바꿔 보세요. 좌우로는 안 놓이고 위아래로 놓이는 것을 확인하세요. (좌우 배치는 12단원에서 배웁니다)

섹션 7 — 자주 하는 실수

표는 태그가 여러 겹이라 어긋나기 쉽습니다. 그런데도 에러는 나지 않고 모양만 이상해집니다.

실수 1 — 행마다 칸 개수가 다름
<tr> <th>이름</th> <th>국어</th> <th>영어</th> </tr> <tr> <td>김민준</td> <td>90</td> ← 칸이 두 개뿐입니다 </tr>
이름 국어 영어
김민준 90

모자란 자리가 테두리도 없는 빈칸으로 남습니다. 표의 오른쪽 아래가 뻥 뚫려 보입니다. 개수가 모자란 행을 찾아 <td></td> 를 하나 채워 넣으면 반듯해집니다. 다음 파일에서 배울 colspan 을 쓰는 방법도 있습니다.

실수 2 — td 를 table 밖에서 씀
<td>표 밖의 칸</td>
표 밖의 칸

글자만 남고 칸은 사라집니다. 위에 "표 밖의 칸" 이라는 글자가 평범하게 보일 텐데, 브라우저가 td 태그를 통째로 버리고 안의 글자만 남긴 것입니다. li 는 혼자 있어도 점이라도 붙었지만 td 는 table 밖에서는 아예 존재하지 못합니다.

실수 3 — caption 을 표 맨 아래에 씀
<table border="1"> <tr><td>김민준</td></tr> <caption>맨 아래에 쓴 제목</caption> </table>
이름 점수
김민준 90
맨 아래에 쓴 제목

코드에서는 맨 아래인데 화면에서는 맨 위에 나옵니다. 브라우저가 caption 을 무조건 표 위로 끌어올리기 때문입니다. 결과가 맞게 나오니 실수를 알아챌 방법이 없습니다. 코드를 읽는 사람이 헷갈리니 항상 table 을 연 다음 줄에 쓰세요.

실수 4 — tfoot 을 tbody 보다 위에 씀
<tfoot> ... </tfoot> <tbody> ... </tbody>
합계 165
김민준 90
이서연 75

화면에서는 "합계" 줄이 그대로 맨 아래로 내려갑니다. 브라우저가 태그 이름을 보고 자리를 정하기 때문입니다. 결과가 원하는 대로 나오니 넘어가기 쉽지만, 코드에서는 순서대로 thead → tbody → tfoot 으로 쓰세요.

실수 5 — tr 안에 글자를 직접 씀
<tr> 김민준 <td>90</td> </tr>
김민준
90

글자가 표 위쪽 바깥으로 튀어나옵니다. 칸이 아닌 글자는 표 안에 있을 자리가 없어서 브라우저가 표 앞으로 밀어내기 때문입니다. tr 안에는 td 나 th 만 넣으세요.

실수 6 — 좌우 배치를 표로 함
<table> <tr> <td>메뉴</td> <td>본문</td> </tr> </table>

섹션 6 에서 본 그것입니다. 화면은 원하는 대로 나옵니다. 그래서 더 조심해야 합니다. 잘 나오는데 틀린 코드가 제일 고치기 어렵습니다. 좌우 배치는 12단원 flex, 13단원 grid 로 합니다.

── 정리 ──

1. table 안에 tr, tr 안에 td 를 넣습니다. 행 단위로 씁니다.

2. 제목 칸은 th, 자료 칸은 td. th 는 굵고 가운데 정렬로 나옵니다.

3. caption 은 표 제목이며 table 의 첫 자식으로 씁니다.

4. thead · tbody · tfoot 으로 머리 · 몸통 · 바닥을 나눕니다.

5. scope 는 제목 칸의 방향을 알려 줍니다. 화면은 안 바뀝니다.

6. 표는 자료를 담는 것입니다. 화면 배치는 12 · 13단원의 flex · grid 로 합니다.

7. border="1" 은 구조를 보려고 잠깐 쓰는 것입니다. 진짜 테두리는 10단원 CSS 입니다.
