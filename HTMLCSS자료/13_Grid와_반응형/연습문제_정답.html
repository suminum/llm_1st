문제 16 [확인] — 왜 반대로 동작할까요

고친 곳은 한 군데입니다. @media (max-width: 700px) 를 @media (min-width: 700px) 로 바꿨습니다. max-width 는 "이 값 이하일 때" 라서 좁은 화면에서만 조건이 맞았습니다.

── 13단원을 마치며 ──

1. 한 줄이면 flex, 격자면 grid. 둘은 섞어 씁니다.

2. 격자는 선에 번호를 붙입니다. 1부터, 칸보다 하나 많습니다.

3. 배치가 복잡하면 grid-template-areas 로 이름을 붙이세요.

4. viewport meta 와 img { max-width: 100% } 는 항상 넣습니다.

5. 기본은 좁은 화면용, min-width 로 덧붙입니다. 작은 값부터 위에서 아래로.

6. 폭은 되도록 정하지 말고, 정해야 하면 상한선만 정하세요.
