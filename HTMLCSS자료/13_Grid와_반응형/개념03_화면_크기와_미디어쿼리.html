개념 03 — 화면 크기와 미디어쿼리

13단원 · Grid 와 반응형

이 파일은 창 크기를 바꿔 가며 봐야 합니다. 브라우저 창의 오른쪽 끝을 마우스로 잡고 좁혔다 넓혔다 해 보세요. 아래 상자들의 색과 칸 수가 바뀝니다. 섹션 3 에서 폭을 숫자로 정확히 맞추는 방법(F12 기기 툴바)을 단계별로 배웁니다.

섹션 1 — 왜 반응형이 필요한가

폭을 px 로 못 박아 두면 창이 좁아져도 그대로입니다. 좁은 화면에서는 화면 밖으로 삐져나갑니다.

실제 결과 — 위는 고정 700px, 아래는 폭을 안 정한 카드

width: 700px — 창을 좁혀도 안 줄어듭니다
폭을 안 정함 — 창을 좁히면 같이 줄어듭니다

✏️ 직접 해보기 1 — 브라우저 창의 오른쪽 끝을 마우스로 잡고 화면 절반 정도까지 좁혀 보세요. 두 카드 중 어느 쪽이 줄어드는지 확인하고, 다시 넓혀 놓으세요.

섹션 2 — viewport meta 가 없으면 벌어지는 일

반응형을 만들기 전에 반드시 먼저 넣어야 하는 한 줄이 있습니다. 이것을 빠뜨리면 아래에서 배울 내용이 전부 헛일이 됩니다.

<head> <meta charset="UTF-8" /> <meta name="viewport" content="width=device-width, initial-scale=1" /> <title>내 페이지</title> </head>

이 줄은 휴대폰에서만 효과가 있습니다. PC 브라우저에서는 넣으나 빼나 화면이 같습니다. 그래서 더 잘 빠뜨립니다. 새 파일을 만들 때마다 charset 바로 아래에 같이 쓰는 습관을 들이세요.

✏️ 직접 해보기 2 — 이 파일 맨 위 <head> 안에서 viewport 줄을 찾아보세요. 찾았으면 그 줄 앞뒤를 소리 내어 읽어 보고, 여러분이 앞 단원에서 만든 파일 중 하나를 열어 그 줄이 있는지 확인해 보세요. 없다면 지금 넣어 두세요.

섹션 3 — F12 기기 툴바로 화면 폭 바꿔 보기

창을 손으로 끄는 것으로는 지금 폭이 몇 px 인지 알 수 없습니다. 크롬에 폭을 숫자로 정해 놓고 보는 기능이 있습니다. 이 단원은 이것 없이는 못 배웁니다.

  1. F12 를 누릅니다. 화면 오른쪽(또는 아래) 에 개발자 도구가 열립니다.
  2. Ctrl + Shift + M 을 누릅니다. 개발자 도구 왼쪽 위의 휴대폰 모양 아이콘을 눌러도 같습니다. 페이지가 좁은 화면으로 바뀝니다.
  3. 페이지 위쪽에 생긴 막대에서 기기 이름 칸을 Responsive (반응형) 로 바꿉니다. 그래야 폭을 마음대로 정할 수 있습니다.
  4. 그 옆의 숫자 칸에 폭을 직접 칩니다. 360 을 넣어 보세요. 작은 휴대폰 크기입니다.
  5. 폭을 480 → 600 → 768 → 1024 로 하나씩 바꾸면서 이 페이지의 섹션 4, 5, 6 상자가 어떻게 변하는지 보세요.
  6. 다 봤으면 Ctrl + Shift + M 을 다시 눌러 끄고, F12 로 개발자 도구를 닫습니다.

폭 숫자가 이상하게 나온다면 브라우저 확대 배율을 확인하세요. Ctrl + 0 을 누르면 100% 로 돌아갑니다. 확대가 걸려 있으면 미디어쿼리가 판단하는 폭도 같이 달라집니다.

✏️ 직접 해보기 3 — 위 순서대로 기기 툴바를 켜고 폭을 375 로 맞춰 보세요. 그 상태에서 아래 섹션 4 의 띠가 무슨 색인지 확인하고, 폭을 800 으로 바꿔 다시 확인하세요.

섹션 4 — @media (max-width) 로 좁을 때만 다르게

@media 는 "이 조건일 때만 이 CSS 를 적용해라" 라는 뜻입니다. 조건이 안 맞으면 그 안의 규칙은 아예 없는 것이 됩니다.

실제 결과 — 창 폭에 따라 띠가 바뀝니다

넓은 화면입니다 (601px 이상)

좁은 화면입니다 (600px 이하)

✏️ 직접 해보기 4 — @media (max-width: 600px) 의 600 을 1000 으로 바꿔 보세요. 창을 좁히지 않아도 주황 띠로 바뀝니다. 왜 그런지 설명해 보고, 확인했으면 600 으로 되돌리세요.

섹션 5 — @media (min-width) 와 흔한 중단점

min-width 는 반대입니다. "이 폭 이상일 때" 적용합니다. 배치가 바뀌는 기준 폭을 중단점(breakpoint) 이라고 부릅니다.

실제 결과 — 700px 이상이면 초록

min-width: 700px 조건이 맞으면 초록, 아니면 회색입니다

중단점 대략 어떤 기기 보통 이렇게 씁니다
기본 (조건 없음) 휴대폰 1단으로 세로로 쌓기
600px 이상 큰 휴대폰 가로, 작은 태블릿 2단으로 나누기
900px 이상 태블릿 가로, 노트북 3단, 옆 메뉴 보이기
1280px 이상 데스크톱 가운데 폭 제한, 여백 늘리기

✏️ 직접 해보기 5 — .mq-min 의 조건을 @media (max-width: 700px) 로 바꿔 보세요. 색이 언제 초록이 되는지가 정확히 반대로 뒤집힙니다. 확인했으면 되돌리세요.

섹션 6 — 미디어쿼리로 격자의 칸 수를 바꿉니다

13단원의 두 축이 여기서 만납니다. grid 로 칸을 만들고, @media 로 칸 수를 바꿉니다.

실제 결과 — 1칸 → 2칸 → 3칸

✏️ 직접 해보기 6 — 기기 툴바에서 폭을 599 로 맞췄다가 600 으로 한 칸 올려 보세요. 1px 차이로 배치가 바뀝니다. 이 순간이 바로 중단점입니다.

섹션 7 — 자주 하는 실수

미디어쿼리의 실수는 대부분 "아무 일도 안 일어난다" 로 나타납니다. 조건이 한 번도 맞지 않으면 그 안의 CSS 는 없는 것과 같기 때문입니다.

실수 1 — viewport meta 를 빠뜨림
<head> <meta charset="UTF-8" /> <title>내 페이지</title> </head>

무슨 일이 일어나나요: PC 에서는 멀쩡합니다. 그런데 휴대폰에서 열면 글자가 개미만 하게 축소되어 보이고, 정성껏 쓴 미디어쿼리가 하나도 안 먹습니다. 브라우저가 화면 폭을 980px 이라고 믿고 있기 때문입니다. 이 단원에서 가장 비싼 실수입니다.

이렇게 쓰세요
<meta name="viewport" content="width=device-width, initial-scale=1" />
실수 2 — min-width 와 max-width 를 반대로 씀
/* 휴대폰에서 1칸으로 만들려고 */ @media (min-width: 600px) { .cards { grid-template-columns: 1fr; } }

무슨 일이 일어나나요: 정확히 반대로 동작합니다. 넓은 화면에서 1칸이 되고 휴대폰에서는 그대로입니다. min-width 는 "이 값 이상", max-width 는 "이 값 이하" 입니다. 이름의 min/max 가 화면 크기가 아니라 조건의 경계값을 가리킨다고 생각하면 덜 헷갈립니다.

실수 3 — @media 안에 선택자를 안 씀
@media (max-width: 600px) { grid-template-columns: 1fr; }

무슨 일이 일어나나요: 아무 일도 안 일어납니다. @media 안에는 규칙 전체가 들어가야 합니다. 즉 선택자와 중괄호를 한 번 더 써야 합니다. 선언만 덜렁 쓰면 무시됩니다. "중괄호가 두 겹" 이라는 것을 기억하세요.

이렇게 쓰세요
@media (max-width: 600px) { .cards { grid-template-columns: 1fr; } }
실수 4 — 조건에 단위를 안 씀
@media (max-width: 600) { .cards { grid-template-columns: 1fr; } }

무슨 일이 일어나나요: 조건이 절대 맞지 않아 그 안의 CSS 가 한 번도 적용되지 않습니다. 600 이 아니라 600px 이어야 합니다. CSS 는 0 말고는 단위를 생략할 수 없습니다.

실수 5 — @media 를 기본 규칙보다 위에 씀
@media (min-width: 900px) { .cards { grid-template-columns: 1fr 1fr 1fr; } } .cards { grid-template-columns: 1fr; } /* 나중에 쓴 이쪽이 이깁니다 */

무슨 일이 일어나나요: 넓은 화면에서도 계속 1칸입니다. 명시도가 같으면 나중에 쓴 규칙이 이깁니다(08단원). @media 는 명시도를 올려 주지 않으므로 순서에서 밀리면 그냥 집니다. 기본 규칙을 먼저, 미디어쿼리를 아래에 쓰세요.

실수 6 — 미디어쿼리 안의 규칙이 명시도에서 짐
#cardList { grid-template-columns: 1fr 1fr 1fr; } /* 1-0-0 */ @media (max-width: 600px) { .cards { grid-template-columns: 1fr; } /* 0-1-0 */ }

무슨 일이 일어나나요: 좁은 화면에서도 3칸 그대로입니다. @media 안에 있다고 해서 더 세지지 않습니다. id 선택자가 클래스 선택자를 이기는 것은 그대로입니다(08단원). 안에서든 밖에서든 같은 선택자를 쓰는 것이 가장 안전합니다.

── 정리 ──

1. 뷰포트는 브라우저에서 페이지가 실제로 그려지는 영역입니다.

2. <meta name="viewport" content="width=device-width, initial-scale=1" /> 를 항상 넣습니다. 없으면 휴대폰에서 미디어쿼리가 안 먹습니다.

3. F12 → Ctrl+Shift+M 으로 폭을 숫자로 정해 놓고 확인합니다.

4. @media (max-width: 600px) 는 좁을 때, @media (min-width: 600px) 는 넓을 때입니다. 경계값은 포함입니다.

5. @media 안에는 선택자까지 씁니다. 중괄호가 두 겹입니다.

6. 흔한 중단점은 600px 과 900px 두 개면 대개 충분합니다.

7. @media 는 명시도를 올려 주지 않습니다. 순서와 선택자 무게를 지키세요.
