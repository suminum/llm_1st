개념 02 — 방향과 줄바꿈

12단원 · Flexbox

이 파일은 flex-direction 과 flex-wrap 두 속성만 다룹니다. 둘 다 컨테이너에 쓰는 속성입니다. 아래 옅은 파란 칸(무대)의 안쪽 폭은 모두 600px 이니, 상자 폭을 더해 보면서 읽으세요.

이 파일에 나오는 "왼쪽 좌표" 는 브라우저 창을 1280px 로 놓고 잰 값입니다. 본문이 가운데 정렬이라 창 폭이 다르면 숫자가 통째로 좌우로 밀립니다. 숫자 자체를 외우지 말고, 상자들 사이의 차이(간격·나뉜 몫)를 보세요. 그 차이는 창 폭과 상관없이 늘 같습니다.

섹션 1 — flex-direction: row (기본값)

display: flex 만 썼을 때 이미 적용되어 있는 값이 flex-direction: row 입니다.

flex-direction: row

1
2
3

flex-direction 은 컨테이너에 쓰는 속성입니다. 상자 하나하나에 쓰면 아무 일도 일어나지 않습니다.

✏️ 직접 해보기 1 — .row-stage 안에 <div class="tile">4</div> 를 하나 더 넣어 보세요. 120px 짜리가 네 개가 되어 480px 을 쓰고 120px 이 남습니다.

섹션 2 — flex-direction: column 이면 축이 통째로 바뀝니다

이 섹션이 이 파일에서 가장 중요합니다. 방향을 바꾸면 주축과 교차축이 서로 자리를 바꿉니다.

flex-direction: column

1
2
3

column 인데 폭을 120px 로 정한 경우

1

지금 당장 외울 문장은 이것입니다. row 면 주축이 가로, column 이면 주축이 세로. 개념03·04 의 정렬 속성이 전부 이 문장 위에 얹힙니다.

✏️ 직접 해보기 2 — <style> 에 .col-fixed-stage .tile { width: 300px; } 규칙을 새로 넣어 보세요. 세로로 쌓인 채 폭만 넓어집니다. 주축(세로)은 그대로이고 교차축(가로) 크기만 바뀐 것입니다.

섹션 3 — row-reverse 와 column-reverse

뒤에 -reverse 를 붙이면 줄을 채우기 시작하는 쪽이 반대가 됩니다.

1
2
3

-reverse 는 보이는 순서만 뒤집습니다. HTML 에 적힌 순서는 그대로입니다. 그래서 눈으로 읽는 순서와 코드 순서가 달라집니다. 화면을 보지 않고 코드 순서대로 읽어 주는 프로그램을 쓰는 사람에게는 여전히 1, 2, 3 으로 읽힙니다. 꼭 필요할 때만 쓰세요.

✏️ 직접 해보기 3 — .colrev-stage 의 값을 flex-direction: column 으로 바꿔 보세요. 상자들이 무대 위쪽으로 올라가고 순서도 1, 2, 3 이 됩니다.

섹션 7 — 자주 하는 실수

아래 다섯 가지 모두 에러가 나지 않습니다. 화면이 생각과 다를 뿐입니다.

실수 1 — display: flex 를 빼먹고 flex-direction 만 씀
.noflex-stage { flex-direction: row; } /* display 가 없습니다 */

아무 일도 일어나지 않습니다. flex-direction 은 flex 컨테이너에게만 뜻이 있는 속성입니다. 컨테이너가 아니면 브라우저는 이 줄을 조용히 넘깁니다. 아래가 그 결과입니다.

1
2
이렇게 쓰세요
.noflex-stage { display: flex; flex-direction: row; }
실수 2 — column 에서 좌우로 옮기려고 justify-content 를 씀
.swap-stage { flex-direction: column; justify-content: center; }

상자가 좌우 가운데로 갈 거라 기대하지만 위아래 가운데로 갑니다. column 에서는 주축이 세로이고, justify-content 는 주축을 다루기 때문입니다. 좌우로 옮기려면 개념04 에서 배울 align-items 를 써야 합니다.

1
2
실수 3 — flex-wrap 을 안 줘서 상자가 찌그러짐
.nowrap-stage { display: flex; } /* flex-wrap 이 없습니다 */

width: 150px 이라고 분명히 썼는데 화면에서는 120px 입니다. "내가 준 폭이 왜 안 먹지?" 하고 width 만 계속 들여다보게 되는데, 범인은 빠진 flex-wrap 한 줄입니다. 섹션 4 와 섹션 5 를 나란히 비교해 보세요.

실수 4 — 상자 하나하나에 flex-direction 을 씀
.tile { flex-direction: column; } /* 아이템에 썼습니다 */

아무 변화가 없습니다. 방향은 컨테이너가 아이템들을 어느 쪽으로 줄 세울지 정하는 것입니다. 아이템 자신은 자기가 어디에 놓일지 정하지 못합니다. 개념01 섹션 5 의 표를 다시 보세요.

실수 5 — 값을 vertical, horizontal 이라고 씀
.col-stage { flex-direction: vertical; } /* 그런 값은 없습니다 */

그 한 줄이 통째로 버려지고 기본값 row 로 남습니다. 세로로 세우고 싶었는데 가로로 그대로 있는 것이 유일한 신호입니다. 값은 row, column, row-reverse, column-reverse 네 개뿐입니다.

── 정리 ──

1. flex-direction 의 기본값은 row, 즉 왼쪽에서 오른쪽입니다.

2. column 으로 바꾸면 주축이 세로, 교차축이 가로가 됩니다.

3. -reverse 는 채우기 시작하는 쪽을 반대로 바꿉니다. HTML 순서는 그대로입니다.

4. flex-wrap 의 기본값은 nowrap 이라, 자리가 모자라면 아이템이 찌그러집니다.

5. flex-wrap: wrap 을 주면 아랫줄로 내려가고 아이템은 원래 폭을 지킵니다.

6. flex-flow: row wrap 은 두 속성을 한 줄로 합친 단축입니다.

7. 네 속성 모두 컨테이너에 쓰는 속성입니다.
