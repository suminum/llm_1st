개념 04 — absolute 와 fixed

11단원 · 배치 (display와 position)

이 파일에는 스크롤해야만 보이는 데모가 두 개 있습니다(섹션 3, 섹션 4). 화면 왼쪽 아래 구석에 붙어 있는 검은 쪽지도 이 파일이 만든 것입니다. 마우스 휠을 굴리면서 무엇이 따라오고 무엇이 안 따라오는지 보세요.

섹션 3 — fixed 는 화면에 붙습니다

fixed 의 기준은 페이지가 아니라 브라우저 창입니다. 그래서 스크롤해도 안 움직입니다.

이 "브라우저 창" 을 정확히는 뷰포트(viewport) 라고 부릅니다. 페이지가 실제로 그려지는 영역이라는 뜻입니다. 13단원에서 화면 크기에 따라 모양을 바꿀 때 이 이름으로 다시 나옵니다.

섹션 5 — 다섯 값을 한 표로

여기까지 나온 position 값 다섯 개를 한자리에 놓고 비교합니다. 이 표 하나면 이 단원의 절반이 정리됩니다.

position 다섯 값 비교

값 무엇을 기준으로 놓나 흐름에서 빠지나 top·left 가 먹나 스크롤하면
static 기준 없음 (흐름이 준 자리) 아니요 안 먹습니다 같이 흘러갑니다
relative 자기 자신의 원래 자리 아니요 (자리 남음) 먹습니다 같이 흘러갑니다
absolute static 이 아닌 가장 가까운 조상 네 (자리 없어짐) 먹습니다 같이 흘러갑니다
fixed 브라우저 창 네 (자리 없어짐) 먹습니다 안 움직입니다
sticky 평소엔 원래 자리, 닿으면 스크롤 영역 아니요 (자리 남음) 붙을 지점을 정합니다 어느 지점부터 붙습니다

✏️ 직접 해보기 5 — .fixed-note 의 position 을 absolute 로 바꿔 보세요. 처음에는 아무것도 안 바뀐 것처럼 보이는데, 스크롤을 내리면 쪽지가 페이지와 함께 위로 흘러가 사라집니다. 표의 '스크롤하면' 칸과 맞는지 확인하세요. 확인했으면 fixed 로 되돌려 놓으세요.

섹션 6 — 자주 하는 실수

absolute 는 잘못 쓰면 요소가 엉뚱한 곳으로 사라집니다. 어디로 갔는지 찾는 방법까지 같이 익혀 두세요.

실수 1 — 부모에 relative 를 안 걸고 absolute 를 씀
.card { border: 2px solid #999; } /* relative 가 없습니다 */ .badge { position: absolute; top: 6px; left: 6px; }

아래 붉은 카드 안에 배지를 넣었는데 카드 안에 안 보입니다. 기준이 될 조상을 못 찾아서 페이지 맨 위 왼쪽 구석으로 날아갔습니다. 지금 페이지를 맨 위까지 올려서 왼쪽 구석을 보세요. 거기 붙어 있습니다.

길 잃은 배지

이 카드 안에 배지가 있어야 하는데 비어 있습니다.

이렇게 하세요
.card { position: relative; border: 2px solid #999; } .badge { position: absolute; top: 6px; left: 6px; }
실수 2 — absolute 로 바꿨더니 아래 내용이 위로 올라옴
.item2 { position: absolute; top: 0; left: 300px; }

옮긴 요소만 신경 쓰다가 남은 요소들이 다 같이 올라오는 것을 놓칩니다. 흐름에서 빠지면 그 자리가 통째로 없어지기 때문입니다. 자리를 남기고 싶다면 absolute 가 아니라 relative 를 써야 합니다.

실수 3 — absolute 로 바꿨더니 상자가 홀쭉해짐
.panel { position: absolute; top: 0; left: 0; }

div 는 블록이라 원래 가로를 꽉 채웠는데, absolute 가 되는 순간 글자 길이만큼으로 줄어듭니다. 흐름에서 빠지면 "부모 폭을 꽉 채운다" 는 규칙도 같이 사라지기 때문입니다. 폭이 필요하면 width 를 직접 적어 주세요.

실수 4 — fixed 가 부모 상자 기준일 거라고 생각함
.box { position: relative; } .inner { position: fixed; top: 0; left: 0; }

.inner 는 .box 왼쪽 위가 아니라 브라우저 창 왼쪽 위 구석에 붙습니다. fixed 는 조상을 아예 쳐다보지 않습니다. 부모 안에 붙이고 싶으면 absolute 를 쓰세요.

실수 5 — sticky 를 썼는데 안 붙음
.head { position: sticky; }

아무 일도 안 일어납니다. 어디에 붙을지를 안 말해 줬기 때문입니다. top: 0; 처럼 붙을 지점을 반드시 같이 적어야 합니다. 부모에 overflow: hidden 이 걸려 있어도 안 붙으니 그것도 확인하세요.

── 정리 ──

1. absolute 와 fixed 는 흐름에서 빠집니다. 자리가 없어집니다.

2. absolute 의 기준은 static 이 아닌 가장 가까운 조상입니다.

3. 그래서 부모에 relative, 자식에 absolute 가 한 쌍입니다.

4. fixed 의 기준은 브라우저 창이라 스크롤해도 안 움직입니다.

5. sticky 는 평소엔 흐름 안에 있다가 정해진 지점에서 붙습니다. top 필수입니다.

6. 흐름에서 빠진 요소는 width 를 안 주면 글자 길이만큼으로 줄어듭니다.

저는 fixed 입니다. 스크롤해도 이 자리에 남습니다.
