개념 03 — position 기초

11단원 · 배치 (display와 position)

이 파일에서는 position 의 기본값 static 과 첫 번째 값 relative 두 개만 다룹니다. "top 을 줬는데 왜 안 움직이지?" 의 답이 섹션 2 에 있습니다.

섹션 1 — 모든 요소는 이미 position 을 갖고 있습니다

position 을 안 썼다고 없는 것이 아닙니다. 안 쓰면 static 입니다. 그게 기본값입니다.

섹션 2 — static 에는 top·left 가 안 먹습니다

아래 분홍 상자에는 top: 40px; left: 60px; 이 분명히 적혀 있습니다. 그런데 조금도 안 움직입니다.

기억할 한 줄입니다. top·right·bottom·left 를 쓰기 전에는 반드시 position 을 먼저 바꿔야 합니다.

섹션 3 — relative 는 원래 자리를 남겨 둡니다

relative 로 옮긴 요소는 겉모습만 이동합니다. 흐름이 잡아 둔 원래 자리는 그대로 비어 있습니다.

섹션 5 — 자주 하는 실수

position 을 배우고 나면 실수의 모양이 늘 비슷합니다. 코드는 멀쩡한데 화면이 안 바뀝니다.

실수 1 — position 을 안 바꾸고 top 만 줌
.box { top: 40px; left: 60px; }

아무 일도 안 일어납니다. position 을 안 썼으니 기본값 static 이고, static 에는 top·left 가 안 먹습니다. 이 단원에서 가장 많이 나는 실수입니다.

이렇게 하세요
.box { position: relative; top: 40px; left: 60px; }
실수 2 — relative 로 옮기면 원래 자리도 따라올 거라고 생각함
.item2 { position: relative; left: 200px; }

옮긴 요소만 이동하고 원래 자리는 빈칸으로 남습니다. 그래서 "가운데가 뻥 뚫렸어요" 라는 말이 나옵니다. 고장이 아니라 원래 그렇습니다. 자리까지 없애고 싶으면 relative 가 아니라 absolute 를 써야 합니다(개념04).

실수 3 — 단위를 빠뜨림
.box { position: relative; top: 40; }

그 줄만 조용히 무시됩니다. position 은 잘 먹었는데 top 만 안 먹은 상태라 더 헷갈립니다. 0 을 뺀 모든 숫자에는 px 같은 단위가 필요합니다(09단원).

실수 4 — relative 로 크게 옮겨서 옆 요소를 덮음
.menu { position: relative; left: 300px; }

옆 요소는 비켜 주지 않습니다. 옮긴 요소가 그 위를 덮어 버려서 아래 글자가 가려집니다. 클릭도 안 됩니다. 큰 이동에는 relative 대신 absolute 를 쓰거나, 아예 12단원의 flex 로 배치를 다시 짜야 합니다.

실수 5 — relative 만 썼는데 안 움직인다고 당황함
.stage { position: relative; }

이건 실수가 아닙니다. relative 는 옮길 준비만 시킵니다. 얼마나 옮길지는 top·left 로 따로 말해 줘야 합니다. 그리고 일부러 안 움직이게 두는 이 한 줄이 개념04 의 가장 중요한 관용구가 됩니다.

── 정리 ──

1. position 의 기본값은 static 이고, 흐름이 준 자리에 그대로 있습니다.

2. top·right·bottom·left 는 static 에는 안 먹습니다.

3. relative 의 기준은 자기 자신의 원래 자리입니다.

4. relative 는 원래 자리를 남겨 둔 채 겉모습만 옮깁니다.

5. 옆 요소가 비켜 주지 않으므로 큰 이동에는 맞지 않습니다. 미세 조정용입니다.

6. position: relative; 한 줄만 쓰는 것은 기준점 표시입니다(개념04).
