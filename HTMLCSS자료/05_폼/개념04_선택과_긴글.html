개념 04 — select 로 고르기, textarea 로 긴 글 받기

05단원 · 폼

이 파일에는 접히는 목록과 여러 줄 입력칸이 살아 있는 채로 들어 있습니다. 목록을 펼쳐 보고, 긴 글 칸에 엔터를 쳐 가며 여러 줄을 써 보세요. 섹션 5 의 "공백이 값이 된다" 는 이 단원에서 두 번째로 큰 함정입니다.

섹션 1 — select 와 option: 접히는 목록

<select> 가 목록 상자이고, 그 안의 <option> 하나하나가 고를 수 있는 항목입니다.

실제 결과 — 상자를 눌러 펼쳐 보세요

상자의 가로 크기는 가장 긴 항목 글자에 맞춰 저절로 정해집니다. 그래서 항목 이름이 짧으면 상자도 아주 작아집니다. 크기를 직접 정하는 방법은 10단원에서 배웁니다.

✏️ 직접 해보기 1 — 위 목록 맨 위에 <option value="">고르세요</option> 를 한 줄 넣어 보세요. 새로고침하면 처음 보이는 글자가 "서울" 에서 "고르세요" 로 바뀝니다.

섹션 2 — 보이는 글자와 보내는 값은 다를 수 있습니다

option 의 value 가 실제로 보내지는 값이고, 태그 사이의 글자는 화면에 보여 주는 글자입니다.

실제 결과 — 처음부터 "부산" 이 골라져 있습니다

✏️ 직접 해보기 2 — 위 목록에서 selected 를 "대구" 줄로 옮겨 보세요. 새로고침하면 처음 보이는 글자가 "대구" 가 됩니다. value 는 그대로 두세요. 화면 글자만 바뀌는 것을 확인하는 것이 목적입니다.

섹션 3 — optgroup 으로 묶기, multiple 과 size

항목이 많아지면 optgroup 으로 묶고, 여러 개를 고르게 하려면 multiple 을 붙입니다.

실제 결과 — 셋을 비교해 보세요

✏️ 직접 해보기 3 — "여러 개 고르기" 목록에서 multiple 만 지워 보세요. 새로고침하면 목록판 모양은 그대로인데 이제 한 줄만 골라집니다. size 는 모양을, multiple 은 개수를 정한다는 뜻입니다.

섹션 4 — textarea: 여러 줄짜리 긴 글

rows 는 보이는 줄 수, cols 는 보이는 가로 글자 수입니다.

실제 결과 — 엔터를 쳐 가며 여러 줄을 써 보세요

✏️ 직접 해보기 4 — 위 칸의 rows="4" 를 rows="10" 으로 바꿔 보세요. 새로고침하면 칸이 세로로 길어집니다. cols 도 60 으로 바꿔 가로 길이를 늘려 보세요.

섹션 5 — 함정: 태그 사이의 공백이 그대로 값이 됩니다

textarea 는 여는 태그와 닫는 태그 사이의 모든 글자를 처음 값으로 삼습니다. 눈에 안 보이는 띄어쓰기와 줄바꿈까지 포함해서입니다.

잘못된 예 — 보기 좋게 들여씀
<textarea rows="3" cols="30"> 안녕하세요 </textarea>

글자가 오른쪽으로 밀려서 시작합니다. 앞에 공백 네 칸이 값으로 들어가 있기 때문입니다. 칸 안을 눌러 커서를 맨 앞으로 옮긴 뒤 백스페이스를 눌러 보면 공백이 하나씩 지워집니다.

올바른 예 — 딱 붙여서 씀
<textarea rows="3" cols="30">안녕하세요</textarea>

글자가 왼쪽 벽에 딱 붙어서 시작합니다. 값이 정확히 "안녕하세요" 다섯 글자뿐입니다.

진짜로 빈 칸을 만들고 싶으면 <textarea></textarea> 처럼 사이에 아무것도 넣지 마세요. 엔터 한 번, 스페이스 한 칸도 안 됩니다.

✏️ 직접 해보기 5 — 잘못된 예의 <textarea> 안에서 줄바꿈과 공백을 전부 지워 <textarea id="trapArea" rows="3" cols="30">안녕하세요</textarea> 로 만들어 보세요. 새로고침하면 글자가 왼쪽 벽에 붙습니다.

섹션 6 — datalist 맛보기: 추천 목록이 뜨는 글자 칸

datalist 는 글자 칸에 추천 목록을 붙이는 태그입니다. 목록에 없는 값을 직접 쳐 넣어도 됩니다.

실제 결과 — 칸을 누르거나 "서" 를 쳐 보세요

✏️ 직접 해보기 6 — 위 datalist 안에 <option value="대전"></option> 을 한 줄 넣어 보세요. 새로고침하고 칸을 누르면 추천이 다섯 줄로 늘어납니다.

섹션 7 — 자주 하는 실수

textarea 관련 실수는 값이 조용히 오염되는 종류입니다. 화면만 슬쩍 봐서는 잘 모릅니다.

실수 1 — textarea 안을 보기 좋게 들여씀
<textarea name="memo" rows="3" cols="30"> </textarea>

빈 칸을 만들려던 것인데 줄바꿈과 공백이 값으로 들어갑니다. 사용자가 아무것도 안 써도 빈 값이 아니게 되고, 개념06 의 required 검사도 그냥 통과해 버립니다. 아래 칸을 누른 뒤 Ctrl+A 로 전체 선택을 해 보세요. 숨어 있던 공백이 드러납니다.

이렇게 쓰세요
<textarea name="memo" rows="3" cols="30"></textarea>

실수 2 — textarea 를 input 처럼 빗금으로 닫음
<textarea rows="2" cols="30" />그다음에 쓴 글자

textarea 는 빈 태그가 아닙니다. 끝의 빗금은 무시되고 태그가 열린 채로 남습니다. 그래서 뒤에 오는 글자가 전부 칸 안으로 빨려 들어갑니다. 닫는 태그를 만날 때까지 계속 먹습니다. 페이지 절반이 칸 안에 들어가기도 합니다.

아래 살아 있는 예에는 </textarea> 를 한 문장 뒤에 일부러 붙여 두었습니다. 안 붙이면 이 페이지의 나머지가 전부 칸 안으로 빨려 들어가 아래 내용을 하나도 못 보게 되기 때문입니다. 그래서 여기서는 한 문장만 삼켜진 모습을 보여 줍니다.

실수 3 — textarea 에 value 를 씀
<textarea rows="2" cols="30" value="안녕하세요"> </textarea>

input 버릇대로 쓴 것입니다. 아무 일도 안 일어납니다. 칸은 빈 채로 나오고 경고도 없습니다. textarea 에는 value 속성이 아예 없습니다. 처음 값은 태그 사이에 씁니다.

실수 4 — select 안에 option 없이 글자만 씀
<select name="city">서울 부산 대구</select>

아무 항목도 없는 아주 작은 빈 상자가 나옵니다. 눌러도 펼쳐지지 않습니다. 글자는 화면에 나오지도 않습니다. select 는 option 만 항목으로 인정하기 때문입니다.

실수 5 — 한 select 안에 selected 를 여러 개 씀
<option value="a" selected>가</option> <option value="b" selected>나</option>

둘 다 골라지지 않습니다. 마지막 것 하나만 골라집니다. 여러 개를 고르게 하려면 multiple 을 붙여야 하고, 그때는 목록판 모양으로 바뀝니다.

── 정리 ──

1. <select> 안에 <option> 을 넣습니다. name 은 select 에 붙입니다.

2. option 의 value 가 보내는 값, 태그 사이 글자가 보이는 글자입니다.

3. selected 는 처음 고를 항목, optgroup 은 묶음 제목입니다.

4. multiple 은 여러 개 고르기, size 는 펼쳐 보일 줄 수입니다.

5. <textarea> 는 rows 와 cols 로 크기를 잡습니다.

6. textarea 는 태그 사이의 공백과 줄바꿈까지 값이 됩니다. 딱 붙여 쓰세요.

7. datalist 는 추천만 해 줍니다. 목록 밖의 값도 쳐 넣을 수 있습니다.
