개념 01 — 웹페이지와 HTML

01단원 · HTML 시작하기

이 파일은 웹페이지가 무엇인지와 내 손으로 웹페이지 파일을 만들어 여는 방법을 다룹니다. 코드보다 손을 움직이는 내용이 많습니다. 읽기만 하지 말고 꼭 따라 해 보세요. 마지막 섹션에는 01단원에서 앞으로 배울 것의 지도가 있습니다.

섹션 1 — 웹페이지도 결국 '파일' 입니다

웹페이지는 신기한 무엇이 아니라 글자가 적힌 파일 하나입니다. 브라우저는 그 파일을 읽어서 화면으로 그려 주는 프로그램입니다.

실제 결과

이 글자는 파일 안에 적혀 있던 글자입니다.

브라우저는 크롬, 엣지, 파이어폭스, 사파리 같은 프로그램을 말합니다. 이 자료는 크롬을 기준으로 씁니다. 다른 브라우저를 써도 대부분 같지만, 화면이 조금 다를 수 있습니다.

✏️ 직접 해보기 1 — VS Code 에서 이 파일을 열고 Ctrl+F 를 눌러 이 글자는 파일 안에 를 검색해 보세요. 코드 안에서 그 줄을 찾으면 "화면의 글자는 파일 어딘가에 반드시 적혀 있다" 를 확인한 것입니다.

섹션 2 — HTML 은 글에 '이름표' 를 붙이는 일입니다

HTML 로 하는 일은 딱 하나입니다. 글자 덩어리마다 "이건 무엇이다" 라는 이름표를 붙이는 것입니다.

이름표를 붙여서 쓴 글

오늘의 메뉴

김치찌개 8000원

된장찌개 8000원

✏️ 직접 해보기 2 — 위 상자 안에 <p>순두부찌개 9000원</p> 를 한 줄 더 넣어 보세요. 저장하고(Ctrl+S) 브라우저에서 새로고침(F5) 하면 줄이 하나 늘어납니다.

섹션 3 — 이름표가 없으면 어떻게 되나

이름표를 안 붙이고 글자만 쓰면, 아무리 줄을 나눠 써도 브라우저는 전부 한 줄로 이어 붙여 버립니다.

이름표 없이 글자만 쓴 결과

오늘의 메뉴 김치찌개 8000원 된장찌개 8000원

같은 글자인데 화면이 다릅니다. 달라진 것은 이름표를 붙였는지 여부뿐입니다. 이것이 HTML 을 배우는 이유입니다.

✏️ 직접 해보기 3 — 위 상자 안의 글을 브라우저에서 마우스로 드래그해 보세요. 한 줄로 이어진 글자 전체가 끊긴 데 없이 한 덩어리로 칠해집니다. 그다음 섹션 2 의 상자를 드래그해서 어떻게 다른지 비교해 보세요.

섹션 4 — 내 손으로 .html 파일 만들기

읽기만 해서는 늘지 않습니다. 지금 빈 파일 하나를 직접 만들어 브라우저로 열어 봅니다.

<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8" /> <title>내 첫 웹페이지</title> </head> <body> <p>안녕하세요. 제 첫 웹페이지입니다.</p> </body> </html>

first.html 을 열었을 때 나오는 화면

안녕하세요. 제 첫 웹페이지입니다.

브라우저 주소창을 보면 file:///C:/Users/... 로 시작합니다. 인터넷에서 받아 온 것이 아니라 내 컴퓨터의 파일을 그대로 연 것이라는 뜻입니다. 인터넷이 끊겨 있어도 잘 보입니다.

✏️ 직접 해보기 4 — 위 코드로 first.html 을 만들어 브라우저로 열어 보세요. 그다음 <p> 로 감싼 줄의 글자를 여러분 이름으로 바꿔 보세요.

섹션 5 — 저장(Ctrl+S) → 새로고침(F5)

코드를 고쳤는데 화면이 그대로일 때, 원인의 거의 전부는 이 두 가지입니다. 저장을 안 했거나, 새로고침을 안 했거나.

실제 결과

이 문장을 고쳐 보세요.

고쳤는데 안 바뀐다고 코드를 다시 뜯어보기 전에, Ctrl+S 를 눌렀는지부터 확인하세요. 초보자가 시간을 가장 많이 버리는 지점입니다.

✏️ 직접 해보기 5 — 위 문장을 VS Code 에서 다른 문장으로 바꾸되, 저장하지 말고 먼저 F5 를 눌러 보세요. 화면이 안 바뀝니다. 그다음 Ctrl+S 로 저장하고 다시 F5 를 눌러 보세요. 이제 바뀝니다.

섹션 7 — 자주 하는 실수

여기 나오는 것들은 에러 메시지가 뜨지 않습니다. 그냥 원하는 화면이 안 나올 뿐입니다. 그래서 스스로 알아채야 합니다.

실수 1 — 파일 이름이 first.html.txt 가 됨
first.html.txt

메모장에서 파일 형식을 텍스트 문서 그대로 두고 저장하면 이렇게 됩니다. 더블클릭하면 브라우저가 아니라 메모장이 다시 열립니다. 코드가 화면에 글자 그대로 보이면 십중팔구 이 경우입니다.

이렇게 하세요
first.html

메모장이라면 저장할 때 파일 형식을 모든 파일 로 바꾸세요. VS Code 로 만들면 이 문제가 아예 생기지 않습니다.

실수 2 — 확장자를 .hmtl 로 잘못 침
first.hmtl

html 의 글자 순서가 바뀌었습니다. 컴퓨터는 이런 확장자를 모르니 어떤 프로그램으로 열어야 할지 물어보는 창이 뜨거나, 엉뚱한 프로그램이 열립니다. 이름을 고치면 바로 해결됩니다.

실수 3 — 저장하지 않고 새로고침

코드를 고쳤는데 화면이 하나도 안 바뀝니다. 에러도 안 납니다. VS Code 탭 이름 옆에 흰 동그라미가 있으면 아직 저장 전입니다. Ctrl+S 를 누르고 다시 F5 를 누르세요.

실수 4 — 저장은 했는데 새로고침을 안 함

이 경우도 화면이 안 바뀝니다. 브라우저는 한 번 읽은 화면을 계속 들고 있습니다. F5 를 눌러야 파일을 다시 읽습니다.

실수 5 — 워드나 한글 프로그램으로 코드를 씀

워드나 한글은 글자 말고도 글꼴·색·표 같은 정보를 파일에 함께 저장합니다. 그래서 브라우저가 읽으면 이상한 글자가 잔뜩 섞여 나오거나 아예 안 열립니다. 코드는 반드시 VS Code 나 메모장처럼 글자만 저장하는 프로그램으로 씁니다.

── 정리 ──

1. 웹페이지는 확장자가 .html 인 파일 하나이고, 브라우저가 그것을 읽어 그립니다.

2. HTML 은 글자 덩어리에 "이건 무엇이다" 라는 이름표를 붙이는 언어입니다.

3. 이름표를 안 붙이면 여러 줄로 써도 한 줄로 이어져 나옵니다.

4. 파일은 VS Code(또는 메모장)로 만들고, 더블클릭하면 브라우저가 엽니다.

5. 고쳤으면 Ctrl+S 로 저장하고 F5 로 새로고침합니다. 둘 다 해야 화면이 바뀝니다.

6. HTML 은 틀려도 에러가 안 납니다. 화면을 눈으로 확인하는 것이 유일한 확인 방법입니다.
