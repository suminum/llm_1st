섹션 5 — 자주 하는 실수

다시 한 번 강조합니다. 아래 실수들은 전부 에러가 나지 않습니다. 화면이 이상해질 뿐입니다. 그래서 눈으로 알아채는 연습이 필요합니다.

실수 1 — 닫는 태그에 빗금(/) 을 안 씀
<p>안녕하세요<p>

닫으려고 쓴 <p> 가 사실은 새 문단을 여는 태그입니다. 그래서 빈 문단이 하나 더 생깁니다. 글자는 그대로 보이니 알아채기 어렵습니다.

이렇게 쓰세요
<p>안녕하세요</p>
실수 2 — 태그 이름을 대문자로 씀
<P>안녕하세요</P>

이건 실제로 잘 동작합니다. 태그 이름은 대소문자를 가리지 않습니다. 그런데도 실수로 치는 이유는, 요즘 코드는 전부 소문자로 쓰기로 약속되어 있어서 대문자가 섞이면 남이 읽을 때 걸리기 때문입니다. 항상 소문자로 쓰세요.

실수 3 — 나중에 연 태그를 나중에 닫음
<p>오늘은 <strong>화요일</p></strong>

브라우저가 알아서 순서를 바로잡아 그립니다. 이 예에서는 운이 좋아서 제대로 쓴 것과 완전히 똑같은 결과가 나옵니다. 그래서 화면만 봐서는 틀린 줄을 영영 모릅니다.

순서를 어겨서 쓴 실제 결과

오늘은 화요일

문제는 겹치는 태그가 늘어날 때입니다. 그때는 브라우저가 요소를 둘로 쪼개거나 바깥으로 밀어내서 내가 쓴 것과 다른 구조를 만듭니다. 08단원에서 CSS 로 요소를 골라 꾸밀 때 그 어긋난 구조 때문에 원하는 대로 안 먹습니다. 운에 기대지 말고 나중에 연 것을 먼저 닫으세요.

실수 4 — 꺾쇠를 빠뜨림
p>안녕하세요</p>

여는 꺾쇠 < 가 없으니 태그로 인식되지 않습니다. 화면에 p>안녕하세요 라는 글자가 그대로 보입니다. "코드가 화면에 글자로 보인다" 면 십중팔구 꺾쇠나 빗금이 빠진 것입니다.

p>안녕하세요

실수 5 — 한글 자판으로 태그를 침
<ㅔ>안녕하세요</ㅔ>

p 를 치려다 한영 전환을 안 해서 ㅔ 가 들어갔습니다. 초보자에게 가장 많이 나는 실수입니다. 그런데 결과가 좀 이상합니다.

<ㅔ>안녕하세요

앞의 <ㅔ> 는 글자로 그대로 보이고, 뒤의 </ㅔ> 는 흔적도 없이 사라집니다. 브라우저는 꺾쇠 다음에 영어 글자가 와야만 태그로 봅니다. ㅔ 는 영어가 아니니 앞쪽은 그냥 글자 취급을 받고(실수 4와 같은 상황), 뒤쪽 </ 로 시작한 것은 주석으로 삼켜져 화면에서 없어집니다.

그래서 증상이 "글자가 반쪽만 이상하게 보인다" 로 나타납니다. 화면에 < 나 > 가 보이면 한영 전환부터 확인하세요.

── 정리 ──

1. 태그는 <이름> 과 </이름> 이 짝입니다. 닫는 쪽에는 빗금이 붙습니다.

2. 여는 태그 + 내용 + 닫는 태그 덩어리 전체를 요소라고 부릅니다.

3. <br />, <hr /> 처럼 감쌀 내용이 없는 빈 태그는 닫지 않습니다.

4. 태그 안에 태그를 넣는 것을 중첩이라 하고, 나중에 연 것을 먼저 닫습니다.

5. HTML 은 틀려도 에러가 안 납니다. 화면이 이상한지 눈으로 확인해야 합니다.

6. 태그 이름은 항상 소문자로 씁니다.
