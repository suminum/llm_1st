개념 03 — 문서의 뼈대

01단원 · HTML 시작하기

이 파일은 모든 HTML 파일에 똑같이 들어가는 네 부분을 다룹니다. 가장 중요한 것은 head 는 안 보이고 body 는 보인다는 차이입니다. 마지막에는 한글이 깨져 보이는 사고의 원인을 직접 만들어 봅니다.

섹션 1 — 뼈대 전체 그림

HTML 파일은 상자 안에 상자가 들어 있는 구조입니다. 먼저 전체 모양을 눈에 익힙니다.

<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8" /> <title>가게 안내</title> </head> <body> <p>오늘도 문을 엽니다.</p> </body> </html>

섹션 2 — 첫 줄의 <!DOCTYPE html>

파일의 맨 첫 줄에 늘 이것을 씁니다. 태그처럼 생겼지만 태그가 아니라 알림입니다.

섹션 3 — <html lang="ko"> : 가장 바깥 상자

html 요소는 문서 전체를 감싸는 하나뿐인 바깥 상자입니다. DOCTYPE 을 뺀 모든 것이 이 안에 들어갑니다.

섹션 4 — <head> : 화면에 안 보이는 곳

head 안에 넣은 것은 화면에 나오지 않습니다. 대신 브라우저가 이 문서를 어떻게 다룰지 알아내는 데 쓰입니다.

섹션 7 — 자주 하는 실수

아래 다섯 가지도 전부 에러가 나지 않습니다. 브라우저가 조용히 자기 방식대로 처리해 버립니다.

실수 1 — 화면에 보이길 원하는 글을 head 에 씀
<head> <title>가게 안내</title> <p>오늘도 문을 엽니다.</p> </head>

브라우저가 <p> 를 보는 순간 "여기부터는 본문이구나" 하고 멋대로 body 를 시작해 버립니다. 결과가 우연히 맞아 보일 때도 있지만, 내가 쓴 구조와 브라우저가 만든 구조가 달라져서 나중에 CSS 가 안 먹는 원인이 됩니다.

이렇게 쓰세요
<head> <title>가게 안내</title> </head> <body> <p>오늘도 문을 엽니다.</p> </body>
실수 2 — charset 을 body 안이나 파일 아래쪽에 씀
<body> <meta charset="UTF-8" /> <p>안녕하세요</p> </body>

브라우저는 이미 글자를 다 읽은 뒤에 이 쪽지를 보게 됩니다. 늦게 본 쪽지는 소용이 없어서 그냥 무시됩니다. 한글이 깨질 수 있는데도 코드에는 charset 이 분명히 적혀 있어서 원인을 찾기 어렵습니다. charset 은 head 안 맨 위에 씁니다.

실수 3 — DOCTYPE 위에 빈 줄이나 다른 글자를 둠
내가 만든 페이지 <!DOCTYPE html> <html lang="ko">

맨 위에 있던 내가 만든 페이지 라는 글자가 화면 맨 위에 그대로 튀어나옵니다. 그리고 DOCTYPE 이 첫 줄이 아니게 되어 브라우저가 옛날 규칙으로 그리기 시작합니다. <!DOCTYPE html> 은 언제나 파일의 첫 줄입니다.

실수 4 — head 를 닫지 않고 body 를 시작함
<head> <title>가게 안내</title> <body> <p>오늘도 문을 엽니다.</p> </body>

닫는 </head> 가 없습니다. 그런데도 화면은 멀쩡하게 나옵니다. 브라우저가 알아서 닫아 주기 때문입니다. 운이 좋아 맞은 것이니 습관으로 삼지 마세요. 여는 것마다 반드시 닫으세요.

실수 5 — title 을 두 개 씀
<title>가게 안내</title> <title>영업시간</title>

탭에는 앞의 것 하나만 나오고 뒤의 것은 조용히 버려집니다. "탭 이름을 바꿨는데 왜 안 바뀌지?" 하고 헤매게 됩니다. 위쪽에 title 이 이미 있는지 먼저 확인하세요.

── 정리 ──

1. 모든 HTML 파일은 <!DOCTYPE html> · html · head · body 네 부분으로 되어 있습니다.

2. <!DOCTYPE html> 은 태그가 아니라 알림이고, 언제나 첫 줄입니다.

3. html 은 전체를 감싸는 바깥 상자이고, lang="ko" 로 한국어임을 알립니다.

4. head 는 안 보이는 정보, body 는 보이는 내용입니다. 이 차이가 핵심입니다.

5. title 은 본문이 아니라 브라우저 탭 이름으로 나옵니다.

6. <meta charset="UTF-8" /> 를 head 맨 위에 씁니다. 저장 방식과 어긋나면 한글이 깨집니다.
