# 09단원 — 종합 실습

01~08단원을 **엮어서** 하나를 만드는 단원입니다.
새로 배우는 문법은 없습니다. 배운 것을 조립하는 연습만 합니다.

**4개 실습 / 25문제 / 약 5.2시간**

## 어디서 하나

종합01~03은 이 폴더에 있습니다.

```
node 종합01_주문_관리.ts
npm run grade          ← 채점
npm run check          ← 타입 검사
```

**종합04만 브라우저**가 필요해서 07단원의 실습프로젝트 안에 있습니다.

```
cd ../07_React와_타입스크립트/실습프로젝트
npm run dev            ← 왼쪽 목록에서 "종합04 주문 화면" 고르기
```

## 이 단원의 규칙

앞 단원들에서 정한 것과 같습니다. **세 가지를 쓰지 않습니다.**

| 금지 | 대신 |
| --- | --- |
| `any` | 모양을 적거나(04단원) `unknown` 으로 받고 확인(08단원) |
| `!` | `?.` 와 `??`, 또는 `if` 로 확인(05단원) |
| `as` | `satisfies` 또는 `: 타입` (08단원) |

**정답 파일 넷 다 이 셋을 한 번도 안 씁니다.** 안 써도 다 됩니다.

---

## 푸는 순서

**앞 문제에서 만든 것을 뒤에서 씁니다.** 순서대로 푸세요.

예를 들어 종합01은 문제 2에서 만든 `findMenu` 를 문제 3·6이 쓰고,
문제 7(영수증)은 3·5·6을 전부 가져다 씁니다.
그래서 마지막 문제는 새로 쓸 코드가 거의 없습니다. **그게 함수로 쪼개 둔 이유입니다.**

막히면 `_정답.ts` 를 보되, 먼저 10분은 혼자 고민해 보세요.
정답 파일은 **해설이 본체**입니다. 맞았어도 해설은 읽으세요.

## 다 끝냈다면

종합01~04를 다 풀었다면 이제 이걸 할 수 있습니다.

- **React 컴포넌트에 타입을 붙여 만든다** — props · useState · 이벤트 · 화면 상태 (07단원 · 종합04)
- **서버 데이터를 받아 모양을 적고 확인해서 쓴다** — `unknown` 으로 받고 좁혀서 쓰는 흐름 (종합03)
- **남의 코드에 나오는 `type` · 제네릭 · 유니온을 읽는다** (04~06단원)
- **기존 JS 프로젝트를 한 파일씩 옮긴다** — `allowJs` → `checkJs` → `.ts` (08단원)

목록을 읽고 "이건 아직 못 하겠는데" 싶은 것이 있으면 괄호 안 단원으로 돌아가세요.
그게 이 자료를 한 번 더 볼 값어치가 있는 유일한 신호입니다.

### 안 배운 것 중에 곧 필요해질 것

- **`zod`** — 밖에서 온 값을 확인하는 일을 대신해 줍니다. 종합03에서 손으로 짠 여섯 줄이 한 줄이 됩니다.
- **`ESLint`** — `any` 금지 같은 규칙을 사람이 아니라 도구가 봅니다.
- **유틸리티 타입** `Partial` · `Pick` · `Omit` · `Record` — 08단원 개념03에 이름만 나왔습니다.
- **`async` / `await` 로 진짜 서버 부르기** — 06단원에서 `Promise` 를 봤고, 07단원 화면 상태와 종합03의 확인을
  이어 붙이면 그게 실무 코드입니다. 이 자료에서는 `setTimeout` 으로 흉내만 냈습니다.

**바로 이어서 할 것** — Node.js + Express + DB(백엔드).
그때도 타입스크립트로 하면 여기서 배운 것이 그대로 쓰입니다.
서버에서 받은 요청 본문에 모양을 적는 일이 04단원 개념04와 완전히 같습니다.
