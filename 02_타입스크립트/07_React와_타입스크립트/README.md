# 07단원 — React와 타입스크립트

이 단원만 **브라우저**가 필요합니다. 그래서 파일이 `실습프로젝트/` 안에 있습니다.
01~06단원처럼 `node 파일.ts` 로 돌릴 수 없습니다.

---

## 시작하기

한 번만 (이 폴더에서):

```
cd 실습프로젝트
npm install
```

그다음 매번:

```
npm run dev
```

주소가 뜨면(`http://localhost:5173/`) 브라우저로 여세요.
왼쪽 목록에서 예제를 고르면 오른쪽에 나옵니다.

**터미널을 하나 더 열어서** 검사를 돌립니다. `npm run dev` 는 켜 둔 채로 둡니다.

```
npm run typecheck    # 개념·정답 파일 — 언제나 조용해야 정상
npm run check        # 연습문제 — 다 풀면 조용해짐
```

## 파일이 어디 있나

```
실습프로젝트/
  src/
    07_React와_타입스크립트/
      개념01_props에_타입_붙이기.tsx
      개념02_useState와_타입.tsx
      개념03_이벤트와_폼.tsx
      개념04_화면_상태_다루기.tsx
      연습문제.tsx
      연습문제_정답.tsx
    _ui/          ← 자료가 쓰는 틀. 안 봐도 됩니다
    App.tsx       ← 왼쪽 목록 화면. 안 고쳐도 됩니다
    main.tsx      ← 시작점
```

`src/07_.../` 에 `.tsx` 파일을 새로 만들면 **왼쪽 목록에 저절로 나타납니다.**
(React자료 실습프로젝트와 같은 구조입니다)

## 01~06단원과 뭐가 다른가

| | 01~06단원 | 07단원 |
| --- | --- | --- |
| 확장자 | `.ts` | `.tsx` |
| 실행 | `node 파일.ts` | `npm run dev` → 브라우저 |
| 타입을 지우는 것 | `node` | **Vite** |
| 정리 | 파일 아래 주석 | **화면에 렌더링**(`<Summary>`) |

**타입을 검사하지 않고 지운다**는 구조는 똑같습니다.
Vite 도 `node` 와 마찬가지로 타입을 안 봅니다.
그래서 **화면이 잘 나와도 타입이 틀려 있을 수 있습니다.**
저장할 때마다 VS Code 의 빨간 밑줄을 보는 습관이 여기서 특히 중요합니다.

## 막히면 여기부터

**에러에 `never` 가 보인다**
→ `useState([])` 입니다. `useState<Menu[]>([])` 로 고치세요. (개념02 섹션3)

**`TS7031 Binding element ... implicitly has an 'any' type`**
→ props 에 타입을 안 붙였습니다. (개념01 섹션2)

**이벤트 매개변수 타입을 모르겠다**
→ 외우지 마세요. 태그 안에 인라인으로 써 보고 `e` 에 마우스를 올려 이름을 베끼면 됩니다. (개념03 섹션2)

**`TS2314 Generic type ... requires 1 type argument(s)`**
→ `React.ChangeEvent` 처럼 `<HTMLInputElement>` 를 빼먹었습니다. (개념03 섹션3)

**폼을 제출하면 화면이 새로고침된다**
→ `e.preventDefault()` 를 빠뜨렸습니다. 타입은 이걸 안 막아 줍니다. (개념03 섹션4)

## 강사용

화면이 실제로 그려지는지는 `tsc` 가 안 봅니다. 진짜 크롬으로 확인하세요.

```
터미널 A:  npm run dev
터미널 B:  node ../../_검증도구/drive_07.js
```

예제를 하나씩 눌러 가며 콘솔 에러·`ErrorBox`·빈 화면·조작 동작·폼 새로고침을 봅니다.

에러 예제(`// 에러:`) 대조는 따로입니다.

```
node ../../_검증도구/verify_tsx.js
```
